# 变更日志

## [0.2.0] - 2026-10-29

### 变更

- 合并原「诉讼案件前期研判」与「诉讼文书与案件推进」两个套件，对外统一为「诉讼分析及文书撰写专家套件」。
- 将案件分析、判决深析、法律检索、要素式文书、方案生成和 Word 交付组织为同一诉讼工作流，减少成员重复和入口歧义。
- 保留 `litigation-assessment` 与 `litigation-documents-operations` 的历史 v0.1.0 下载资产，不再继续分别发布新版本。
- `case-progress`、`case-dashboard` 仍处于骨架版本，本版不纳入公开套件。
