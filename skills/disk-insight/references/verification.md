# 验证范围

## 创建预检

| 层 | 本 Skill 的实现与验收 |
| --- | --- |
| Contract | 只读诊断；私有新文件是唯一输出副作用；增长必须有可比历史，缺失不补零 |
| Producer | `disk_probe.py`：预算内元数据采集、独立快照比较、schema 9 只读历史自动发现/差分/容量汇总 |
| Verifier | `check_probe.py` 在临时目录构造真实文件、硬链接、符号链接和多候选 SQLite（含时间戳全损坏库）；断言实际数值与输入字节不变 |
| Evidence binding | 维护任务记录命令、候选提交和 SHA-256；正式 Harness 标记须由 `skill-lint` 候选门禁另外复算 |
| Fault injection | 不同根/口径、缺失路径、预算截断、符号链接越界、未知 schema、输出已存在、非法参数、快照时间戳全损坏应拒绝或明确降级 |
| Closure | 所覆盖脚本场景通过才记录对应证据；Agent 对用途/活跃度判断不能由脚本测试签发通过 |
| Composition | 可选 Fathom 只读输入；输出含 schema、时点、范围、口径、质量；后续清理/Git 操作另有精确授权 |

正常样例：缓存内存在普通文件与硬链接，仅计一次分配块，符号链接不进入外部目录。自动历史摘要选择目标窗口内同数据集快照，并同时返回目录差分和容器 free delta。

失败样例：选择两个不同扫描根的 Fathom 快照，应返回非零且不生成差分文件。

逃逸反例：旧快照没有某目录，新快照目录为 10 GiB；不能输出“增长 10 GiB”，只能标记“旧侧未记录”。另一个反例是预算到期后的目录小计，不能当作该目录完整占用。第三个反例是整个历史库的快照时间戳均不可解析：这是历史损坏，不能降级成 `no_history` 并退出 0，必须非零退出且不产出成功 JSON；损坏库与可用库并存时，可用库照常返回，损坏库标为 `corrupt_history`。

## 可运行检查

```bash
PYTHONDONTWRITEBYTECODE=1 python3 "SKILL_DIR/scripts/check_probe.py"
```

仅使用 Python 标准库、临时合成材料，不联网、不执行删除/迁移/模型管理。测试临时目录由 Python 测试框架在结束时回收。真实 HOME 的脚本试跑只能证明该范围的采集路径；不能代替跨日历史或全盘覆盖验证。

新上下文前向测试使用现实请求：“磁盘满了，帮我看近七天 AI 产物；保留视频工程和最终成片”，给当前 Skill 和最少原始材料，检查是否正确区分增长/mtime、截断/总量和可视化/缓存。没有运行独立前向测试与多轮签名门禁时，Agent 语义可靠性和指令遵循稳定性为 `NOT_VERIFIED`。
