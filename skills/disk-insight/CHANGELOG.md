# 变更记录

## [1.1.0] - 2026-10-21

### 新增

- `history` 子命令：自动发现常见 Fathom 数据库（或显式 `--db` / 限定的 `--db-dir`），按请求天数选择同数据集前后快照，返回目录差分、`volume_stats` 与容器容量样本，可直接解释真实硬盘总量变化。
- 输出实际区间 `actual_days`、候选库发现报告与容量 delta，避免用单次测量或目录累计冒充增长和可释放空间。

### 改进

- 主流程改为“先自动复用历史，再只对缺口补定向扫描”，减少重复全盘采集；SKILL.md 与参考同步默认优先历史。
- 规则补充 APFS clone/硬链接导致目录累计与物理容量可能严重偏离的判读要求（来自 Chrome 签名副本实测）。
- 快照时间戳全部不可解析时按历史损坏处理并非零退出，不再静默降级为 `no_history`；损坏库与可用库并存时可用库照常返回，损坏库标为 `corrupt_history`。
- 补充跨根硬链接边界：去重只在单个扫描根内生效，分次扫描不同根时同一 inode 会各计一次。

## [1.0.0] - 2026-10-21

### 新增

- 基于 Fathom 的快照差分与逐层归因思路，提供独立的磁盘空间研判 Skill；支持有预算的元数据采集和只读历史查询。
- 区分模型、Agent 会话、Git 工作树、依赖缓存与可视化材料的保留价值；明确保护工程、独有素材、成品和必要证据。
- 提供同口径比较、缺失不补零、权限/预算降级、私有新文件输出与合成正反例检查；不提供自动清理功能。
