# 证据与争点核对

自查用于建立议程；不要在角色发言前由主控替双方写好全部攻防结论。

对每项请求或指控建立：主张 → 经核验的适用规范与要件 → 待证事实 → 证明责任及依据 → 支持材料 → 相反材料 → 未解决事项。证明责任与证明标准按案型和争点核验，不能将民事模板直接套到刑事。

| 标记 | 含义 |
|---|---|
| 有材料支持 | 找到对应材料，仍须审查来源、证明范围与反证；不等于要件已被证明 |
| 待检验 | 材料存在矛盾、来源或身份未明、证明链不完整等具体问题 |
| 当前未见材料 | 仅说明本次提供范围内未找到，不等于现实中没有该证据 |
| 不适用／待核验 | 规范、责任分配或争点适用性尚未明确 |

每项核对：原始来源及定位是否可查；材料由谁形成、如何取得；能证明什么、不能证明什么；其他材料是否相互印证或冲突；对方是否已有具体异议。

不要仅凭“无公证”“复印件”“利害关系人”“间接证据”等标签自动认定无效或薄弱。记录需要核实的具体事项，再结合适用规则与全部材料评价。

民事按适用性检查权利基础、主体、效力、履行、数额、时间及程序争议；刑事分别检查指控事实、身份辨认、行为联系、证据取得及审查问题，并单列量刑相关材料。未提供的程序事实、例外规则与期限一律待核验，不给每个案件机械套满抗辩清单。

输出争点编号 I-001 等，每项附相关材料编号、正反主张、需回答的问题与优先级，交给法官组织演练。
