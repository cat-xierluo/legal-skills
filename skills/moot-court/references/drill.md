# 调度与回合规则

主 Agent 是唯一调度入口，兼任书记员；法官负责公开程序主持，双方负责各自论证。主控不因持有私有材料而给法官或对方暗示答案。先选 [程序方案](procedure-profiles.md)，再按 [Runtime 能力](runtime-adapters.md) 调用宿主工具。

## 一次正式发言做一个主要动作

`stage` 标示庭审环节，正文写明本次动作及对象，不增加 submission 的 JSON 字段：

| 动作 | 正文至少包含 | 下一步 |
|---|---|---|
| 提出主张／展示材料 | 争点、具体命题、材料及定位、证明目的 | 对方回应 |
| 质证／反驳 | 针对的事件与具体句意、异议理由、影响、需解释的问题 | 被质疑方回应 |
| 发问 | 问题编号、指定回答方、一个核心问题及其争点关系 | 指定角色回答 |
| 回答／补充回应 | 问题或事件编号、直接回答、依据、承认范围或不能回答的原因 | 必要追问或下一争点 |
| 程序申请／异议 | 针对的动作、适用理由、所求处理；不夹带完整实体辩论 | 必要时对方简答，再由法官处理 |
| 主持处理／争点归纳 | 已讨论内容、未决问题、处理及依据或待核验、下一动作与角色 | 主控依决定和剩余预算派发 |
| 总结 | 实际论证保留下来的观点、关键回应及材料限制 | 对方总结或法官归纳 |

问题可用 `Q-I001-01` 等稳定标签，但问题表是正文约定，clerk 不自动校验。提出反问不能代替本轮必须回答的问题；允许直接答“现有材料不能判断”，并说明缺什么，而不是编造答案。

## 什么算一轮讨论

一次争点交流回路：一方提出可检验主张／问题 → 另一方对该对象作具体回应 → 必要时原方针对新异议短答 → 法官归纳或指定下一步。它可能包含多个正式发言，也可能因无新问题提前结束。不是“原告一篇、被告一篇、法官一篇”便自动算完成。

默认每争点最多两次交流回路；出现实质新材料或新异议可在总预算内延至四次。追问、技术重派都消耗派发预算。预留双方总结和法官归纳的空间；预算不足先缩小争点范围，不先耗尽再强行写完整结论。预算是资源限制，不是现实诉讼中的法定轮次。

## 保证下一轮确实依赖上一轮

1. 法官依据可见案卷提出议程，双方陈述后确认争点。首轮只围绕其中一个关键命题。
2. 书记员 `dispatch` 固定 role、issue、stage、prompt 与 `responds_to`。开庭和首次陈述可无必答；后续回答应绑定实际问题事件。指定正文中的问题标签，不能只要求“反驳对方”。
3. 给角色本轮 packet、角色合同、公开程序约定及本方备忘录。packet.history 的 seq 对应正式事件，context 标出原争点与阶段；不把私有调度 prompt 放入共享历史。
4. 等待完整稿件。主控核对格式、实际回应与披露范围；书记员 commit 后才让后续角色回应。观点不同不构成拒收理由，论证强弱留给对方与复核。
5. 回应未覆盖必答问题时先请求同一角色补齐草稿，保持原派发；持续技术失败按重试上限处理。已入卷后发现遗漏则新开更正／补答发言，保留历史。
6. 法官从公开事件更新待答事项，主控据此选下一动作。不要让法官替应答方作答或替主张方补证。

书记员字段校验只证明 `responds_to` 与派发一致，不证明正文有效回应。实际检查采用：它回应了对方哪一句；给出了什么理由或明确限制；因此下一个问题为什么变化。即使双方未改变立场，只要针对同一争议作出了有据回应，也可以构成真实讨论。

## 待答事项与程序中断

公开归纳以简表维护：争点／问题编号、来源事件、回答方、回应事件、状态（待答／已直接回应／有材料缺口／请求程序处理／预算内未处理）。状态由法官发言与实际回复派生，可在复盘重建；备忘录或表格不得覆盖正式记录，也不能把“已回应”当作“已证明”。

异议与追问通过短回合插入，默认在上一个完整发言入卷后处理。若宿主不能实时中断，就明示“按发言边界处理”，不要声称重现现场抢话。异议提出 → 必要回应 → 法官处理 → 返回被打断的争点，四者均回指具体事件。禁止把所有异议留到结束后，也不为每句普通陈述机械插一次法官发言。

若确需中断尚未入卷的生成：停止或忽略旧实例、cancel、由法官明确新安排后重新派发。不得把半截稿当正式发言；取消不代表已经发表的观点被撤销。

有私有材料需要披露时，角色先向主控单独提出请求，不能在公开稿里夹带。披露、更正、重开按 [信息模型](information-model.md) 与 [书记员协议](clerk-protocol.md) 执行；每次新增决定性材料须给受影响方回应机会。

## 结束条件

一个争点可在以下情况下收口：关键主张和异议均有回应；材料缺口阻止进一步推进；没有新的实质争议；或预算已到。分别标记已演练／有待查事项／预算内未覆盖，不强迫共识，不把用户或角色沉默当实体失败。

双方总结之后由法官从公开记录归纳，不预测结果。独立复核者另查材料与互动质量，分离材料缺口、论证缺口与角色执行失误。用户参与的轮次必须等待真实输入；用户等待不是技术超时。主持无需占住一个持续在线的子任务，按需续接或冷启动即可。
