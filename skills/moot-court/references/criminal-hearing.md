# 刑事演练

先按 [程序方案](procedure-profiles.md) 记录程序范围与省略环节。

适用配置：judge、prosecution、defense。先明确法域、审级、程序和指控范围，按经核验的适用规则组织；本文件是演练议程，不能替代刑事程序与证明规则的检索。

1. 控方说明指控事项、对应事实及已有依据，辩方区分事实争议、法律争议与需先处理的程序问题。
2. 将指控拆为具体待证事项，分别映射支持证据、相反材料、矛盾与缺口；核验责任与标准，不套用民事请求清单。
3. 围绕各项证据开展审查、质疑与回应；若提出取证程序问题，先核对材料是否记载该情节，未知情况不能写成既有违法事实。
4. 法官追问身份关联、时间线、证据矛盾与推理缺口；不能以要求辩方补齐指控证据的方式代替控方论证。
5. 分别整理定罪相关争点与量刑相关事项；法官归纳本次讨论的材料基础和未解决问题，不宣布真实案件结果或量刑预测。

案件中已有被告人或证人的陈述，以材料原文和明确定位引用。本版不自动创建“知晓真相的证人／被告人 Agent”；不得通过角色扮演编出新的供述、证言或案件事实。用户明确要求模拟询问时，仅能在现有陈述范围内回答，超出部分标“材料未提及”，并将该环节注明为练习。

不能将角色沉默、工具超时或没有反证当作指控成立；也不能将辩方否认直接当作指控错误。复核者分别检查事实来源、论证回应与适用规则核验情况。

## 诉讼身份与程序完整性

当前 prosecution／defense 表示控方／辩护方的论证职责；defense 不能同时冒充被告人。刑诉法2018公开文本第198条区分辩论与被告人最后陈述，具体案件使用时核验适用规则。本版未支持独立被告人、证人及鉴定人，故交付应写“刑事核心争点控辩预演”，不得声称完成被告人最后陈述或全部庭审。证人未知回答不由辩护人或主控补造。

逐组证据明确证明目的、异议与回应；程序异议需要核对材料后由法官处理或保留，不把其他法域的异议口令自动移植进来。定罪与量刑议题分别跟踪待答事项，新增决定性材料须先给另一方回应机会。
