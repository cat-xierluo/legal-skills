# 民事演练

适用配置：judge、plaintiff、defendant。先明确法域、审级和实际程序；以下是争点驱动的演练框架，不是固定的法定庭审顺序。反诉、多方当事人及二审需在本次议程中明确角色映射和范围；当前工具仅支持三角色，复杂多方案件应说明限制，不把多个利益相反主体混成一个角色。

1. 原告明确各项请求及计算基础，被告分别回应；法官确认双方真正争议的事项。
2. 按请求建立权利基础、要件、待证事实和材料对应，核验各项证明责任及依据；不得仅凭“有证据”标记认定已经证明。
3. 围绕争点展示材料，由对方就来源、真实性、取得方式、关联及证明范围提出具体异议；提出异议不等于异议成立，主张无异议也不自动排除其他矛盾。
4. 对关键事实、身份、时间和金额进行发问与回应，法官追问双方未解释的缺口。
5. 辩论聚焦规则适用与证据到结论之间的推理，双方总结后列出待核验事项。

仅有起诉方材料时，被告以质疑现有证明与条件性假设开展攻防；仅有应诉方材料时，原告请求与证据缺失应明确列出。二审按上诉请求、原审争点及现有卷宗另拟议程，未提供原审文书时不假定原审认定。

每个争点保留双方最强观点、关键发言编号、回应情况及当前材料限制。调解空间、放弃请求、事实承认或证据披露需要用户决定，不由模拟角色替用户作实际处分。
