# 数据纪律

## 企查查 MCP · E 路径 ⓪ 铁律

### 实体识别（不可跳过）

任何企业类调用都必须先经 `qcc-company.get_company_by_query` 做实体识别,识别失败时**必须把候选列表完整展示给用户,等待用户明确选定后**再调用下游业务工具。**禁止自动选择排名第一的候选项**(会导致对错误主体发起尽调)。

满足以下任一条件可直接调用下游工具（无需再走 get_company_by_query）：

1. 输入以 18 项完整组织机构后缀之一结尾:
   - 有限公司、有限责任公司、股份有限公司、集团有限公司、集团股份有限公司
   - 合伙企业、普通合伙企业、有限合伙企业、特殊普通合伙
   - 个人独资企业、外资企业、全民所有制、集体所有制、联营企业、股份合作企业
   - 律师事务所、农民专业合作社（含"联合社"）
   - 分公司（前面必须带完整母公司全名）
2. 输入是 18 位统一社会信用代码(例如 `91320594MA1MNBPN3Q`)

> 简称、品牌名、股票简称、不完整名不得直接作为 searchKey。"科技、集团、控股"等行业词不属于完整后缀。

### 引用已聚合字段的口径

- 穿透类（实控人 / 受益所有人）：以 `get_actual_controller` / `get_beneficial_owners` 的返回值为准,禁止自行累乘各层持股比例。
- 直接股东 / 对外投资：`get_shareholder_info` / `get_external_investments` 返回的是"一层直接"比例,禁止据此推断穿透或间接持股。
- 财务比率 / 增速：`get_financial_data` 返回的服务端精算字段,禁止自行用营收/净利润重算。

## 网络检索 · 信源优先级

报告骨架的 2-3 段（产业链 / 政策 / 产业园）靠网络检索补。信源优先级（高 → 低）：

| 优先级 | 信源类型 | 示例 |
|---|---|---|
| P1 | 上市公司招股说明书 / 挂牌公司公开转让说明书 / 法律意见书中的行业分析与风险提示 | 巨潮资讯网、各交易所披露平台 |
| P2 | 官媒产业报道 | 新华社、人民日报、经济日报、财新、第一财经 |
| P3 | 行业协会发布的白皮书 / 年报 | 中国半导体行业协会、中国汽车工业协会等 |
| P4 | 主流财经媒体专题报道 | 21 世纪经济报道、证券时报、上海证券报 |
| P5 | 一般网页 | 兜底,需在引用处显式标注 |

引用规范：

- 每条关键结论必须在 `templates/report-skeleton.md` 第 6 段附录中标注信源 URL + 检索时间 + 信源层级（如 `[P2]`）
- 关键数据须有至少 2 个独立信源交叉验证,否则标注 `[单一信源]`
- 政策文件须标注发布 / 施行日期

## 不可信信源黑名单

`config/source-blacklist.txt` 一行一个域名,命中则丢弃。可加入但不限于：

- 内容农场(例如 `baijiahao.baidu.com` 默认黑)
- AI 生成内容农场(可通过特征识别)
- 已被监管处罚的违规新闻源

## 不复制真实项目信息

报告示例严禁出现：

- 真实客户名 / 商号
- 真实申请号 / 案号
- 内部案件编号 / 委托编号
- 真实内部联系人姓名

一律用 `XX 行业 / XX 地区 / XX 客户 / {YYYYMMDD} / {申请号}` 占位。
