# 信源优先级

行业调研报告第 2-3 段（产业链 / 政策 / 产业园）靠网络检索补。AI 在引用网络信源时,按本表优先级从高到低选取,并在引用处标注信源层级 `[P1]` - `[P5]`。

## 优先级总表

| 优先级 | 信源类型 | 典型示例 | 标注规则 |
|---|---|---|---|
| P1 | 一手文本 | 上市公司招股说明书 / 挂牌公司公开转让说明书 / 法律意见书 / 政府正式文件 | `[P1] URL` |
| P2 | 权威官媒 | 新华社 / 人民日报 / 经济日报 / 财新 / 第一财经 | `[P2] URL` |
| P3 | 行业协会 / 研究机构 | 中国半导体行业协会、中国汽车工业协会、艾瑞、易观、赛迪 | `[P3] URL` |
| P4 | 主流财经媒体专题 | 21 世纪经济报道 / 证券时报 / 上海证券报 / 经济观察报 / 中国经营报 | `[P4] URL` |
| P5 | 一般网页 | 兜底,需显式标注且不得作为关键结论唯一信源 | `[P5] URL` |

## 交叉验证规则

- **关键数据**(行业规模、市场份额、政策核心条款、产业园规划目标)必须有 ≥2 个独立信源,且建议至少 1 个 P1 或 P2。
- 找不到第二独立信源时,在引用处显式加 `[单一信源]` 标记,不得隐去。
- "独立信源"定义为：域名 / 主办方不同,且不是转载关系(同一稿件多家媒体转载只算 1 个信源)。

## 时效性

- 政策文件须标注 **发布 / 施行日期**；超过 24 个月的政策文件在引用时自动加 `[可能已过期]` 提示。
- 招股说明书 / 法律意见书须标注 **披露年份 / 文件版本**。
- 行业规模 / 市场份额数据须标注 **统计口径年份**(如"2025 年规模"指 2025 年统计)。

## 不可信信源(默认黑名单)

`config/source-blacklist.txt` 中声明的域名,网络检索结果命中则自动丢弃。下表是建议默认加入但由用户自行维护的清单(本 skill 默认空):

```
# 示例（取消注释即生效）
# baijiahao.baidu.com
# 360kuai.com
# sohu.com  # 注:也含优质原创,谨慎
```

## 法律材料特殊来源

行业调研**不**调取华宇元典法规数据库（v1 不接元典,v2 再议"行业相关法规动态"模块）。如报告涉及法规动态,优先信源：

1. 国务院 / 部委官方发布的法规原文(中国政府网、国家法律法规数据库)
2. 最高人民法院发布的司法解释 / 指导案例
3. 行业主管部门发布的规章 / 规范性文件
4. 主流法律期刊(《中国法律评论》《中国法学》《法学》等)
