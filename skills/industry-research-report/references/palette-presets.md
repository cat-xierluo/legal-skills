# 律师常见调色板预设

本 skill 内置 5 个律师行业常见调色板,用户首启时选择一个作为主调,后续可在 `report-profile.md` 单独覆盖 `accent_color` 微调。

> 调色板决定 `--primary`(主色,封面背景/标题/页眉/表头)、`--accent`(强调色,标题下划线/h3 左边框/装饰线)、`--bg-card`(次背景,交替行/引用块)的颜色。
> `--bg-page`(页面底色)默认白色;律所强偏好米黄可单独覆盖 `--bg-page: #F4F1EA`。
> 完整 color tokens 见 `references/design-spec.md`。

## 1. bluebook · 蓝皮书（默认）

- **视觉哲学**：法律经典蓝皮书,庄重权威
- **适用场景**：对外正式发布物(白皮书 / 法律意见书 / 行业报告)
- **主色**：`#1B3C59` 深蓝
- **强调色**：`#D4AF37` 金色
- **次背景**：`#F4F1EA` 米黄
- **典型律所**:综合性大所常见配色
- **历史渊源**:法律经典蓝皮书体例

## 2. service-plan · 律所深棕

- **视觉哲学**：传统律所文书风,温暖稳重
- **适用场景**：服务方案 / 提案 / 顾问客户长期物料
- **主色**：`#5A4E48` 律所深棕
- **强调色**：`#927F76` 棕点缀
- **次背景**：`#F5F0ED` 浅棕
- **典型律所**：金杜 / 国浩 / 锦天城等传统强所
- **沿用**：md2word `service-plan` 主题色

## 3. burgundy · 酒红

- **视觉哲学**：高端典雅,带学术气
- **适用场景**：法学院 / 学术出版 / 涉外律所
- **主色**：`#722F37` 酒红
- **强调色**：`#B08D5C` 古铜金
- **次背景**：`#F8F1ED` 米白
- **典型场景**：海问 / 瀛和等精品所 / 国际仲裁出版物

## 4. forest · 森林绿

- **视觉哲学**：环境法 / ESG / 合规方向
- **适用场景**：环境资源法 / ESG 合规 / 碳中和业务
- **主色**：`#1F4E3D` 森林绿
- **强调色**：`#A8853A` 麦穗金
- **次背景**：`#F2F4ED` 麦草白
- **典型律所**：专注环境法的精品所 / ESG 业务部门

## 5. tech · 科技蓝

- **视觉哲学**：科技感,数字化律所
- **适用场景**：互联网 / 数据合规 / AI / 知识产权
- **主色**：`#1A3A6E` 科技蓝
- **强调色**：`#00A6B6` 青色点缀
- **次背景**：`#F0F4F8` 冰蓝白
- **典型律所**：互联网专项所 / 知产所 / 数据合规团队

---

## 自定义(advanced)

如需在 5 个预设之外自定义配色(如律所官方 VI 色),在 `report-profile.md` 通过覆盖 `accent_color` 字段即可微调强调色。**改主色需要同步改主模板 `references/report-template.html` 的 `:root { --primary }` 变量**,v1 不开放;v2 会把主色也变成 profile 字段。

## 选择建议

| 律所特点 | 推荐调色板 |
|---|---|
| 综合性大所、对外白皮书 | bluebook |
| 传统强所、长期顾问客户 | service-plan |
| 精品所、涉外仲裁 | burgundy |
| 环境法 / ESG / 合规专项 | forest |
| 互联网 / 数据合规 / AI / 知产 | tech |
| 律所官方有特定 VI 色 | 选最近似预设 + 后续人工微调 |
