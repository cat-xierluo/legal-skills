# 金额计算表模板

当案件涉及多类别款项（返还、贷款清偿、违约金、损失等）时，使用本表统一列示，避免遗漏、错算或重复计算。本模板对应 `SKILL.md` 输出模板体系，供民商事纠纷、合同解除、损害赔偿等场景使用。

## 二、贷款处理专项说明（商品房/按揭类必备）

- 不得要求相对方将全部房款直接返还委托人；应区分首付款、已偿还贷款本息、尚欠贷款本金。
- 尚欠贷款通常由委托人继续向银行清偿，或解除后由相对方直接涤除抵押/代偿，处置方式影响第 2、3 项金额归属。
- 银行诉讼地位：建议列为第三人或合并处理贷款合同，避免「判返还全款却未了结贷款」的履行冲突。

## 三、不得重复计算的项目

- 资金占用损失与逾期违约金：如均指向同一笔已付款的资金成本，避免双重获利，择一或差额主张。
- 已偿还贷款本息与返还本金：已还部分已从本金中支出，返还本金时不得再包含已还本金（除非约定全款返还且贷款由相对方结清）。
- 违约金与损害赔偿：以实际损失为上限，约定过高可能被调减，表中标注「调减风险」。

## 四、使用要求

- 每项金额必须附计算依据（合同条款、流水、票据或司法解释），不得只给总数。
- 存在争议的款项，在「备注」列标注「待举证」或「待法院认定」，不臆测。
- 与 `templates/legal-analysis-report.md` 的「请求与金额」小节衔接：报告中的请求金额应可追溯回本表序号。
