# 分析过程工作簿模板

用于展示 AI 执行法律分析的全过程中间产物，便于教学、竞赛演示、内部复盘与质量核查。本工作簿不是最终报告，而是「过程底稿」，各节可独立产出、逐步累积。对应 `SKILL.md` 输出模板体系。

## 一、材料清单

| 编号 | 材料名称 | 来源 | 类型 | 是否原件/复印件 | 初步可信度 |
|------|----------|------|------|----------------|------------|
| M1 | | | 合同/凭证/裁判文书/陈述 | | |

## 二、事实台账

- 客观事实（有材料支撑）：逐条列出，标注材料编号。
- 待证事实（需举证/核实）：标注「待补充」。
- 当事人陈述 vs 客观材料：区分两类，不混同。

## 三、法律问题树

```
委托目标
├── 问题1（如：解除权是否成立）
│   ├── 子问题1.1（约定解除 vs 法定解除）
│   └── 子问题1.2（催告要件）
├── 问题2（如：贷款如何处理）
└── 问题3（如：执行救济路径）
```
