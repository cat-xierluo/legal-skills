# 脱敏输出模式

当用户声明材料用于课程、竞赛、公开演示、案例分享或内部培训时，默认开启脱敏输出模式。本文件是对 `SKILL.md`「脱敏输出模式」章节的细化规则。

## 触发与范围

- 触发词示例：「用于竞赛」「课程演示」「脱敏后分享」「匿名化输出」。
- 范围：输出文本中的可识别个人/主体字段，不含分析结构本身。
- **材料自称「已脱敏」不等于脱敏合格**。输入材料常常只替换了人名（改成「委托人A/相对方B」）却保留了地名、机构名、平台账号等。看到已有角色化称谓时不得据此认定材料干净，仍须按下方字段清单逐类复查，**不得把材料原文的地域、机构表述直接抄进输出**。这是最常见的失效路径：材料里写「青岛市某区一家餐厅」，模型误以为已脱敏而原样照抄。

## 匿名化字段清单

| 类别 | 示例 | 替代称谓 |
|------|------|----------|
| 自然人 | 姓名、身份证号、手机号、住址 | 委托人A、相对方B、第三人C |
| 法人/组织 | 公司名、统一社会信用代码、住所地、经营地/门店地址、注册地 | 机构D、开发商B、银行D；地址一律按下行地域规则处理 |
| 地域 | 省、市、区/县、乡镇、街道、小区、楼盘、园区、商圈名称；法院名称中含的行政区划 | 一律抽象到**市级或更粗**：某省、某市、A地、B地；跨地域时用「甲地/乙地」区分。**不得输出「某区」「某县」「某街道」等区县及以下颗粒度**，即便已加「某」字——详见下方组合识别风险 |
| 财产标识 | 房产证号、银行账号、车牌 | 项目X、房屋Y |
| 案件标识 | 真实案号、裁判文号 | 以「本案」「另案」指代，不编造假案号 |

### 地域脱敏的组合识别风险（易漏项）

行政区划单独出现时识别度不高，但**与主体类型、行业、经营状态、时间等特征组合后往往足以反查到唯一主体**。例如「某市某区 + 餐厅 + 个体工商户 + 经营异常」在小范围内即可定位到具体商户，此时脱敏已实质失效。

规则：

- **区/县及以下颗粒度一律不得出现在输出中**，包括「某区」「某县」「某街道」这类已加「某」字的写法。加「某」字只去掉了名称，没有去掉颗粒度——而颗粒度本身就是缩小检索范围的关键信息。地域一律抽象到「某市」或「A 地」。
- 判断标准是**组合后的可识别性**，不是单个字段是否脱敏。输出前应自问：把本段所有特征拼起来，能否在公开渠道检索到唯一主体。
- 法院名称、登记机关名称、平台账号名称中隐含的地域同样适用本规则。

**输出前自检（脱敏模式下必做）**：全文搜索「区」「县」「街道」「镇」，逐个确认不是行政区划颗粒度的残留。案件画像表、当事人描述、管辖章节是三个最容易漏的位置。

## 保留项（不得因脱敏丢失）

- 法律关系性质（买卖/借贷/侵权/婚姻等）。
- 事实结构与时间线（用相对时间或「时点T1/T2」标注）。
- 争议焦点、要件、证据与法律问题树。
- 金额区间与计算逻辑（可用「首付款」「已还本息」等角色化表述，保留数值）。
- 管辖连接点的**法律性质**：如「侵权行为地」「侵权结果发生地」「被告住所地」「合同履行地」「不动产所在地」。脱敏只去掉具体行政区划名称，不去掉连接点本身——连接点属于程序分析的骨架，丢失后管辖章节无法成立。
  - 正确写法：「侵权行为地（相对方 B 经营地，具体行政区划已脱敏）在某市，与被告住所地重合」。
  - 错误写法（丢失分析价值）：「管辖已脱敏，不予分析」。
  - 错误写法（脱敏失效）：「青岛市某区」保留了真实市名；「某市某区」虽全部匿名，但保留了区县颗粒度，与行业、经营状态等特征组合后仍可反查——两者都不合格，正确写法是「某市」。

## 与核心原则的边界

- 脱敏是**输出呈现层**的处理，不改变「事实与陈述区分」「材料未提及标注未提及/待补充」原则。
- 若用户后续要求回填真实信息用于正式文书，关闭脱敏模式并提示复核隐私与合规（见 AGENTS.md 敏感信息规范）。
- 不得为脱敏而虚构事实、证据或法律关系。

## 输出模板衔接

- 客户说明版（`templates/client-summary.md`）、简版咨询答复可天然适配脱敏称谓。
- 正式法律分析报告（`templates/legal-analysis-report.md`）在脱敏模式下，页眉增加「本报告已脱敏，主体以角色称谓指代」声明。
