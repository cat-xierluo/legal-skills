# 场景八：等同原则分析

## 适用边界

仅在选定权利要求的某一必要技术特征与被诉技术方案不构成字面相同时，对对应特征进行初步等同分析。不得以产品整体相似代替逐特征判断。开始前读取 [共用法源与结论门禁](00-legal-basis.md)。

## 法律分析框架

对每个差异特征依次分析：

1. 被诉特征是否采用与权利要求特征基本相同的技术手段
2. 是否实现基本相同的功能
3. 是否达到基本相同的效果
4. 本领域普通技术人员在被诉侵权行为发生时，是否无需创造性劳动即可联想到该替换
5. 是否受禁止反悔、捐献规则、现有技术、权利要求公示性或其他规则限制

前三项都不能省略；“可联想到”是独立要件，不等于事后知道存在替换方案。等同分析须组合适用下列条款，不以单一案例、单一条文或整体效果相近替代逐特征判断：

| 核验问题 | 共同适用条款 | 核验重点 |
|---|---|---|
| 等同的一般定义 | 《最高人民法院关于审理专利纠纷案件适用法律问题的若干规定》第十三条；《专利侵权司法解释（一）》第七条 | 核对基本相同的手段、功能、效果，以及本领域普通技术人员在侵权行为发生时无需创造性劳动即可联想到。 |
| 全面覆盖与逐特征判断 | 《专利侵权司法解释（一）》第七条 | 只对字面不相同的对应特征分析等同；其他必要技术特征仍须逐项覆盖，不作整体等同。 |
| 功能性特征 | 《专利侵权司法解释（一）》第四条；《专利侵权司法解释（二）》第八条 | 先从说明书及附图确定实现该功能或效果不可缺少的具体技术特征，再判断相同或等同。 |
| 说明书捐献 | 《专利侵权司法解释（一）》第五条 | 说明书或附图已经披露但权利要求未记载的技术方案，原则上不能借等同原则重新纳入。 |
| 禁止反悔 | 《专利侵权司法解释（一）》第六条；《专利侵权司法解释（二）》第十三条 | 核对授权、复审或无效程序中的修改和意见陈述；明确被有权机关否定的限缩性陈述或修改，不当然导致放弃。 |
| 数值及范围边界 | 《专利侵权司法解释（二）》第十二条 | 对“至少”“不超过”等特别强调的边界用语，不得仅以数值接近认定等同。 |
| 封闭式组合物 | 《专利侵权司法解释（二）》第七条 | 增加其他技术特征可能排除落入；不可避免的常规数量杂质除外。 |
| 使用环境、制备方法和步骤顺序 | 《专利侵权司法解释（二）》第九条、第十条、第十一条 | 分别核对限定环境、产品制备方法和本领域技术人员能够直接明确理解的步骤顺序，不得被总体功能相近架空。 |
| 现有技术边界 | 《专利法》第六十七条；《专利侵权司法解释（一）》第十四条；《专利侵权司法解释（二）》第二十二条 | 扩张后的等同范围不得越过现有技术边界；现有技术抗辩本身仍须按一项现有技术方案进行完整比较。 |

## 输入门禁

- 选定权利要求及完整引用链
- 已完成的逐特征字面比对表
- 差异特征双方的结构、步骤、参数或连接关系
- 行为发生时的本领域常识、教科书、标准、论文或专利等证据
- 审查档案、无效档案和确权文书
- 无效程序存在修改时的全文替换页、修改对照表和最后一次符合现行规则的修改文本

证据仅能说明总体功能相近、但无法说明技术手段或效果时，结论为“证据不足”。

2026年《专利审查指南》未修改等同原则的司法判断标准。涉及比特流权利要求或无效程序修改时，仍须按指南第二部分第九章第7节和第四部分第三章第4.6.4节固定权利要求形态与最后有效文本，再适用本页列明的司法解释条款；不得用指南替代等同的一般定义、全面覆盖、捐献或禁止反悔规则。

## 结论门禁

- 任一三项比对要素或可联想到性为“无法判断”，不得输出“构成等同”。
- 任一核心要素存在实质差异，通常不支持该特征等同；说明具体差异和证据。
- 即使三项比对及可联想到性均初步支持，仍须完成限制因素审查。
- 等同分析只解决对应差异特征；选定权利要求的其他必要特征仍须满足全面覆盖要求。

## 输出措辞

支持但仍需复核：

> 现有证据初步支持差异特征〔编号〕在技术手段、功能和效果方面基本相同，并支持行为发生时的可联想到性；但该判断仍取决于审查档案、现有技术及其他限制因素的进一步核验。

不支持或证据不足：

> 差异特征〔编号〕在〔具体要素〕上存在实质差异 / 现有材料不足以判断〔具体要素〕，因此现阶段不支持 / 无法确认该特征构成等同。

最终报告必须列出不利证据和替代解释，不使用未核验案号、虚构裁判或类案统计。
