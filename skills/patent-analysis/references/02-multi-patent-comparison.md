# 场景二：多专利比对

## 适用边界

用于比较多件专利的技术方案和保护范围结构，不以相似度直接推导侵权、有效性或专利价值。分析前读取 [共用法源与结论门禁](00-legal-basis.md)。

## 输入门禁

- 各专利的法域、专利号、分析基准日和法律状态来源
- 各专利当前有效的权利要求及必要说明书内容
- 比较目的：技术布局、保护范围、同族演进、诉讼准备或交易尽调
- 任务选定的权利要求；未选定时，先列出全部独立权利要求供用户确认

不同法域、不同基准日或法律状态无法核验时，不输出保护范围强弱排序。

## 比较方法

1. 建立专利族、优先权和申请时序表，避免将同族文本当作独立技术来源。
2. 对每件专利的选定权利要求分别拆解必要技术特征。
3. 统一术语，但保留各专利原文；同名特征不得未经解释即视为相同。
4. 标记共同特征、差异特征、上下位概念和功能性限定。
5. 对保护范围关系只作条件性描述，并列明术语解释、法律状态和引用链前提。
