# 场景四：稳定性与无效风险分析

## 适用边界

用于识别中国发明或实用新型专利可能面临的无效理由、证据缺口和应对选项，不预测无效结果或胜诉概率。开始前读取 [共用法源与结论门禁](00-legal-basis.md)。进入具体无效程序时再读取 [无效宣告应对](09-invalidation-defense.md)。

## 必需输入

- 法域、专利号、分析基准日和法律状态来源
- 当前有效权利要求、说明书、附图和审查档案
- 任务选定的权利要求及完整引用链
- 已检索的对比文件、公开日/优先权日和证据来源
- 已有无效决定、行政裁判或相关确权记录

缺少有效权利要求、审查档案或可核验现有技术时，只能列风险议题和检索计划。

## 分析框架

### 1. 权利要求与时间基准

| 权利要求 | 类型/引用链 | 优先权日或申请日 | 当前文本来源 | 既往修改 |
|---|---|---|---|---|
|  |  |  |  |  |

### 2. 无效理由与证据

按任务和现有材料检查新颖性、创造性、说明书公开充分、权利要求清楚/支持、修改超范围、必要技术特征等可能理由。不得把问题清单写成已经成立的结论。

| 理由 | 目标权利要求/特征 | 证据及公开时间 | 支持因素 | 反向因素 | 证据缺口 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

### 3. 新颖性

- 每项新颖性判断原则上对应一份现有技术，核对是否直接、无歧义地公开全部必要技术特征。
- 核验公开时间、文本版本、译文和组合关系。
- 缺少一项必要特征时，不得仅凭整体相似作出“不具新颖性”判断。

### 4. 创造性

记录：最接近现有技术、区别特征、实际解决的技术问题、其他证据给出的技术启示，以及是否存在反向教导、预料不到的技术效果等。不得预设最接近现有技术或拼接动机。

### 5. 公开与支持

分别检查：

- 本领域技术人员能否根据说明书实现权利要求技术方案
- 权利要求概括是否获得说明书支持
- 术语或功能性限定是否清楚
- 审查过程中的修改是否有原始记载依据

## 风险表达

使用“已识别理由/关键证据/反向因素/证据缺口/建议动作”表达，不用百分比或简单红黄绿分数替代论证。

| 权利要求 | 已识别主要风险 | 关键证据 | 反向因素 | 现阶段结论 |
|---|---|---|---|---|
|  |  |  |  | 证据支持/需补检索/无法判断 |

## 修改方案边界

- 仅在现行无效程序规则和案件阶段允许时讨论权利要求修改。
- “进一步限定”所补入的技术特征应来自其他权利要求，不得直接从说明书或附图抽取新特征加入。
- 不得扩大原专利保护范围，不得以修改补救原始申请文件未记载的内容。
- 每个候选修改方案都要核验：形式是否合法、原始记载依据、对侵权比对的影响及禁止反悔风险。
- 不承诺合议组必然接受任何修改方案。

## 输出结构

1. 分析范围、基准日和材料清单
2. 权利要求版本及既往修改
3. 分理由、分权利要求的证据表
4. 支持因素、反向因素和证据缺口
5. 现有技术补充检索计划
6. 条件性修改或答复选项
7. 对侵权、许可或交易判断的影响
8. 法源和人工复核事项
