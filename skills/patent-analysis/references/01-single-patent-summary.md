# 场景一：单专利技术要点提取

## 适用边界

用于快速理解一件中国发明或实用新型专利，不直接判断侵权、有效性或价值。分析前同时读取 [共用法源与结论门禁](00-legal-basis.md)。

## 必需输入

- 专利公开/授权文本及专利号
- 分析基准日和法律状态来源
- 当前有效权利要求文本
- 说明书、附图及可取得的审查档案

缺少授权文本、有效权利要求或法律状态时，只做材料摘要并列出缺口。

## 分析步骤

1. 记录申请人、发明人、申请日、优先权日、公开日、授权日和当前法律状态及来源。
2. 用一句话概括专利拟解决的技术问题；不要把摘要表述直接当作保护范围。
3. 列出全部独立权利要求，逐项拆解必要技术特征。
4. 按引用关系整理从属权利要求，说明其新增限制，不使用“越多越稳定”的简单计分。
5. 结合说明书和附图解释关键术语，记录段落号、附图号及可能的替代解释。
6. 区分专利明示的有益效果与分析者推断的技术效果。
