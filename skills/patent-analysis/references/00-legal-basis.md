# 共用法源、条款组合与结论门禁

> 适用范围：中国发明和实用新型专利的初步分析。核验日期：2026-07-30。本文只列法源名称、条款及适用要点，不保存法院或行政机关网页链接。正式意见应重新核对现行正式文本、施行日期及案件基准日。

## 二、保护范围与权利要求解释

保护范围不是由单一条文完成判断，应按“法定基准—主张对象—解释方法—特殊限定—公示边界”组合适用。

| 子问题 | 共同适用条款 | 适用要点 |
|---|---|---|
| 保护范围法定基准 | 《专利法》第六十四条；《专利纠纷若干规定》第十三条；《专利侵权司法解释（一）》第二条 | 以权利要求内容为准；说明书及附图用于解释而不是替代权利要求；保护范围由权利要求记载的技术特征及依法认定的等同特征确定。 |
| 权利人主张哪项权利要求 | 《专利侵权司法解释（一）》第一条；《专利侵权司法解释（二）》第一条 | 以权利人明确主张的权利要求为审理和比对对象；主张多项时逐项列明，未明确时应先释明而不是自动选择权利要求1。 |
| 从属权利要求 | 《专利侵权司法解释（一）》第一条第二款；《专利法实施细则》第二十三条、第二十五条 | 从属权利要求的范围由其附加技术特征和完整引用链共同确定；不得把其他从属权利要求的附加特征混入当前权利要求。 |
| 一般解释方法 | 《专利侵权司法解释（一）》第二条；《专利侵权司法解释（一）》第三条；《专利侵权司法解释（二）》第四条 | 站在本领域普通技术人员角度，结合说明书及附图、相关权利要求和审查档案解释；说明书有特别界定的从其界定；能够得到唯一理解的歧义按唯一理解认定。 |
| 功能或效果限定 | 《专利侵权司法解释（一）》第四条；《专利侵权司法解释（二）》第八条 | 先判断是否属于功能性特征，再结合说明书及附图中实现该功能或效果不可缺少的技术特征确定内容；不能只比较抽象功能。 |
| 说明书披露但权利要求未记载 | 《专利侵权司法解释（一）》第五条 | 仅在说明书或附图中披露、未写入权利要求的技术方案，原则上不能通过解释重新纳入保护范围。 |
| 权利要求各部分的限定作用 | 《专利侵权司法解释（二）》第五条；《专利法实施细则》第二十四条、第二十五条 | 独立权利要求前序部分、特征部分，以及从属权利要求引用部分、限定部分记载的技术特征均具有限定作用。 |
| 说明书明显缺陷与解释 | 《专利法》第二十六条第三款、第四款；《专利侵权司法解释（二）》第三条、第四条 | 说明书无法用于解释且专利权被请求无效时，可能涉及诉讼中止；可由本领域技术人员得到唯一理解的明显错误或歧义，按唯一理解处理。 |
| 权利要求撰写结构 | 《专利法实施细则》第二十二条至第二十五条 | 核对技术特征、独立/从属关系、前序/特征部分和引用/限定部分；附图标记通常用于理解，不当然构成额外限制。 |

解释顺序：先固定权利要求文本和版本，再确定主张对象及引用链，然后解释争议术语，最后才进行产品比对。不能先看产品结构再反向扩张权利要求。

## 三、全面覆盖与字面落入

### 1. 一般规则

共同适用《专利侵权司法解释（一）》第七条和《专利纠纷若干规定》第十三条：

- 审查被主张权利要求记载的全部技术特征，而不是只比较“发明点”或整体功能。
- 被诉技术方案包含全部相同或依法认定等同的对应特征，才可能落入保护范围。
- 缺少一个以上必要技术特征，或者存在一个以上不相同且不等同的对应特征，不落入该权利要求保护范围。
- 等同特征仍须逐项对应；不得用整体近似替代全面覆盖。

### 2. 特殊限定规则

一般全面覆盖规则还应与下列条款共同适用：

| 特征类型 | 条款 | 额外检查 |
|---|---|---|
| 前序部分、特征部分、引用部分、限定部分 | 《专利侵权司法解释（二）》第五条 | 不得认为只有“其特征在于”之后的内容才具有限定作用。 |
| 封闭式组合物 | 《专利侵权司法解释（二）》第七条 | 被诉方案即使包含权利要求全部特征，增加其他技术特征仍可能不落入；不可避免的常规数量杂质除外。 |
| 功能性特征 | 《专利侵权司法解释（一）》第四条；《专利侵权司法解释（二）》第八条 | 以说明书中实现功能或效果不可缺少的具体技术特征为比较基础。 |
| 使用环境特征 | 《专利侵权司法解释（二）》第九条 | 被诉方案不能适用于该限定使用环境的，不落入保护范围。 |
| 以制备方法界定产品 | 《专利侵权司法解释（二）》第十条 | 被诉产品的制备方法不相同也不等同的，不落入保护范围。 |
| 方法步骤顺序 | 《专利侵权司法解释（二）》第十一条 | 虽未明写顺序，但本领域普通技术人员能够直接、明确认为应按特定顺序实施的，该顺序具有限定作用。 |
| 数值或数值范围 | 《专利侵权司法解释（二）》第十二条 | 权利要求特别强调边界用语的，对不同数值主张等同受到严格限制。 |

### 3. 证据门禁

法律上的全面覆盖和事实上的证据充分是两个层次。逐特征使用以下状态：

| 状态 | 判定标准 | 结论作用 |
|---|---|---|
| `A-已证实` | 直接、可回查的证据支持产品具有对应特征 | 可计入已覆盖 |
| `B-初步支持` | 间接材料提供线索，仍需实物、图纸、检测或其他可靠证据核验 | 不计入已覆盖 |
| `C-不相同/缺失` | 证据显示不存在对应特征，或技术内容实质不同 | 不计入字面覆盖；必要时进入等同分析 |
| `D-无法判断` | 材料不足、产品版本不明或术语解释存在关键分歧 | 不计入已覆盖 |

- 出现 `C` 时，无论是否同时存在 `B/D`，均不得得出字面全面覆盖；逐项披露 `B/D` 缺口，并对需要评估的 `C` 特征另行分析等同。
- 仅在不存在 `C` 而出现 `B` 或 `D` 时，才写“证据不足，暂不能判断是否全面覆盖”，并列出补证方法。
- 只有全部必要特征均为 `A-已证实`，才能写“现有证据初步支持字面落入”。

## 四、等同原则及其限制

等同分析须同时适用一般定义、全面覆盖、具体特征类型和权利公示边界，不能只做“手段—功能—效果”三项文字比较。

| 子问题 | 共同适用条款 | 适用要点 |
|---|---|---|
| 等同的一般定义 | 《专利纠纷若干规定》第十三条；《专利侵权司法解释（一）》第七条 | 对对应技术特征判断是否以基本相同的手段、实现基本相同的功能、达到基本相同的效果，并且本领域普通技术人员在侵权行为发生时无需创造性劳动即可联想到。 |
| 逐特征与全部技术特征约束 | 《专利侵权司法解释（一）》第七条 | 等同判断针对不相同的对应特征；其他必要特征仍须满足全面覆盖，不得作整体等同。 |
| 功能性特征的相同或等同 | 《专利侵权司法解释（一）》第四条；《专利侵权司法解释（二）》第八条 | 先确定实现功能或效果不可缺少的技术特征，再比较手段、功能、效果和可联想到性。 |
| 说明书捐献 | 《专利侵权司法解释（一）》第五条 | 已在说明书或附图中披露但未写入权利要求的方案，原则上不能借等同原则收回。 |
| 禁止反悔 | 《专利侵权司法解释（一）》第六条；《专利侵权司法解释（二）》第十三条 | 授权、复审或无效程序中通过修改或意见陈述放弃的技术方案，不得重新纳入；但限缩性修改或陈述被有权机关明确否定的，不视为导致放弃。 |
| 数值特征 | 《专利侵权司法解释（二）》第十二条 | 对“至少”“不超过”等被特别强调的边界用语，主张不同数值构成等同受到限制；不能只以数值接近得出等同。 |
| 使用环境、制备方法、步骤顺序 | 《专利侵权司法解释（二）》第九条至第十一条 | 这些限定可能决定保护范围；对应内容不相同也不等同时，不能以总体效果接近绕过。 |
| 封闭式组合物 | 《专利侵权司法解释（二）》第七条 | 增加技术特征可能直接排除落入，不能机械套用“增加特征仍覆盖”的一般直觉。 |

等同分析至少回答：对应特征是什么、四项要件各自由什么证据支持、行为发生时的本领域认知是什么、是否触发说明书捐献或禁止反悔、是否存在数值或特定类型权利要求限制。

## 五、侵权行为与常见抗辩

| 主题 | 主要条款 | 分析要点 |
|---|---|---|
| 专利权人的排他权和实施行为 | 《专利法》第十一条 | 区分制造、使用、许诺销售、销售、进口及方法使用、使用或销售依方法直接获得的产品等行为，并核对行为主体、地点和时间。 |
| 侵权纠纷的请求与处理 | 《专利法》第六十五条 | 区分协商、民事诉讼和管理专利工作的部门处理等路径；该条用于纠纷处理，不替代第十一条对实施行为的识别。 |
| 依方法直接获得的产品 | 《专利侵权司法解释（二）》第二十条 | 对制造方法专利，进一步加工、处理该方法直接获得的产品后形成的后续产品，原则上不再作为“依照该专利方法直接获得的产品”。 |
| 帮助侵权与诱导侵权 | 《专利侵权司法解释（二）》第二十一条 | 核对行为人是否明知有关产品或方法系专门用于实施专利、是否未经许可提供，以及是否积极诱导他人实施；不得只因上下游有关联就直接认定。 |
| 新产品制造方法举证及评价报告 | 《专利法》第六十六条；《最高人民法院关于知识产权民事诉讼证据的若干规定》第三条；《专利法实施细则》第六十二条 | 新产品制造方法专利可能发生举证责任特别安排；非新产品制造方法仍应结合权利人已举证内容审查举证责任；实用新型或外观设计纠纷可能涉及专利权评价报告。 |
| 现有技术抗辩 | 《专利法》第六十七条；《专利侵权司法解释（一）》第十四条；《专利侵权司法解释（二）》第二十二条 | 先按申请日时适用的法律确定现有技术，再将被诉方案的全部相关技术特征与一项现有技术方案比较，判断是否相同或无实质性差异；不得拼接多项现有技术。 |
| 被诉方自己的在后专利 | 《专利侵权司法解释（二）》第二十三条 | 被诉技术方案获得在后专利，不当然排除其落入在先专利保护范围，仍须依照全面覆盖规则比对。 |
| 先用权等法定例外 | 《专利法》第七十五条 | 核对在先制造/使用准备、原有范围、临时过境、科研实验和行政审批例外的具体要件。 |
| 合法来源抗辩 | 《专利法》第七十七条；《专利侵权司法解释（二）》第二十五条；《最高人民法院关于知识产权民事诉讼证据的若干规定》第四条 | 使用、许诺销售或销售者须证明不知道且能证明产品合法来源，并提交符合通常交易习惯的证据；通常影响赔偿责任，不当然否定侵权行为性质。 |

## 六、稳定性与无效程序

| 主题 | 共同适用条款 | 适用要点 |
|---|---|---|
| 新颖性、创造性、实用性 | 《专利法》第二十二条 | 分权利要求、分对比文件审查，不以整体相似或主观分数代替法定要件。 |
| 公开充分、支持和清楚 | 《专利法》第二十六条第三款、第四款；《专利授权确权规定（一）》第六条至第九条 | 区分能否实施、是否需要过度劳动、是否得到说明书支持、术语是否清楚及功能性限定是否有具体实施方式。 |
| 修改超范围 | 《专利法》第三十三条 | 核对原说明书和权利要求书记载范围；申请、复审和无效阶段还要分别适用对应程序规则。 |
| 无效请求和决定 | 《专利法》第四十五条、第四十六条 | 任何单位或个人可依法请求无效；对无效决定不服的，自收到通知之日起三个月内起诉。 |
| 转送与专利权人答复 | 《专利法实施细则》第七十二条；《专利审查指南》第四部分第三章关于答复期限的现行规定；国家知识产权局通知书 | 国家知识产权局将无效请求书及有关文件副本送交专利权人并指定陈述意见期限；转送文件或审查通知须在指定期限内答复。指定答复期限通常为一个月，但必须以本案通知书记载、送达事实和现行规则核算；期满未答复不影响继续审理。 |
| 无效程序中的修改范围、方式与时机 | 《专利法》第三十三条；《专利法实施细则》第七十三条；《专利审查指南》第四部分第三章第4.6.1节至第4.6.3节 | 不得扩大原专利保护范围；“进一步限定”补入的技术特征应来自其他权利要求，不得直接从说明书或附图抽取；不得修改说明书和附图；具体修改方式、提交时机和审查文本以现行指南及合议组通知为准。 |
| 修改文本的提交 | 《专利审查指南》第四部分第三章第4.6.4节（自2026年1月1日起施行） | 修改权利要求书时提交全文替换页和修改对照表；同一无效程序内提交多个均符合第4.6.3节的修改文本时，以最后一次提交的文本为审查基础，其余不作为审查基础。 |

## 七、行政诉讼期限

- 对无效决定不服：适用《专利法》第四十六条，自收到通知之日起三个月内起诉。
- 不服第一审行政判决：适用《行政诉讼法》第八十五条，判决书送达之日起十五日内上诉。
- 不服第一审行政裁定：适用《行政诉讼法》第八十五条，裁定书送达之日起十日内上诉。
- 记录文书名称、送达日期、载明期限、计算口径和经办人；节假日、境外送达、电子送达或恢复权利问题交由专业人员核算。

## 八、选定权利要求和结论强度

1. 记录权利人已主张或任务明确选定的权利要求，不自动以权利要求1替代。
2. 存在多项独立权利要求时逐项解释和比对；从属权利要求合并完整引用链。
3. 依次区分 `材料事实`、`分析推断` 和 `法律判断`，每项法律判断写明法源全称或本文简称、具体条款、适用前提、效力状态和核验日期。
4. 不要求在报告中附法院或行政机关网页链接；内部检索记录可用于复核，但不能用检索摘要替代条文。
5. 不输出无数据来源的侵权概率、无效概率、胜诉率、固定案件周期或专利价值指数。
6. 诉讼、无效、FTO、交易和对外法律意见须由专利律师或专利代理师结合正式文本和完整材料复核。
