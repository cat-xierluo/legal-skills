# 场景九：无效宣告应对

## 适用边界

用于中国专利无效宣告程序的初步材料整理、理由分析和答复方案设计，不代替专利代理师/律师办理程序。收到通知后应立即以通知书记载内容、送达事实和现行《专利审查指南》核定期限。开始前读取 [共用法源与结论门禁](00-legal-basis.md)。

## 一、输入门禁

- 无效宣告请求书、证据、转送通知及送达日期
- 专利授权文本、当前有效权利要求、说明书和附图
- 原始申请文件、历次补正/修改、审查意见和答复
- 既往无效决定、行政裁判和关联侵权诉讼材料
- 当前《专利审查指南》、已生效修改决定及合议组发出的具体通知

缺少通知书或送达日期时，先标记“期限待立即人工核验”，不得按模板假定截止日。

## 二、期限表

| 事项 | 基本规则 | 本案需记录 |
|---|---|---|
| 专利权人答复 | 依《专利法实施细则》第七十二条在指定期限内陈述意见或答复；指定期限通常为一个月，以实际通知书记载及送达规则为准 | 通知名称、送达日期、载明期限、截止日计算 |
| 对无效决定起诉 | 自收到无效决定通知之日起三个月内向人民法院起诉 | 决定送达日期、三个月届满日 |
| 不服一审行政判决 | 判决书送达之日起十五日内上诉 | 判决送达日期、十五日届满日 |
| 不服一审行政裁定 | 裁定书送达之日起十日内上诉 | 裁定送达日期、十日届满日 |

法源见 [共用法源与结论门禁](00-legal-basis.md)。如涉及节假日、电子送达、境外当事人、补正或恢复权利，交由经办专业人员另行核算。

## 四、新颖性与创造性答复

### 新颖性

核验一份证据是否直接、无歧义地公开目标权利要求的全部必要技术特征，以及公开时间、版本、译文和证据资格。指出缺失特征或组合关系，避免仅写“整体不同”。

### 创造性

依次审查：

1. 最接近现有技术选择是否合理
2. 区别特征是否准确
3. 实际解决的技术问题是否包含区别特征或答案提示
4. 其他证据是否给出结合启示
5. 是否存在反向教导、技术障碍或预料不到的效果

每个环节分别列请求人主张、支持证据、答复理由和反向风险。

## 五、权利要求修改边界

不得沿用“可从说明书任意抽取特征加入”或“现场可以随时修改”的做法。

共同适用《专利法》第三十三条、《专利法实施细则》第七十三条及《专利审查指南》第四部分第三章第4.6.1节至第4.6.4节。第四十六条规范无效决定及决定后的行政诉讼救济，不替代第七十二条的转送答复规则或第七十三条的无效程序修改规则。

候选方案必须逐项核验：

- 符合当前无效程序允许的修改方式和提交时机
- 不改变原权利要求主题，不扩大原专利保护范围
- “进一步限定”所补入的技术特征来自其他权利要求，而不是直接来自说明书或附图
- 删除或更正是否满足现行规则
- 原始申请文件中的记载依据和不得超范围要求
- 提交权利要求书全文替换页和逐项修改对照表
- 同一程序提交多个修改文本时，明确最后一次符合第4.6.3节的文本将作为审查基础
- 修改后对侵权比对、损害赔偿期间和禁止反悔的影响

| 候选方案 | 修改方式 | 特征来源 | 提交时机依据 | 全文替换页/修改对照表 | 合法性风险 | 对侵权分析影响 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

不要把专利授权后“增加新的从属权利要求”列为当然可行的补强措施。合议组是否接受具体修改，以现行规则和本案程序决定为准。

## 六、口头审理准备

- 逐项建立争议焦点、证据位置、答复人和备用论证表
- 核验原件、译文、公开时间、证据交换和质证要求
- 准备技术示意，但不得用示意图替代权利要求文本和证据
- 对拟修改文本提前完成程序合法性和侵权影响复核
- 记录合议组通知和庭审安排，不假定可当庭任意补充新理由或修改文本

## 七、输出结构

1. 程序状态、通知与期限核算表
2. 当前有效权利要求及完整引用链
3. 分理由、分权利要求、分证据答复矩阵
4. 支持因素、反向因素和待补证据
5. 条件性修改方案、全文替换页、修改对照表及合法性核验
6. 对关联侵权、许可或交易的影响
7. 口头审理和后续行政诉讼准备
8. 法源、经办人和人工复核记录

不得输出无来源的无效成功率、胜诉率、固定审理周期或“必然维持/必然无效”等结论。
