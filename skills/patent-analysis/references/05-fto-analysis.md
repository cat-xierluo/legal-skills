# 场景五：自由实施（FTO）分析

## 适用边界

FTO 用于在特定法域、特定时间和特定实施行为下识别可能阻碍产品商业实施的有效专利权利要求。FTO 不是“不侵权保证”，也不能由单次关键词检索穷尽风险。开始前读取 [共用法源与结论门禁](00-legal-basis.md)。

## 必需输入与停止门禁

| 必需输入 | 至少记录 |
|---|---|
| 目标法域 | 计划制造、使用、许诺销售、销售、进口或实施方法的国家/地区 |
| 产品版本 | 型号、配置、软硬件版本、方法步骤及预计变更 |
| 实施行为 | 主体、地点、时间、供应链环节和具体行为 |
| 时间基准 | 检索截止日、预计上市/实施日和分析基准日 |
| 技术资料 | 图纸、BOM、流程、规格、接口、样品和可回查来源 |
| 检索范围 | 数据库、分类号、关键词、申请人/权利人、同族和截止条件 |
| 法律状态基线 | 状态数据来源、查询日、目标法域同族、权利要求版本和权属 |
| 法源更新基线 | `config/legal-source-register.json` 的基线ID、核验日期、指南版本、司法解释修订状态、期限补偿和许可备案 |

缺少目标法域、产品版本、实施行为、检索截止日或法律状态基线，或者候选专利的法律状态、目标法域同族和有效权利要求未核验时，必须停止风险评级，只输出补充或核验清单。法源或状态刷新触发后尚未完成复核的，适用同一停止门禁。

## 法源组合与刷新触发

FTO不是单一《专利审查指南》问题。至少共同适用《专利法》第十一条、第六十四条、第六十七条、第七十五条、第七十七条，《专利侵权司法解释（一）》第七条、第十四条，以及《专利侵权司法解释（二）》第二十一条至第二十五条；再结合《专利审查指南》核验权利要求形成、修改和状态事项。

分析前读取 [2026年《专利审查指南》十场景影响与更新门禁](11-2026-guideline-impact.md)。出现下列任一事项时，旧FTO基线失效并须刷新：

- 分析基准日晚于法源核验日，或者法律、司法解释、指南发布修改；
- 候选权利要求经授权、复审或无效程序修改；
- 专利法律状态、权属、期限补偿或许可备案变化；
- 产品版本、实施行为、供应链环节、目标法域或检索截止日变化。

刷新未完成时，停止风险评级，只输出补充或核验清单；不得把旧报告结论直接迁移到当前产品或当前日期。

## 工作步骤

### 1. 产品特征树

将产品拆为可检索的模块、结构、连接关系、参数、控制逻辑和方法步骤，区分当前版本与规划版本。

### 2. 检索与筛选

记录数据库、查询式、分类号、时间范围和检索日期。检索至少覆盖：

- 关键词与同义词
- IPC/CPC 分类号
- 主要竞争者、权利人和发明人
- 引证/被引证专利与同族
- 已公开申请、已授权专利和相关法律状态变化

命中摘要只用于初筛；进入风险清单前必须读取权利要求及必要说明书内容。

### 3. 法律状态与同族核验

对每个候选专利核验目标法域内的授权、届满、失效、终止、无效、恢复、权属、期限补偿、许可备案及有效权利要求版本。外国同族的状态不能代替目标法域核验。

### 4. 分权利要求比对

按 [产品—专利侵权比对](03-infringement-comparison.md) 使用 `A/B/C/D` 证据状态。多项独立权利要求、方法权利要求和选定从属权利要求分别评估。

|---|---|---|---|---|---|
|  |  |  | 通过/未通过 |  |  |

风险等级必须由明确规则支撑，例如：有效权利要求、全部必要特征证据、实施行为和剩余期限；不要用未定义的高/中/低评分。

## 结论边界

报告必须列出：

- 检索截止日和数据库覆盖限制
- 法源基线ID、核验日期、指南版本和本次刷新触发检查结果
- 未公开申请、状态延迟、语言和分类偏差等固有限制
- 产品版本变化导致重新分析的触发条件
- 候选专利的无效、许可、规避、异议或继续监测选项
- 需要目标法域专利专业人员复核的事项

推荐措辞：

> 在列明法域、产品版本、实施行为、数据库和检索截止日范围内，已识别以下候选权利要求。该结果不表示不存在其他专利风险；产品、权利要求、法律状态或实施地域发生变化时，应重新检索和比对。
