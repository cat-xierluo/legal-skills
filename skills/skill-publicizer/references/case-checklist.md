# 案例检查清单

源自三个实际公开化案例的共性收敛（magpie-optimizer、slides、self-evolve，2026-10 抽取）。用作执行清单或独立 reviewer 的检查范围；不是替代门禁脚本的证据。

## 阶段 A：范围与私密定义

- [ ] 「什么算私密」有一句话判定标准与不确定时的默认处置
- [ ] 敏感类别各有允许的替代写法（占位、档位、引用标签）
- [ ] 派生值（用量、聚合、并发）是否算私密已明确
- [ ] 「只读可访问」不等于「适合公开」已写明
- [ ] 示例值是明显占位形态
- [ ] 作者署名与内容中的真实名称已区分为两类
- [ ] 本轮授权范围（候选/合并/发布）已固定，越界项标 NOT_VERIFIED
- [ ] 权威仓库形态已显式选择：公仓为权威源 / 私仓为权威源导出快照 / 仅本地候选，未混用
- [ ] 导出快照形态记录来源 OID / manifest 与同步方向，公仓目录禁止独立改实现

## 阶段 B：分层与配置契约

- [ ] 私有层摆放形态已定（共树 ignore 分离或用户数据目录），对应防护已就位
- [ ] 私有层约定位置固定（`config/*.local.*` + `state/` 等）
- [ ] 公开层只保留 `*.example.*` 与 schema
- [ ] schema 与 example 成对维护且声明同步义务
- [ ] schema ID 区分设计态与可执行输入态
- [ ] 校验器不打印资料值
- [ ] 配置解析顺序明确；坏配置 fail-closed
- [ ] 相对路径按配置文件所在目录解析
- [ ] 私有配置名通配忽略，新增文件零维护
- [ ] 敏感私有文件按目标约定最小权限（创建时 0600 或既有兼容约定）；运行产物不入库
- [ ] 维护文档的去留形态已定（随仓去具体化 or 发布包排除）

## 阶段 C：机器可执行门禁

- [ ] 只读发布检查脚本存在；不联网、不写业务文件
- [ ] 覆盖：凭证关键字、邮箱手机号形态、本机路径、真实账号与额度、代理地址
- [ ] 覆盖：example/schema 可解析且字段一致
- [ ] 覆盖：Markdown 相对链接与被引用脚本存在
- [ ] 覆盖：多来源版本号一致
- [ ] 覆盖：ignore 确实覆盖私有层；私有层不在待发布集合
- [ ] 覆盖：具体名称通用模式（机构/人名职称/内部编号/联系方式/素材文件名/业务路径）
- [ ] 配置文件从严：身份联系素材字段必须为空
- [ ] 泛指前缀豁免防误报
- [ ] 有意保留项走登记表（file+正则+理由）
- [ ] 报告不回显命中原文
- [ ] 「什么算私密」判定同样覆盖派生统计：文件数、会话计数、页数、预算金额不写进公开正文、CHANGELOG 公开条目、PR 与提交说明
- [ ] 以退出码为准（0/1/2 合同）

## 阶段 D：打包与发布

- [ ] 允许清单打包，非整目录减黑名单
- [ ] 允许清单内二次排除（产物/缓存/私有目录/内部文档）
- [ ] 打包绑定不可变 OID；输出目录存在即拒绝覆盖
- [ ] 逐文件 SHA-256 + manifest + excluded 清单
- [ ] homepage 未公开时在 manifest 登记
- [ ] 从干净导出目录打包
- [ ] `.gitignore` 随包分发
- [ ] 已跟踪文件不因加 ignore 自动退出（逐项处理过）
- [ ] 分发/推送/部署分别授权

## 阶段 E：历史与洁净发布

- [ ] 历史导出形态已确认（清洁历史 vs 经审历史）
- [ ] 复用旧历史时敏感内容已单独评估并获用户裁决
- [ ] 转公开默认空仓 + 单一初始提交
- [ ] 「删除后靠 ignore 遮盖」未被当作移除手段
- [ ] 发布后对公开树重跑同一门禁

## 阶段 F：验证与复审

- [ ] 负控：注入痕迹全命中
- [ ] 负控：泛指零误报
- [ ] 负控：干净树零命中
- [ ] 反例：坏 schema/坏 JSON/坏链接均非零退出
- [ ] 无旧上下文前向检查通过
- [ ] 独立复审至少两轮；第二轮换宽判据
- [ ] 悬空引用与文档-实现一致性已查
- [ ] 复合 Skill（多 Runtime、状态库、HTML 报告、调度器）完成公开目录首次配置与隔离安装前向检查
- [ ] 安装入口与实际可调用性已核
- [ ] NOT_VERIFIED 逐条列明范围、责任方与恢复条件

## 案例特有决策参考

| 决策点 | 案例 | 结论 |
|---|---|---|
| 实现份数 vs 权威仓库 | self-evolve | 单源同包：只有一份可编辑源码，个性化走本地配置；「私仓为权威源 + 公仓导出快照」仍属单源，禁止两边都改实现 |
| 外部参照素材许可 | slides | 整体删除 + 自建替代，争议归零优于标注保留 |
| 私有层在 Skill 内 vs 用户目录 | slides | 五级解析两者兼容，缺省匿名可用 |
| 设计模板 vs 执行输入 | magpie | 不同 schema ID，文档明示不可直接喂给执行器 |
| 报告回显 | magpie | findings 不回显命中原文，防二次泄露 |
| 采用回执 | self-evolve | 「已登记验证通过」≠ 脚本验证；声明与核验分开 |
