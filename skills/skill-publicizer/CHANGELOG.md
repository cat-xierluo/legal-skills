# Changelog

## [1.1.0] - 2026-10-27

### 新增

- 明确私仓到公仓的两种迁移形态：整目录权威迁移与发行包快照；发行包快照必须记录来源 OID / manifest 与同步责任，不得冒称单源维护。
- 新增复合 Skill 前向安装检查：多 Runtime 会话读取、本地状态库、HTML 报告和调度器需验证公开目录首次配置、匿名默认路径、隔离数据根、来源只读扫描与实际报告生成。
- 结构校验前先对齐目标仓发布字段规范；通用 `quick_validate` 与项目合法 frontmatter 不兼容时记录 NOT_VERIFIED，不修改目标 Skill 迎合不匹配工具。

## [1.0.0] - 2026-10-26

### 新增

- 建立个人 Skill 公开化的完整流程编排：设计预检、三层分层与配置合同、个人经验剥离、版本与索引同步、发布前门禁、独立复审、发布执行授权边界。
- 沉淀三个实际公开化案例（magpie-optimizer、slides、self-evolve）的共性阶段、差异机制、共通踩坑与 53 项分阶段检查清单，作为执行与独立复审的检查范围。
- 明确单源自用公开同源、ignore 不解除已跟踪、版本控制与发布包双通道防护、静态检查是下界、对外动作逐级授权五条共同约束。
- 隐私检测采用通用模式而非私有名单思路，配套泛指豁免、登记表豁免、报告不回显原文与退出码合同。
- 私仓到公仓迁移默认清洁历史；禁止改 remote 直推；发布后对公开树重跑同一门禁并核实际加载入口。

### 修复

- 复用会话已有授权；明确维护原件同目录本地 ignore、通用结论进 references，Skill 内不创建 README。
- 发布验收绑定真实 Git 导出树和目标仓库各级忽略规则，补语义隐私与历史泄露复查及分阶段依赖说明。
- 个人统计、可关联会话的标识与真实产物哈希保留在私有层；公开示例使用合成数据，不以部分遮罩或派生比例替代隐私剥离。
