# Changelog

## [1.1.0] - 2026-10-27

### 新增

- 区分「实现份数」与「权威仓库」两个正交轴：单源约束只规定一份可编辑源码，公开化还需单独裁决公仓目录是权威源还是导出快照；导出快照必须记录来源 OID / manifest 与同步方向，且公仓目录禁止独立改实现。
- 新增能力适用表：隔离安装与首次配置后，仅验证候选实际具备的本地配置、持久化、只读扫描、报告与调度能力；缺失能力记不适用，适用未验项保留 `NOT_VERIFIED`。
- 结构校验前先对齐目标仓发布字段规范与 skill-lint frontmatter 政策；通用 `quick_validate` 与项目合法 frontmatter 不兼容时记录 NOT_VERIFIED，不修改目标 Skill 迎合不匹配工具。
- 派生统计按来源判断：私人会话与实际预算等运行统计保留本地；公开候选元数据、功能规模与合成测试数量有依据时可以披露。
- 公开允许清单须服从用户已确认的完整功能合同：个人硬编码改为本地配置，不能用排除旧功能或另做精简包规避整改。
- 前向检查覆盖演示后续命令的数据根隔离与进程退出后的保留/清理承诺；可选依赖回归与无依赖主链分别结算。
- 收紧完成判定：NOT_VERIFIED 只覆盖不适用项与非阻断兼容性缺口；关键门禁未执行时公开化整理阶段保持未完成。
- 案例检查清单由 53 项增至 59 项：补权威仓库与同步责任、派生统计口径、完整功能合同及演示隔离检查；1.0.0 条目的 53 项保留当时口径。

## [1.0.0] - 2026-10-26

### 新增

- 建立个人 Skill 公开化的完整流程编排：设计预检、三层分层与配置合同、个人经验剥离、版本与索引同步、发布前门禁、独立复审、发布执行授权边界。
- 沉淀三个实际公开化案例（magpie-optimizer、slides、self-evolve）的共性阶段、差异机制、共通踩坑与 53 项分阶段检查清单，作为执行与独立复审的检查范围。
- 明确单源自用公开同源、ignore 不解除已跟踪、版本控制与发布包双通道防护、静态检查是下界、对外动作逐级授权五条共同约束。
- 隐私检测采用通用模式而非私有名单思路，配套泛指豁免、登记表豁免、报告不回显原文与退出码合同。
- 私仓到公仓迁移默认清洁历史；禁止改 remote 直推；发布后对公开树重跑同一门禁并核实际加载入口。

### 修复

- 复用会话已有授权；明确维护原件同目录本地 ignore、通用结论进 references，Skill 内不创建 README。
- 发布验收绑定真实 Git 导出树和目标仓库各级忽略规则，补语义隐私与历史泄露复查及分阶段依赖说明。
- 个人统计、可关联会话的标识与真实产物哈希保留在私有层；公开示例使用合成数据，不以部分遮罩或派生比例替代隐私剥离。
