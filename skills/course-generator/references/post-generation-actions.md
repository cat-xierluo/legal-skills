# 课程生成后的操作

本文件只在用户明确要求归档既有课程，或从已验证课程提取培训方案时读取。生成完成不自动触发这些操作。

## 归档课程

1. 读取课程 manifest；没有 manifest 的旧课程标记为 legacy，不声称通过当前细粒度验证。
2. 从用户材料确认培训实际日期、正式课名、归档根目录和主办方写法，不用生成日期冒充举办日期。
3. 默认复制；只有用户明确要求“移动”时才移走源文件。
4. 目标已存在时不覆盖，使用新版本目录或请用户决定。
5. 复制后在目标目录重跑验证；源、目标文件集合或哈希不一致时归档失败。
6. 只有知识库索引属于本次范围时才更新索引。

## 提取培训方案

读取 [extract_prompt.md](extract_prompt.md)，按“解析需求 → 匹配课程 → 定位已验证素材 → 提取重组 → 输出方案”推进。

需求至少包含受众、基础水平、培训时长和重点方向。优先使用带 manifest 的课程并沿 source refs 追踪素材；只有原始转录稿时先完成课程生成。既有材料覆盖不了的主题标记“需补充素材”，不得凭空补课。
