# 文章候选模板

文章候选应从多个已脱敏 session 的共同方法论出发，不把单次对话复述成文章。

```markdown
# <标题>

## 文章机会

- 核心问题：<读者面对的可复用问题>
- 目标读者：<角色>
- 证据范围：`<evidence-id 列表>`
- 隐私状态：`passed`

## 结论先行

<一句可验证的主张，不包含案件或客户身份信息。>

## 背景与失败模式

<说明问题为什么反复发生，以及旧做法的局限。>

## 可复用工作流

1. <步骤>
2. <步骤>
3. <验证>

## 适用边界

- 适用：<场景>
- 不适用：<场景>
- 待人工核实：<事实或结论>

## 发布前检查

- [ ] 不含真实路径、身份、案件、联系方式或密钥
- [ ] 示例已合成或脱敏
- [ ] 事实与工具能力已经复核
- [ ] 用户已决定是否采用和发布
```

文章候选进入 proposal 生命周期；机器生成不等于用户同意发布。
