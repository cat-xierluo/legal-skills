# CHANGELOG

## [1.0.0] - 2026-09-20

### 新增

- 初版发布：法律 AI 课程录音转写文字稿 → 结构化书面讲义 Markdown 的整理技能
- 核心工作流七步：预检输入 → 通读识别结构 → 拟大纲（长稿先确认）→ 口语转书面 → 专业内容核对 → 按模板生成讲义 → 校验交付
- `references/polishing-guide.md`：删/改/留三类操作边界细则，含术语专名处理、回溯定位规则、多人发言处理
- `references/lecture-notes-template.md`：讲义 Markdown 模板，含课程信息头、答疑精选、附录三清单（工具资源/法条索引/待核实）
- 六条核心原则：忠实原意不创作、口语转书面尺度、引用可回溯、不确定即标注、缺失信息显式标注、敏感信息提醒
- `.skill-metadata.yaml`：三个推荐查询（标准整理、长稿先出大纲、金句与答疑精选）

### 技术优化

- 纯文本整理流程，零外部依赖，开箱即用
- 与 `lecture-review` 明确边界：本 skill 做内容整理（口语→书面），讲授表现复盘归 `lecture-review`
