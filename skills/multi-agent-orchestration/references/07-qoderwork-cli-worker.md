2026-09-30 用户决定删除 QoderWork、保留 CodeBuddy。`qoderwork`、`qoderwork-cn` 不再是可派发 backend；旧 QoderWork.app 中的 `qoderclicn` 不可冒充独立 Qoder CN CLI。

独立 Qoder CN 的入口与验证边界见 [26-optional-cli-backends.md](26-optional-cli-backends.md)。千问办公同名 bundled CLI 见 [27-qwenwork-cli-worker.md](27-qwenwork-cli-worker.md)。本文件只保留旧链接的迁移说明，不包含可执行 QoderWork 启动配方。历史实现记录保留在 CHANGELOG/DECISIONS，不作为当前权限依据。
