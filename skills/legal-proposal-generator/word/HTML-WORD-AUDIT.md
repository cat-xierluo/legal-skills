# HTML → Word 版式审查与修复记录

日期：2026-09-27 · 版本：1.0.0

## 结论与直接入口

旧版没有充分落地 HTML 设计。此次已重新生成四款 Word 模板、四份完整匿名成品和资质页示例，并提供 [三栏视觉对照](previews/index.html)。正文、表格、封面文字和附页文字仍可编辑；几何装饰采用不含文字的底图。

主要结构和装饰已迁入，但不能认定 HTML 与 Word 完全一致。字体字重、标题边线延伸、图片裁切、自动分页及复杂图表仍有下述边界。

## 差距、根因与处理

| 模块 | 旧版问题与来源 | 本次处理 |
|---|---|---|
| 比对基准 | 上次使用 WeasyPrint 回退结果，C 信息区约 186mm 的结论错误；designer 另有未实际加载的模板副本 | 以 `scripts/render.py` 实际加载的 `references/proposal-template.html`、`references/cover-variants/` 为基准，在 Chromium 中渲染完整 HTML |
| C 封面 | 三栏信息和页底定位偏差 | 信息区上边线校准至约 231.5mm；顶部色带 95mm，页脚区从约 273mm 开始 |
| D 封面 | 斜切比例、装饰圆与底部信息区有偏差 | 统一整页几何底图，信息线约 258.3mm；标题区按 HTML 位置重建 |
| E 封面 | 顶部标签过高，底色带没有延伸到纸张底边，圆形装饰位置不对 | 顶部标签约 24mm；底色带从 223.5mm 延伸至 297mm，重建双圆与浅色文字 |
| F 封面 | 网格侧边不连续，底线约 249mm，装饰方块有偏移 | 连续边线约 22–275mm，底线约 274.7mm，方块与信息区按参考重新定位 |
| 页码 | 只有当前页，缺少正文总页数；封面与附页计数边界不清晰 | 正文独立分节，从 1 开始；`PAGE` + `PAGEREF ProposalBodyEnd` 显示 N/M，附页保留页名；打开或修改后更新域 |
| 正文 | 重复标题；图片被固定行高裁切；相邻表格在 Word 中被合成一张表，引文缩到首列 | 去除重复标题，图片段落自动行高；相邻表格间插入分隔段；末段与落款增加同页约束 |
| 团队 | 卡片左竖线缺失，头像尺寸与位置偏差 | 首卡约 47mm，奶油底、左线、图文双栏，头像按 3.2×4.2cm 边界等比显示 |
| 案例 | 图片偏小，缺少介绍卡和浅底框；多于四张会遗漏 | 恢复介绍卡、双列框与间距，图片上限 7.15×7.8cm；每四张续页 |
| 律所 | 左线缺失，介绍被截断，图文顺序丢失 | 保留全部段落与图文顺序；浅底、左线及图片比例恢复。HTML 自身只取前两段并调整图片位置，Word 不复现这项内容丢失 |
| 荣誉 | 星形圆章变为数字，多于六项会遗漏 | 恢复 9mm 星形徽章与细分隔线；每六项续页 |
| 资质与图表 | 原生 HTML/SVG 无法直接进入现有 Word 解析器 | 增加本地 PNG/JPEG 与律师、律所资质专页；不支持的原生 HTML/SVG/Mermaid 明确报错，先导出为图片再引用 |
| 模板填充 | TEAM1 等图片前缀识别错误，填字段后相邻字号、字重丢失 | 按图片槽位限宽高并等比放置，跨 run 替换只修改匹配范围 |
| 交付路径 | 修改脚本不代表旧 DOCX 已重建；嵌套模板目录还被通用 Git 忽略规则排除 | `build-samples.js` 同步生成模板和匿名成品；增加本地忽略例外，固定预览入口及文件链接 |

## 仍有差异，以及后续调整方式

1. **字形和正文分页**：默认 `Songti SC` / `Times New Roman`，不同字体及 Word/WPS 引擎会改变字重、字距和分页。跨平台先安装一致字体或指定 `--font`，再在最终客户端更新域并导出。若要固定发送效果，使用验收后的 PDF。
2. **段落边线**：Word 标题左线会随段前段后间距延伸，长度与 CSS 不完全一致。当前保留可编辑标题和自然分页；追求精确视觉可另做固定版设计稿。
3. **图片和装饰**：图片采用等比完整显示，HTML 的 `object-fit: cover`、圆角、阴影不逐像素复制。几何底图可换色或重建，但不能在 Word 中逐个编辑圆形、斜切及网格。
4. **长标题与大篇幅附页**：`render.js` 会计算最多三行的封面标题；直接填固定 token 模板不会重算浮动锚点，长标题应走脚本生成或手工复核。超长简介、单项超长荣誉等仍需检查跨页。
5. **复杂图解**：SVG/Mermaid 图表保留为图片，不具有 Word 原生图元编辑能力。复杂设计继续由 designer 承担。
6. **客户端范围**：D/E/F 和资质专页的 Microsoft Word 实机、全部 WPS 实机为 `NOT_VERIFIED`。本次没有三轮独立 Agent 产出和签名稳定性证据，不能声称任意内容、多轮或跨客户端都不会漂移。
