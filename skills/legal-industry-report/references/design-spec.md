# 双产品视觉规范

## 两种界面，不共用阅读节奏

| `report_kind` | 视觉隐喻 | 章节策略 | 适合场景 | 合法封面 |
|---|---|---|---|---|
| `report` | 机构研究出版物 | 正式章节从新页开始，宽松留白 | 月度/季度公开报告、下载与长期留存 | `C-geo` / `D-diagonal` / `E-flip` / `F-grid` |
| `brief` | 客户信号快报 | 封面后连续流，短节之间不强制换页 | 每日/每周触达、移动阅读与渠道改写 | `W1-minimal` / `W2-tag-bar` |

类型与封面不匹配时必须回退到该类型默认封面。两者共享品牌色和渲染工具，不共享信息密度。

## 行业报告

- 封面强调系列、标题、报告编号和日期，形成可长期识别的出版物。
- 目录只列可靠章节，不在浏览器最终分页前伪造页码。
- 章节使用 `RESEARCH NOTE 01` 等小标签和清晰标题；每个主章从新页开始。
- 正文使用衬线中文、较宽行距和克制强调色；表格优先呈现口径与证据。
- 不用大面积渐变、发光、卡片堆叠或装饰性仪表盘。

## 客户简报

- 封面突出受众、信息窗口和频率，不再使用“第 N 期”作为唯一身份。
- 封面后正文使用连续流；章节以细分隔线与 `SIGNAL 01` 标记，避免每节一页产生大片空白。
- 正文默认不首行缩进，表格和引用块更紧凑，适合快速扫描。
- 元数据接在正文之后自然排版，空间不足时跨页，不为少量信息单独制造一页。
- 朋友圈与公众号模板属于内容界面：标题、导语、要点与行动提示均需在移动端一次读懂。
- 视觉紧凑不等于减少信源、免责声明或事实边界。

## 页面与技术约束

- 最终 PDF 固定 A4，页尺寸误差不超过 1pt。
- 封面使用独立 `@page cover`，无页眉页脚；正文页眉仅显示报告编号，页脚仅显示页码。
- 长内容自然跨页，不使用固定正文高度或 `overflow: hidden`。
- 表头可跨页重复，单行尽量不拆；不得为凑页数裁切内容。
- report 默认正文 11pt/1.95；brief 默认 10.5pt/1.72。

## 最终视觉验收

模板、封面、分页或渲染器变化后：

1. 分别生成一份信息充足的 `report` 与 `brief` PDF。
2. 检查页数非零、全部 A4、封面类型和报告编号正确。
3. 将全部页面渲染为 PNG 联系表，检查裁切、重叠、乱码、异常空白、孤行和表格断裂。
4. 特别确认 brief 不再“一节一页”，report 仍保留正式章节节奏。
5. 最终 PDF 与 Markdown 事实不一致时，以修复渲染链为先，不用 HTML 截图代替验收。
