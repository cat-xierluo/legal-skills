# UI 截图装裱规范

> "保真优先 + 7 参数 + 背景托底"三件套,法律 deck 化。法律培训高频演示 Skill 界面(Agent 工作台、法律检索平台、法律 AI 产品、ChatBot 对话框、检索结果),**截图质量直接决定说服力**——而 slides 现有 references 完全没覆盖截图装裱(§5 照片比例只管头像/培训照片)。
>
> 与法律气质的一致点:**法律 UI 截图是证据,不是配图**——保真优先,绝不 AI 重绘内容。

## 1. 保真铁律

- **程序化装裱优先**:截图内容、文字、UI 细节需要保真时,**不要重画**。创建目标比例画布,把原截图等比缩放后放入。
- **禁止 AI 重绘截图内容**(界面文字、按钮、数据)。法律演示若重绘界面 = 伪造证据,严肃性归零。
- 默认**不裁剪**截图内容;只有截图已按目标槽位重新生成、或用户明确允许裁切时,才用 `cover`。带文字的 UI 截图一律 `object-fit:contain`。

## 2. 装裱 7 参数

先定 slide 版式和图片槽位比例,**再**决定装裱参数(ratio 跟随槽位,不跟随原图):

| 参数 | 取值 | 法律黑金收窄 |
|---|---|---|
| `ratio` | 21:9 / 16:10 / 4:3 / 1:1 | 跟随槽位;多图同组必须同 ratio |
| `background` | plain / gradient / blurred / grid / paper | **plain(ink 深底) / paper(浅底) / grid 细网格**;不用抢眼渐变 |
| `padding` | compact / standard / spacious | 多用 standard |
| `inset` | none / subtle / balanced | balanced(截图与容器边留呼吸) |
| `shadow` | none / soft / editorial | soft(柔和投影,显层次不抢主) |
| `corners` | square / small / medium | small(与 deck 圆角食谱一致,忌直角/大圆角) |
| `alignment` | center / top-left / ... | 跟随版式落位 |

### 法律 deck 推荐预设

- **深底页截图**(演示 Skill 在 dark slide 上):`ratio:16:10, background:plain(ink), padding:standard, inset:balanced, shadow:soft, corners:small, alignment:center`
- **浅底页截图**(light slide 配图):`background:paper`,其余同上
- **多图截图墙**(并列展示多个 Skill 界面):全组同 ratio(16:10 或 4:3)、同 height、同裁切方式(全 contain),吸附卡片网格,不让原图比例反向决定版式

## 3. 背景托底三原则

截图加背景时,背景是"**托底**",不是主视觉:

- [ ] 背景不比截图本身更抢眼(深底页用近 ink 纯色,不用金色渐变/纹理)
- [ ] 截图落位方向(居中/左上/右下)的那一侧背景安静,无强色块
- [ ] 背景无文字/logo/图标/人物/设备/边框/明显主体/方向性构图
- [ ] 背景 **crop-safe**:裁成 16:10 / 4:3 / 1:1 都不露"被裁掉"的痕迹(中心与四角都安静)

## 4. 脱敏(法律场景必做)

截图入 deck 前先隐藏/打码:

- 账号、头像、用户名、内部 ID
- **当事人姓名、案号、当事人手机号/身份证、客户单位**(与 cn-deck-polish 的脱敏字段一致)
- 内部联系方式、内部系统水印

> 内部系统截图尤其注意:真实案件/客户数据不能入对外 deck。宁可花分钟脱敏,不要带真信息上场。

## 5. 槽位先行

- **先定 slide 版式**(全宽大图 / 左文右图 / 多图网格),再选 ratio 和截图,**不要先生成/截图再硬塞进页面**。
- 一张 UI 长图被拉成巨长条 → 拆成 2–3 张同尺寸局部面板,各配一句小标题,而不是一张长图占满整页。
- 同一组截图(如"四个 Skill 界面对比")必须**同比例、同视觉缩放、同边距密度**,吸附同一卡片网格。
