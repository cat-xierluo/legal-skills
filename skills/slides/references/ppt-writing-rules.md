# PPT 对外方案与排版原则

法定对外交付物(培训课件 / 对外方案 / 客户报告 / Skill 推广稿)的通则。下笔前先扫一遍,**避免逐次纠正**。本文件是该 skill 的硬规则层。

沉淀缘由: 多轮真实授课课件反复出现的通病(语气 AI 化 / 焦虑话术 / 时间表混入 PPT / chrome 冗余),用户明确要求不要每次纠正——沉淀为本文件供后续 PPT 工作遵循。

## 五条硬规则(必修)

### 1. 不打钟点表
PPT chrome / kicker 不写 "X 点 X 分" / "9:00-12:00" / "第一个小时后休息十几分钟" 等钟点流程。

**合法的**:
- "Section X · 15 分钟" — 讲课节奏标注,非钟点
- productivity 对比里的时长("300 页合同 3 小时→15 分钟")— 案例数据

### 2. chrome / 页脚精简
不堆叠"受众 N=195" / 总时长(小时/分钟) / "含茶歇" / 课时起止。默认主题名 + 页码就够,需要再加一句副标题。沿用克制版式的课件就是这个低冗余基调。

### 3. 该分块就分块,绝不偷懒堆文字
并列点 / 步骤 / 对比 / 分类,务必用 `split` / `pillar` / `pipeline` / `grid-2/3` / `callout` / 步骤卡 等组件,**绝不**裸 6+ 个 div 平铺。

**历史教训**: `.pipeline > .step` 组件仅"顶边线+文字"等同文字墙;务必卡化(背景+边框+padding)+ 强编号徽章 + 可选 `.step::after` 箭头连线。详见 `references/layout-theme-playbook.md`。

### 4. 不传播焦虑 / 不审判受众
禁用"被淘汰" / "不 X 就 out" / "末班车" / "被时代抛弃" / "生死存亡" 等 FOMO / 审判式话术。

**替代表**:

| 禁用 (焦虑 / FOMO / 审判) | 替代 (事实 / 趋势 / 选择) |
|---|---|
| "拒绝 AI 的人会被淘汰" | "会用 AI 的人,效率会拉开差距" / "这是正在发生的事实,不是预测" |
| "不学 X 就 out 了" | "X 是新工具,会的人先享受效率红利" |
| "落伍者 / 落后于时代" | "晚用的人需要追赶,这就是差距" |
| "末班车" | "窗口期还在,趁现在上手最快" |
| "你不用就会被取代" | "你用了,产能结构会变" |
| "被时代抛弃" | "这是新工具,取舍在自己" |

**法律人受众(尤其检察官)最敏感被审判**。焦虑话术短期打鸡血,长期反噬信任。

### 5. 语气去 AI 化
**写作心法**: 写"律师/律师助理跟同事说话"的口吻,不是"模型在教用户"。

**禁用模式**:

| 禁用 (AI 化) | 替代 (同行口吻) |
|---|---|
| "Certainly!" / "Sure!" / "I'd be happy to..." | (删) |
| "希望对您有帮助" / "如果需要的话" | (删) |
| "It's worth noting..." / "Needless to say..." | (删,事件本身已说明) |
| "首先...其次...最后..." 空列举 | 写一段连贯叙述;真并列才用列点 |
| "此外" / "另外" (装饰过渡) | 用动作或结论承接 |
| "具体来说" / "也就是" (同义反复) | (删) |
| 📌✅🎯💡 emoji 堆砌 | 限 0-1/页,或不用 |

## 自查清单(交付前 5 分钟跑一遍)
- [ ] 钟点表 / 时间流程 → 0
- [ ] chrome / 页脚冗余信息 → 0
- [ ] "被淘汰" / "out" / FOMO → 0
- [ ] 6+ 平铺 div / 裸 bullet → 改 split 或 grid 卡
- [ ] AI 化套话 ("希望" / "Certainly" / "此外") → 0
- [ ] kicker / hero / chrome 装饰 emoji 堆砌 → 0
