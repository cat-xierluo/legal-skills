# 用页内动效讲清关系

当某页需要讲清过程、依赖、视角切换或操作反馈时使用。动态背景、入场和页间转场按[浏览器演示指南](browser-guide.md)处理。普通阅读、引用、总结页可维持静态。

## 先决定观众要看懂什么

在已有大纲或讲者备注记下：原页怎样讲、观众容易误读哪里、哪些对象保持不变、哪一步发生变化、哪个结果要停住、哪些限定始终可见。旧稿已经讲清的地方沿用。动画应让观众少做一次推断，例如看见 A 与 C 同启、两个产出齐备后 D 才开工。按原顺序把卡片淡入，通常没有这个作用。

| 要讲清的关系 | 可试的表达 | 保留的线索 |
|---|---|---|
| 材料变成结果或方法 | 同一个标签、文件或数据点随讲解移动；在目标区域形成真实可见的结果 | 输入身份、去向、原件是否保留 |
| 并行、等待、汇合 | 用泳道和连线呈现实际依赖；条件满足后才更新下游状态 | 独立分支、闸门、产出；无实际工时就不让长度表示工时 |
| 同一输入下的不同立场 | 把共同输入固定在视野内，切换关注的证据、字段或输出 | 对照双方、精确范围和必要例外 |
| 操作与反馈 | 复用页面片段、编辑器、终端或本地组件；做出真实结果面板 | 操作对象、选择或提交的区别；模拟画面注明示意 |

正文、标签、控件优先用语义 HTML 与 CSS；路径、标记或矢量变形可用内联 SVG。画面复杂时才考虑 Canvas 等，并提供可读静态正文。关键关系先试一个真实页面，比较同一投屏尺寸的静态原页、变化中段和定格结果；可直接读懂的页面保持安静。应用文章配图的对象连续性、可读停留和按内容选画法；演讲不要求 SMIL、固定秒数、循环播放或每页动起来。

## 让动效成为原页的一部分

沿用原页题目、字体、视线入口与结论位置。把场景嵌进现有正文区域，或者让原元素就地改变；避免再套一组标题、导语、整屏底板、总结条和页内播放器。若观众必须先读懂嵌套层级才能理解演示，退回原页结构再排。

借鉴成熟配图时，先看它把注意力放在哪里：像文件树与编辑区联动、条款和批注同屏、任务状态原位更新，或采用记录把「确认」和「有效」分开。每块界面都要对应对象、归属或状态。读者只需看关系时，保留简洁图解；要看操作时才保留定位所需的真实控件或标为示意的界面。质感来自可读的层级、对齐、对象纹理和局部动势，别用统一卡片、窗口外壳或重效果抹平差异。

## 接入已有演示

- 讲者触发关键变化，结果保持到下一次输入。演示控制默认归宿主：把步数、上一步、下一步和重置并到已有放映 HUD（例如与滚轮、静态、大纲同在右下角）。只有演示真实操作需要的控件才留在内容里。普通页无这组控件；为 HUD 留出安全区，导出和大纲时隐藏它。若空格先推进页内步骤，末步才交回翻页；给在焦点中的按钮保留原生空格行为，并限制长按连跳。跳页后显式重置或恢复到确定状态；离页停绘。
- 把场景局限在当前页。每页只有一个 slide 容器，场景内部优先用 `div`、`article` 或 `figure`，避免旧转换器把嵌套的 `section` 计成新页。动态增强成功前，原静态正文应可读。大纲缩略图使用静态正文；克隆 slide 时移除演示实例及重复 ID。已有静态开关可复用，另支持 `prefers-reduced-motion` 下只切状态，不移动。第三方组件应支持离线带走静态数据或资源。
- 可选用[页内步骤控制](../assets/slide-steps.js)：宿主统一控制时用 `SlidesSteps.mount(root, { stepCount })`，用返回的 `go(index)`、`index` 和 `last` 驱动外部 HUD；同页确实需要本地控制时，可用连续的 `data-step-to="0"` 等按钮选步骤，`data-step-by="1"` 或 `"-1"` 走相邻步骤，`data-step-note="0"` 写本步提示。组件监听 `slides:step` 或用 `root.dataset.step` 更新画面；程序化切换用 `go(index)`。宿主在场景可用时调用 `handleKey(event)`，根据返回值决定是否交还导航。该脚本不决定页序、动画样式或宿主键位。
- [两份资料如何汇总](templates/motion-example.html) 是可运行的合成小样。业务状态在画面内更新，步进按钮在右下角，静态正文仍可读；用于参考接法，不用作各主题的固定版式。交付自包含 HTML 时内联选用脚本和样式，或将本地依赖放入随件目录并复核移动后打开。

## 静态交付

静态页应独立解释主要关系和必要条件。现有 deck 的原正文已经合用时直接复用；新稿可用汇总态或少量定格帧。用 CSS 显式控制：无 JS 时静态正文默认显示，运行时才启动页内场景；根元素有 `data-slides-static-export`、`body.exporting` 或 `@media print` 时强制显示静态正文和隐藏播放器。此标记不改变动态背景冻结策略。

本技能的本地 PPTX/PDF 转换及两条截图型 PDF 路径会在测量或截图前设置根元素 `data-slides-static-export`。自建转换器或手工接入 Presentations Runtime 时，要在提取 DOM 前显式设置此标记并核对结果。PPTX/PDF 不继承 HTML 的步进；需要静态文件呈现每一步时把关键状态编成独立页。

## 验收

1. 用实际尺寸浏览：初态、运动中途、各停留态都不能有文字、连线、节点或控件互遮；核对右下放映组件与页脚、导航和正文之间的间距。判断动作是否比静态基线更容易解读；失败时优先重做关系表达或沿用静态。
2. 用键盘和点击走一遍开始、前进、回退、重播、跳页、静态返回；断言结果、阻塞和限定真的变化或保留。检查脱网、减少动态，以及脚本关闭时仍有正文。没有验证过的宿主或模式不宣称支持。
3. 真有 PPTX/PDF 交付时打开成品，核分页、静态正文与条件、控制条未进入输出；可编辑 PPTX 检查至少一页的原生文本。没有导出的格式仅陈述后备机制，不承诺最终文件已验。
