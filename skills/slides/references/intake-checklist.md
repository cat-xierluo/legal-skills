# 动手前 intake 清单

> slides 面向培训 / 讲座 / 汇报类固定画布 deck。多数字段已有稳定默认,**不要每次问用户**——只在用户没给齐关键输入时,按需启动以下确认。
>
> 触发条件:**用户输入里已经有完整「主题 + 讲义/转录稿/案例素材 + 时长」** → 直接进 layout-theme-playbook 选版生成,**不走这张清单**。只有信息不全时才走。

## 0. 默认从哪来

分两层,**不要混用**:

**通用默认**（技能内置，对所有使用者成立）：

| 字段 | 默认 | 来源 |
|---|---|---|
| 画布 | 固定 1280×720 + `--s` 等比缩放 | slides 定位(非流式 vw/vh) |
| 版式库 | 12 个页面类型模板 + `_base.css` 设计系统 | references/templates/ |
| 字号下限 | 正文 18 / 卡片 16 / meta 14（投屏严要求） | style-reference §8.1 |
| 节奏 | 8 页以上 deck 必含 ≥1 深 + ≥1 浅 hero，连续同主题 ≤3 页 | cn-deck-polish §11 |
| 多样性 | 8 页以上 deck 至少 5 个版式家族，禁止连续 3 页同结构 | layout-theme-playbook §7 |
| 禁项 | 禁编造百分比/评分、禁 AI 重绘 UI 截图、禁大色块白字 | layout-theme-playbook §8 + style-reference §8.8 + screenshot-framing §1 |
| 溢出 | 内容必须装进 720，改页前先估高、验证只认 DOM 几何 | cn-deck-polish §14 / §21 |

**个人默认**（来自本地配置，见 [configuration.md](configuration.md)，没有配置时不启用）：

| 字段 | 配置键 |
|---|---|
| 默认风格 / 主题色 / 字体栈 | `brand.style`、`brand.custom_style_file`、`presentation.font_families` |
| 页脚文本与样式 | `brand.footer_text`、`brand.footer_style` |
| 是否生成介绍页 / 几页 | `presentation.show_profile`、`presentation.intro_pages` |
| 头像 / 二维码 / 现场照片及其开关 | `assets.*` + `presentation.show_*` |
| 收尾形态 | `presentation.closing_mode` |
| 受众与术语深度偏好、写作补充 | `preferences_file` |

> 头像 / 二维码 / 字体等私有素材走配置路径；**匿名默认下不生成身份页，也不内联任何素材**（详见 configuration.md §3、§5）。
> 用户说"按上次那样""按 xxx 那场""直接出"等,视为默认沿用,不要逐项确认。

## 1. 触发走清单:用户输入不齐时,才问的 4 项

下列 4 项**每次 deck 都不一样**,无法默认,信息不全时必须问(用 AskUserQuestion 一题一项,4 题为上限,每题给推荐答案):

| # | 问题 | 用户答 → 我怎么用 |
|---|---|---|
| 1 | **时长/场合** | "15min 讲座 / 半天 / 全天" → 套 §时长→页数表定总页数;决定是否带演示链/手搓页 |
| 2 | **原始素材** | "讲义/转录稿/案例库/旧 deck/无" → 有就给稿走抽取改写;无则按 `references/research/` 框架从主题做大纲 |
| 3 | **本次必讲的知识点** | "至少包含 A/B/C,不能漏" → 锁入叙事骨架主体段,逐条对应 |
| 4 | **禁言/脱敏字段** | "不能出现当事人 X/案号 Y/客户 Z" + "截图必须隐藏账号/内部水印" | 入 deck 前逐张过;强约束 case-specific,无法默认 |

> 不在以上 4 项的(主题怎么切、用什么示例、怎么开场收尾、是否加 ASCII 背景等),**由 slides 内部判断**——按 layout-theme-playbook 选版、按 icon-system 选 icon、按 cn-deck-polish 去冗余。

## 2. 时长 → 页数映射(用得着时查)

固定 1280×720 browser-deck,每页主讲约 1.5–2 min(含停顿/互动/演示):

| 时长 | 页数(含封面/分节/收尾) | 节奏 |
|---|---|---|
| 15 min(主题讲座 L1) | 8–10 页 | 1 hero + 6–8 内容 + 收尾 |
| 30 min(短分享) | 16–20 页 | 含 1–2 分节 hero |
| 45 min(标准培训) | 25–30 页 | 含 2–3 分节 hero + 互动页 |
| 2–2.5h(半天 L2) | 38–45 页 | 多分节 + 演示链 + 行动路径 |
| 全天(L3) | 60+ 页 | 分上下半场,各含手搓环节 |

> 内容基线每页 2 min;多出的时间讲师现场把控(扩演示/互动/答疑),**不强制把页数填满时长**——宁可内容扎实、节奏由人,不要为凑时长灌水页。

## 3. 走清单的时机(快速判断)

```
用户输入:主题 + 讲义/转录稿 + 时长 + 必含点(任意形式)
  ↓ 都齐了
直接进 layout-theme-playbook 选版 + icon-system 选 icon + 生成 HTML
(草稿出来后,逐条对照 cn-deck-polish 19 条 + 数据真实性 gate)

  ↓ 缺时长或场合 → 问 §1.1
  ↓ 缺素材或旧 deck → 问 §1.2
  ↓ 有"必须讲 A/B/C" → 问 §1.3
  ↓ 有"禁言 X" → 问 §1.4
```

**最多 4 问,每问给 2-3 个推荐答案**(不臆测、不替用户编造约束)。问完即生成,不要再来回。
