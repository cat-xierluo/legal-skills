## 使用方法

本清单只帮助召回疑似问题，不能直接决定修改。每个 finding 先记录：

```text
discourse_role：事实 / 定义 / 判断 / 机制 / 例子 / 边界 / 过渡 / 小结
pollution_type：七类之一
evidence：问题来自词面、频次、段落功能还是上下文
operation：删除 / 合并 / 直接陈述 / 补足对象 / 恢复结构 / 基于材料重建
```

命中词表但功能成立时保留；没有命中词表但用形式代替内容时仍应报告。

## 七类污染

| 类型 | 识别问题 | 优先处理 |
|---|---|---|
| 姿态污染 | 是否在评价自己、提醒读者、讨好或表演坦诚？ | 删除姿态，留下事实、判断或边界 |
| 模板污染 | 是否用固定句式替代真实逻辑？ | 改为定义、条件、因果、场景或显式列举 |
| 语义稀释 | 是否用程度词、大词和模糊频次冲淡信息？ | 补对象、条件、范围和后果 |
| 节奏污染 | 是否用短句、对仗、排比和断句制造机器节拍？ | 回到段落功能；保护功能性平行 |
| 概念污染 | 是否借黑话、隐喻或术语制造高级感？ | 改普通表达，必要术语说明边界 |
| 过程泄漏 | 是否把模型、调研、协作或编辑状态暴露给读者？ | 正文只留可确认事实和作者判断 |
| 格式污染 | 是否用粗体、引用块、列表或引号替代论证？ | 还原为正文、合法清单或真实引用 |

## 高风险模式家族

### 1. 对比、宣言与假转折

重点复核：

- `不是 X，而是 Y`、`并非 X，而是 Y`；
- `问题不在 X，而在 Y`、`不在于 X，在于 Y`；
- `看似 X，实则 Y`、`看起来 X，其实 Y`；
- `这不是 X。这是 Y。`、独立加粗的`这是 X`；
- `表层 X / 深层 Y`、`低水平 X / 高水平 Y`；
- 短距离反复以`不是 / 不只是 / 不等于 / 不能`开句。

定义和边界偶发使用对比可以成立。问题在于它是否替代了正面定义，或被反复用来制造力度。

### 2. 框架提示与程式化过渡

重点复核：

- `首先、其次、此外、然而、综上所述、总而言之`；
- `下面我们从 N 个方面`、`本文将`、`让我们来看`；
- `值得注意的是`、`更重要的是`、`更麻烦的是`；
- `说到这里`、`回到开头`、`接下来`、`这也是为什么`；
- `你会发现`、`可以看到`、`答案就清楚了`。

步骤和真实层次可以使用连接词。只有当连接词代替逻辑时才处理。

### 3. 自我陈述与伪经验

重点复核：

- `我想强调 / 我想指出 / 我更愿意 / 我更倾向于`；
- `我发现 / 我意识到 / 我后来发现`，但没有对应经历或材料；
- `坦白说 / 说实话`只用于装亲近；
- `我们曾经`、`在实践中`、`从经验看`却没有可确认来源。

有作者证据时第一人称可以保留。没有证据时不要把它换成另一种第一人称。

### 4. 空泛评价、程度词与假排名

重点复核：

- `本质上、核心在于、真正、关键、重要`反复出现；
- `很具体、很现实、很朴素、很危险、很适合`但没有对象和后果；
- `越来越、往往、通常、经常、很容易、更容易`超过两次或缺少依据；
- `最典型、最容易、最危险、最重要`没有比较样本；
- 连续段落用不同排名词伪装同一列表。

这些词不是绝对禁用。一次准确的比较优于为了避词改成含混句。

### 5. 空泛意义拔高与黑话

重点复核：

- `深刻改变、重要意义、未来可期、方向已经明确`；
- `彰显、凸显、赋能、促进、增强、奠定基础`；
- `格局、生态、闭环、抓手、链路、颗粒度、叙事、信号`；
- `不可或缺、复杂性、错综复杂、关键转折点`；
- 工程隐喻：`喂给、直接消费、编译成、打包成`。

正式术语已有定义且全篇稳定使用时保留；普通概念不要靠术语抬高。

### 6. 强加口语、比喻和情绪

重点复核：

- `搞定、跑偏、很顺、入口顺滑、埋雷、反咬一口、漏水`；
- `扎心、震撼、刺痛、眼前一亮、最值钱`；
- 柴火、锅、乱麻、管道、端菜等生活比喻被重复复用；
- 为每个抽象概念都寻找一个画面；
- 源稿正式克制，改稿却突然大量称呼“你”。

口语和比喻只有在属于作者、适合语域并提高理解时才保留。

### 7. 工整排比、隐藏列表与固定节拍

重点复核：

- 三个以上`既要 / 又要 / 还要`；
- 三个以上`如何 / 怎样 / 能不能`；
- 三个以上相同虚词、被动式或动词开头；
- 连续三个以上单句段落承担相同功能；
- 每两三句固定插入短句点睛；
- 显式序号被替换成`最典型 / 最容易 / 也容易 / 类似的还有`。
- 一组分析例子被逐项扩写成“点名对象—解释风险—回到同一结论”的等长段落。

分类、步骤、责任分配和检查清单属于功能性列举，默认保护。仅用于共同证明一个判断的多个例子属于分析型例证，不因数量多而自动获得同样保护。详见 `references/expression-transformations.md`。

功能性列举仍需复核分类尺度：各项粒度不同、类别互相重叠，或两套“N 分法”只为数量对称而强行映射时，标记 `STRUCTURE_REVIEW`。这属于论证结构问题，不通过打散句式解决。

### 8. 同义循环与指代漂移

重点复核：

- 在短距离用`窄 / 小 / 平 / 浅 / 局限`反复表达同一判断；
- 同一对象轮换叫`系统 / 平台 / 工具 / 方案`；
- 为避免重复而改变术语，导致读者误以为对象已经变化；
- 不同句子只是换词重复上一个结论。

准确重复同一名称通常比同义词轮换更自然。

### 9. 换词后的重复语义骨架

重点复核：

- `AI 能／可以／擅长 X，但／却／仍不能 Y`；
- `工具提供 X，判断／经验／责任仍要由人完成`；
- 不同章节只替换任务名、限制词和人的角色，逻辑关系与段落功能不变；
- 同一能力边界既在节首预告、例子收束、节末总结和全文结尾反复出现，却没有增加条件、机制或后果。

一次定义或结论可以成立。后文若继续讨论同一边界，应改为解释缺少什么输入、几个安排如何相互影响、审查怎样进行或责任为什么不能转移，而不是继续换词复述。`scripts/semantic_repetition_gate.py` 只召回这一家族的明显候选，不替代通读。

### 10. 格式与过程残留

重点复核：

- 粗体宣言、引用块口号、表情符号；
- 普通词、动作和状态被大量加引号；
- 无序列表堆积观点而非呈现步骤或清单；
- `公开资料显示 / 多个来源 / 专家认为`却无具体出处；
- `截至我的训练更新 / 基于可用信息 / 适合进入本章`；
- `以上是 / 希望有帮助 / 请告诉我`等协作痕迹。
- `按源稿 / 源稿的导航仍保留 / 材料不足以相连`等编辑现场说明；
- `不是若干项检查任务 / 本轮扫描 / 候选外 / 交付正文`等对改写指令或评测规则的回应；
- `先承认一个前提`等不提供信息、只负责启动框架的句子。
- 为了躲避语义重复，把“能做 X，但还需 Y”改成“X 属于另一项工作／难点在于 Y／生成只对应 X”；
- `工具退场／走到边界，留下判断与责任`等把已重复结论压成传播金句的修复伪影。
- `换词重复 / 同功能段落 / 连续同构 / 能力边界候选 / 门禁阈值`等评测词泄漏；
- `AI 最危险／可怕／重要的时候，是……`等没有新增机制、只服务传播的短金句。
- `入口顺滑 / 更低的入口 / 低摩擦入口`等把具体启动成本换成抽象入口的同义逃逸。

图片行、真实引语、法条和代码等 Protected Spans 按主流程原样保护。

## 频次与位置复核

优先查看：

1. 标题与小标题；
2. 每节第一段和最后一段；
3. 加粗行、引用块和图片前后；
4. 连续单句段；
5. 列表前后的引导句；
6. 术语首次出现处；
7. 结尾的展望、姿态和金句。

`越来越、其实、往往、通常、很多时候、真正、不只是、更像、很容易、更容易`等词全文超过两次时必须复核，但频次本身不自动构成修改理由。

## 例外与假阳性

默认保留：

- 有明确修辞目的且次数有限的排比；
- 分类、步骤、职责、法条和合同条款的平行结构；
- 作者样本稳定使用且适合当前场景的口语；
- 有数据或明确比较对象支持的“最”；
- 定义边界所必需的否定和对比；
- 真实引语、专有名词、专业术语和固定格式。

禁止为追求“零命中”破坏准确性。一次合理保留要写明句子功能和保留理由。
