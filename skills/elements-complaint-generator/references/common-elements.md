# 通用要素层（common-elements）

> 证据基础：`scripts/verify_common_elements.py` 对 templates/ 全部 113 棵树做存在性 + 形态聚类（28 个签名组）。
> 本文档定义**跨案由可复用**的要素块、其覆盖范围与渲染规则；案由特定要素见 `case-types/NN-*.md`。

## 一、分层总览（按覆盖率排序）

| 层 | 要素块 | 覆盖 | 结论 |
|---|---|---|---|
| **L1 当事人-自然人** | 姓名/性别/出生日期/民族/工作单位/住所地/证件类型/证件号码 | 95-113/113 | **超通用**：起诉状/答辩状/申请书/自诉状全部承载 |
| **L2 当事人-法人** | 名称/法定代表人(负责人)/统一社会信用代码 | 82-103/113 | 通用（少数纯自然人案由与精简答辩状无） |
| **L3 委托诉讼代理人** | 姓名/单位/职务/电话/代理权限(一般□特别□) | 103-105/113 | 通用 |
| **L4 证据清单** | 证据清单指引行 | 98/113 | 近全量 |
| **L5 调解意愿** | 调解总述/先行调解好处×5/是否考虑先行调解 | 59-60/113 | **民事起诉状 + 民事答辩状子集**；行政/国赔/执行/刑事自诉无 |
| **L6 具状人落款** | 具状人（签字、盖章）：+ 日期 | 52/113 | 起诉状/自诉状族专用；答辩状/申请书用各自落款（答辩人/申请人，见 §四） |
| ✗ 案由特定 | 诉前保全(25)/约定管辖(20)/保全法院(28)/案号(29) | ≤29/113 | **不入通用层**，归案由层 |

## 二、L1 当事人-自然人（字段 + 渲染规则）

elements 结构（每案由 Schema 的 `当事人` 节共用此定义）：

```yaml
当事人:
  原告/被告/第三人/答辩人/申请人/被申请人:   # 角色名随文书类型变化，字段同构
    主体类型: 自然人|法人或非法人组织
    姓名: ""            # text-replace "姓名：" occurrence=角色序
    性别: 男|女          # make_gender_rule（按 男□/女□ 值勾选）
    出生日期: YYYY-MM-DD # fill_blanks("出生日期：","日") + fmt_date
    民族: ""            # text-replace "民族："
    工作单位: ""        # text-replace "工作单位："
    职务: ""            # text-replace "职务："
    联系电话: ""        # text-replace "联系电话："
    住所地: ""          # text-replace "住所地（户籍所在地）："
    经常居住地: ""      # text-replace "经常居住地："
    证件类型: ""        # text-replace "证件类型："
    证件号码: ""        # text-replace "证件号码："
```

**形态证据**：最大签名组（18 棵答辩状）内 姓名/性别/证件类型 均仅 1 种形态；出生日期+民族 2 种形态（17 棵同段"出生日期：…日 民族："、1 棵拆段）。**渲染规则可直接跨案由复用，occurrence 映射须逐树勘察**（用 `dump_template_fields.py` 生成）。

## 三、L5 调解意愿（仅民事起诉状/答辩状）

```yaml
对纠纷解决方式的意愿:
  是否了解调解: 了解|不了解                      # replace_option_check（防"了解□"⊂"不了解□"双勾）
  是否了解先行调解好处: [了解|不了解] × 5         # 按文档顺序 5 处；跳过已含 ☑ 的段
  是否考虑先行调解: 是|否|暂不确定                # "是☑ 否□" / "暂不确定…☑"
```

## 四、文书类型差异备忘（T3 路由表素材）

| 文书类型 | 当事人角色 | 落款 | 调解意愿 | 备注 |
|---|---|---|---|---|
| 民事起诉状 | 原告/被告/第三人 | 具状人（签字、盖章）： | ✅ | 保全/管辖按案由 |
| 民事答辩状 | 答辩人/被答辩人 | （待勘察：非"具状人"） | ✅（59-60 棵中含答辩状） | 18 棵最大组无保全块 |
| 行政起诉状 | 原告/被告 | 具状人： | ❌ | 11 棵组无调解块 |
| 行政答辩状 | 答辩人（法人精简块） | （待勘察） | ❌ | 无自然人详表（仅姓名：） |
| 刑事自诉状 | 自诉人/被告人 | 具状人： | ❌ | 无 住所地/法代/信用代码 |
| 国家赔偿申请书 | 赔偿请求人/赔偿义务机关 | （待勘察） | ❌ | 56-58 无信用代码 |
| 执行类申请书 | 申请人/被申请人 | （待勘察） | ❌ | 形态最杂（10 棵单例组） |

## 五、渲染规则复用清单（跨案由直接可用）

| 规则/工具 | 用途 | 出处 |
|---|---|---|
| `make_text_replace_rule(append=True)` | 标签+值（默认语义，禁止裸值替换） | DEC-002 铁律 1 |
| `make_gender_rule` | 男□/女□ 按值勾选 | DEC-002 铁律 3 |
| `replace_option_check` | 独立选项勾选（防子串双勾） | DEC-002 铁律 2 |
| `make_text_fill_rule` + `fmt_date` | 年/月/日空白复合占位 | — |
| `check_box` | 首个 □ 勾选（确认无子串包含关系时用） | — |

**新案由接入流程**：`dump_template_fields.py <树>` 生成字段骨架 → 勘察 occurrence 映射 → 复用上表规则写 `build_rules_NN()` → 通用块字段直接引用本文档，不重复定义。
