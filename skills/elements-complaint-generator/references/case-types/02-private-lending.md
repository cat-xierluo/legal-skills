## 二、字段填充规则（人/机双读）

> 渲染器按本节规则把 elements 写回 docx。规则分三类：
> - **text-fill**：在特征文本中找到空白段（如"    年    月    日"），把值嵌入
> - **text-replace**：把整段特征文本替换为指定文本
> - **checkbox**：在特征文本中找到"□"字符，根据布尔值改成"☑"或留"□"

### 2.1 当事人（自然人）

| path | type | match_text（用于定位） | 操作 |
|---|---|---|---|
| `当事人.原告[0].姓名` | text-replace | `姓名：`（同行第一个） | 替换 `：` 后空白为姓名 |
| `当事人.原告[0].性别` | checkbox | `性别：男□    女□` | 男=true → `男☑    女□`；女=true → `男□    女☑` |
| `当事人.原告[0].出生日期` | text-fill | `出生日期：      年        月         日` | 把空白填入 `YYYY年MM月DD日` |
| `当事人.原告[0].民族` | text-replace | `民族：`（同行） | 填入民族 |
| `当事人.原告[0].工作单位` | text-replace | `工作单位：`（同行） | 填入 |
| `当事人.原告[0].职务` | text-replace | `职务：`（同行） | 填入 |
| `当事人.原告[0].联系电话` | text-replace | `联系电话：`（同行） | 填入 |
| `当事人.原告[0].住所地` | text-replace | `住所地（户籍所在地）：` | 填入 |
| `当事人.原告[0].经常居住地` | text-replace | `经常居住地：` | 填入 |
| `当事人.原告[0].证件类型` | text-replace | `证件类型：` | 填入 |
| `当事人.原告[0].证件号码` | text-replace | `证件号码：` | 填入 |

（被告、第三人、委托诉讼代理人类似；MVP v0.1 仅实现「第一个原告/第一个被告」的渲染，多主体留 v0.2）
