## 二、occurrence 勘察结论（05 树专属，2026-08-17）

| 字段 | occurrence | 说明 |
|---|---|---|
| 当事人块 | `build_common_party_rules({"姓名_被告": 2, "单位_被告": 2, "职务_被告": 2, "电话_被告": 2})` | **05 布局：代理人插在原被告之间**（09 是代理人表独立在后） |
| 金额： | 0=损害赔偿 1=经济补偿 2=经济帮助 | 三行连续 |
| 其他□( ) | 0=房屋 1=汽车 2=存款 3=债务1 4=债务2 | 五处同形 |
| 有此问题（勾选行） | 0=子女直接抚养 1=抚养费 2=探望权 | ⚠️ 三行**空格数不一致**，上下文必须用不带空格的"有此问题"（DEC-004 教训） |
| 是□ 否□ | 0=诉讼费用；考虑先行调解走通用规则（取最后一处未勾） | — |

## 三、渲染规则要点（对应 build_rules_05_divorce）

- 归属/承担主体/行使主体 → `make_pick_option_rule`（值即选项，独立勾选）
- "（具体主张）"与"（法律及司法解释…）"占位 → 整体替换（append=False）
- 事实与理由 2-8 节 + 其他请求 + 证据清单 → `make_fill_after_rule`（标题后空段落填入）
- 结婚时间/金额及明细/支付方式/行使方式 → 标签追加（append=True）
- 赔偿三项：勾选 `make_pick_option_rule(选项=离婚损害赔偿/离婚经济补偿/离婚经济帮助)`，bool=true 时传选项名字符串或经 schema 约定

## 四、已知边界

- 被告性别为"女"时输出 `性别：男□    女☑`（勾女框），验收断言须用此形态
- 事实与理由各节 fill_after 要求标题后 3 段内存在空段落；若官方改版加了指引段（如请求依据），需改为占位替换
- 多子女（3+）未支持（模板只有子女1/2 行，可复制扩容条款留待实现）
