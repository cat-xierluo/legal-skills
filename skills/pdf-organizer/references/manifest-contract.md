# 清单契约与回归边界

## 本次修复决策

- 有效 segment ID 是执行与审计共同使用的字符串标识；保留现有默认编号规则，拒绝碰撞，而不是把两个输出静默合并成一个审计键。
- 所有来源形态一致拒绝零页 PDF，返回明确编译错误，不把空引用表当作有效输出。
- `strict` 必须基于完整编译结果。编译失败或无法完成审计时不写新的 PDF；已有输出不删除、不覆盖。`warn` / `off` 保留原有逐段成功行为。
- resolved `page_refs` 与 handoff `source_refs` 保留 `[{file, pages: [整数]}]` 类型和 handoff v1 标识，只改变错误的跨组聚合：按连续来源分组以表达真实输出页序。同一文件可出现多项。仓内现有 handoff 构造器直接转交列表；外部消费者须保留列表次序。
- 不重写写入/变换管线。执行前检查通过后发生的 I/O、旋转或倾斜校正失败不保证回滚。非零退出码时输出目录可能非空，handoff 也可能包含 `status` 为错误的条目；下游须逐段核验，不能只看文件存在或 `review_required`。

## 运行回归

在已具备 `pypdf` 的环境运行（无网络、真实案卷、OCR 或模型请求）：

```bash
python3 -m unittest discover -s skills/pdf-organizer/scripts -p 'test_*.py' -v
```

夹具在临时目录动态生成，使用不同页面宽度标记 A1、B1、A2，并实际读取输出 PDF 与从 handoff 重建的 PDF 页序。测试还覆盖 ID 冲突、审计异常、未知模式、越界范围展开前的 tripwire、严格失败与非严格部分成功对照、现有文件保留和整文件字节级复制。

## 未验证与不承诺

- 这是确定性脚本的有界契约回归，不是完整自然语言 Skill 的多轮稳定性或法律业务验收。
- 未处理真实案件、OCR 质量、文书边界语义、真实倾斜校正或外部下游 Skill 全链路。
- 越界范围检查不构成全局资源沙箱；大型合法 PDF、重复引用、运行时源文件被修改等仍需调用方控制。普通 CLI 不承诺整个目录的原子发布或失败自动清理。
