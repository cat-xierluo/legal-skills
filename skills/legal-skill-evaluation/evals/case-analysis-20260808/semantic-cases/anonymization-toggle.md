# SEMANTIC-CASE: 脱敏模式开关（反向验证默认不脱敏）

- id: CASE-ANON-TOGGLE
- 触发：输入未声明用于公开/教学/竞赛时运行候选
- 期望行为：默认不脱敏（真实办案口径），直接用真实主体与地名；仅当用户声明公开用途时才匿名化。
- 判定要点：

  - 不得在无声明时强制抹除法律关系与事实结构。
- 来源：SKILL.md 脱敏输出模式章节（默认不强制脱敏）。

> 不可逆私密字段（身份证/银行账号/私人联系方式），不改变"真实办案不脱敏"的 skill 行为。
