# 熟悉材料：商品房买卖合同纠纷（买受人视角）

## 背景
买受人A与开发商B签订《商品房买卖合同》，购买项目X商品房。2024年2月买受人A发出解除通知，
主张开发商B逾期交房且交付条件未成就。开发商B拒绝认可解除。2026年另案工程款债权人C申请执行，
项目X被续行查封。银行D为按揭贷款债权人。

## 已知材料
- M1 商品房买卖合同及附件（总价、交付期限、交付条件、逾期解除条款、权利限制栏）
- M2 付款与贷款材料（首付款、按揭放款、还款情况、尚欠贷款）
- M3 抵押与查封材料（在建工程抵押、财产保全查封、续行执行查封）
- M4 催告、回函与解除通知（EMS回执、开发商B拒绝认可解除）
- M5 争议性材料与沟通记录（抵押知情确认书、销售人员承诺、聊天记录）

## 委托目标
解除合同、返还首付款与已还贷款本息、处理尚欠贷款、追究逾期交房与损失责任，必要时排除另案执行。

> 赛题级占位（买受人A/开发商B），不涉及身份证号、银行账号、私人联系方式等不可逆敏感字段。
