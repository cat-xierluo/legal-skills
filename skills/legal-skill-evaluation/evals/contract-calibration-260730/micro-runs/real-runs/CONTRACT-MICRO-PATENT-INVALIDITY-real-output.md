## 二、风险清单

### 风险 1：第三方侵权责任分配倒置，受让方承担全部法律责任

- **风险名称**：第三方侵权责任过宽（责任分配倒置）
- **风险等级**：**P0**
- **相关条款**：第二条"因许可专利引发的第三方侵权，由受让方承担全部法律责任。"
- **风险后果**：
  1. **权利瑕疵风险全部外移给受让方**。专利权属、专利有效性、是否落入他人在先权利范围，均由许可方掌控且属许可方应当担保的事项。本条使受让方在完全无法控制的风险上承担无限责任。
  2. **专利被宣告无效时无救济**。若许可专利嗣后被宣告无效或被认定侵犯他人在先专利，受让方不仅使用落空、许可费无从追回，还要独自承担对第三方的赔偿。
  3. **责任无上限、无例外**。"全部法律责任"字面涵盖第三方索赔本金、维权合理开支、惩罚性赔偿及行政处罚，且未区分侵权成因是否可归责于许可方。
  4. **与法定权利担保义务相悖**。许可方本负有权利无瑕疵担保义务，本条实质以约定架空该义务，一旦发生争议将成为主要抗辩焦点。
- **判别标准**：许可类合同中，凡出现"由被许可方/受让方承担全部（法律）责任"且未区分侵权成因、未设例外、未设上限的表述，一律按 P0 处理。
- **法律依据方向**：民法典合同编技术合同章关于技术许可方权利瑕疵担保与侵权责任分担的规定；专利法关于专利权无效宣告溯及力的规定。（具体条文号需结合定稿文本再行核对，暂标注"待补充"。）
- **整改建议**：整条重写，将责任分配回归"按成因归责"原则，并配套增加许可方权利担保、抗辩配合与无效后果处理条款。
- **建议展现方式**：**整条重写 + 保留解释性批注**（属重大直接修订，需向对方说明修改原因）。

**推荐措辞（第二条替代文本）**：

> **第二条　权利担保与第三方侵权责任**
>
> 2.1 许可方保证其为许可专利的合法权利人，有权就许可专利作出本合同项下的许可，许可专利权属清晰、未设定质押或其他权利负担，且不存在正在进行或据其所知即将提起的权属纠纷、无效宣告程序或侵权诉讼。
>
> 2.2 受让方在本合同许可范围内正常实施许可专利，因许可专利本身的权利瑕疵（包括但不限于许可专利落入第三方在先权利范围、许可方无权许可、许可专利被宣告无效）而遭第三方主张侵权的，由许可方承担全部责任，并负责应诉、抗辩及和解；受让方因此支出的赔偿金、和解金、律师费、诉讼费及其他合理费用，由许可方全额赔偿。
>
> 2.3 受让方超出本合同约定的许可范围、期限、地域或实施方式使用许可专利，或因受让方自行改进、与其他技术结合、擅自转许可而引发第三方侵权主张的，该部分责任由受让方自行承担。
>
> 2.4 任一方收到第三方侵权主张或知悉相关风险的，应在【三】个工作日内书面通知对方，并提供必要的应诉资料与配合；未及时通知致使对方损失扩大的，就扩大部分自行承担。
>
> 2.5 许可专利在许可期内被宣告全部或部分无效的，本合同自无效宣告生效之日起就相应部分终止，受让方有权停止支付其后的许可费；对已支付且尚未实际受益部分的许可费，双方按【　】原则处理（**待双方商定，本项为商务取舍，暂留空**）。

### 风险 2：许可核心要素全部缺失

- **风险名称**：许可标的与许可范围未约定
- **风险等级**：**P0**
- **相关条款**：第一条、第三条
- **风险后果**：合同未载明专利号、专利名称、专利类型、法律状态、许可方式（独占/排他/普通）、许可期限、地域范围、实施方式、许可费及支付节点。核心条款缺失可能导致合同内容不确定、难以履行，甚至成立与否存疑；且受让方无从判断第二条责任对应的风险敞口究竟有多大。
- **判别标准**：许可类合同缺少标的识别信息或对价条款的，一律 P0。
- **整改建议**：签署前必须补入专利基本信息附件（专利号、申请日、授权公告日、当前法律状态、年费缴纳情况）及许可范围、许可费条款。
- **建议展现方式**：批注（属事实待补项，不自行臆造商业安排）。

### 风险 3：无违约救济、解除与争议解决机制

- **风险名称**：救济与退出路径缺失
- **风险等级**：**P1**
- **相关条款**：第三条"未尽事宜由双方另行协商确定"
- **风险后果**：无违约责任条款，第二条改造后的许可方赔偿义务缺乏履约压力；无解除权约定，专利被无效或许可方违约时受让方无明确退出路径；无争议解决条款，发生纠纷时管辖与救济方式不确定。
- **整改建议**：补入违约责任、合同解除（含专利无效、权属变动、许可方丧失许可权限等解除情形）、争议解决（约定管辖法院或仲裁机构）、通知送达条款。
- **建议展现方式**：局部补入 + 批注。

## 四、审查结论

**不建议按现有文本签署。**

第二条将因许可专利引发的第三方侵权责任全部转由受让方承担，属责任分配倒置的 P0 条款，实质将许可方本应承担的权利瑕疵担保风险完全外移，受让方在无法控制的风险上承担无上限、无例外的责任；加之许可标的、许可范围、许可费等核心要素与救济、解除、争议解决机制全部缺失，本合同目前不具备可签条件。

在完成以下先决事项后，可转为"有条件可签"，届时需就修订稿再作一次复核：

**签署前先决事项**
1. 按本意见推荐措辞改写第二条，确立"按成因归责 + 许可方权利担保 + 抗辩配合 + 无效后果处理"结构；
2. 补入许可专利基本信息附件，并核实许可专利当前法律状态（是否有效、有无在审无效宣告程序、年费是否正常缴纳）；
3. 补入许可方式、期限、地域、实施方式与许可费条款；
4. 补入违约责任、解除、争议解决与通知送达条款；
5. 就第 2.5 条许可费返还原则取得受让方商务口径，并补齐主体信息与签署页；
6. 补录审查人身份配置与客户名称，以便出具正式审核修订版 DOCX 与 Word 审查意见书。

**谈判优先级**
- P0：第二条第三方侵权责任重写；许可标的与许可范围、许可费补入。
- P1：违约、解除、争议解决与通知送达机制补入。
- P2：主体信息与签署要件补齐。
