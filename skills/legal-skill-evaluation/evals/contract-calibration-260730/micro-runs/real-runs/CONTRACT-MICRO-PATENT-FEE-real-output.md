# 专利许可合同 审查意见（微案例实跑输出）

合同名称：专利许可合同（contract-micro-patent-fee.docx）
审查立场：受让方（被许可方）
审查目的：签约前把关
审查口径：常规
风险分级：P0 / P1 / P2

---

## 一、综合审查意见

本合同全文仅三条，属于严重不完整的框架性文本。核心商业条款——**许可使用费**——只写了"受让方按约定向许可方支付许可使用费"，既无金额或计费方式，也无支付时间、支付方式、币种、税费承担、逾期责任。此外，专利许可合同赖以成立的**许可标的（专利号、专利名称、专利权状态）**、**许可类型（独占/排他/普通）**、**许可期限与地域**、**权利瑕疵担保**、**违约与争议解决**均缺失。

以受让方立场，本轮**不具备形成"可签"或"有条件可签"正式结论的条件**：现有文本缺项过多，超出"补几处措辞"的范围，需要许可方补充事实与条款后重新提交审查。以下逐项列出已识别风险与推荐措辞，供补充谈判使用。

## 二、风险清单

### 风险 1：许可使用费条款缺项（本轮核心问题）

| 字段 | 内容 |
|:---|:---|
| 风险名称 | 许可使用费金额、计费方式与支付安排全部缺失 |
| 风险等级 | **P0** |
| 相关条款 | 第二条 |
| 风险后果 | 「按约定支付」属于典型的**空指向条款**——合同内并无任何"约定"可指。后果有三：①价款作为专利许可合同的主要条款缺失，可能被认定双方对价款未达成合意，进而影响合同成立或至少导致条款无法执行；②争议时须依《民法典》第511条、第510条按交易习惯或市场价补充确定，受让方将丧失价格控制权，面临许可方主张远高于预期的费率；③无支付时间即无履行期限，许可方可随时催告并起算逾期违约，受让方付款节奏完全被动。 |
| 判别标准 | 价款条款是否同时具备：①确定的金额或可计算的计费公式；②计费基数与结算周期（如按净销售额比例，需定义"净销售额"）；③支付时间与支付条件；④支付方式、账户、币种；⑤税费承担；⑥逾期利息上限。缺任一项即视为不完整；本条为**六项全缺**。 |
| 法律依据 | 《民法典》第470条（合同一般条款应包含价款或报酬）、第510条（未约定或约定不明的补充确定）、第511条第2项（价款不明按订立时履行地市场价履行）、第865条以下（技术许可合同相关规定）。 |
| 整改建议 | 不建议以"另行签订补充协议"方式带过。应在正文直接写死计费口径，或将费率表作为不可分割附件在签署时同步签署。受让方应争取：固定费用为主 / 提成费封顶、明确里程碑付款、明确税费各自承担、逾期利息不超过 LPR 的合理倍数。 |

**推荐措辞（受让方口径，待填事实以"未提及/待补充"标注）：**

> **第二条 许可使用费及支付**
>
> 2.1 计费方式。本合同项下许可使用费采用【固定许可费 / 固定入门费＋提成费】方式计收，具体为：
> （1）入门费：人民币【未提及/待补充】元（含税），于本合同生效且许可方完成第【】条约定的专利资料交付之日起【15】个工作日内一次性支付；
> （2）提成费：按受让方就许可专利产品实现的**净销售额**的【】%计收。「净销售额」指受让方开具发票金额扣除增值税及附加、销售折让、退货、运费与保险费后的余额。
>
> 2.2 提成费上限。每一结算年度提成费累计不超过人民币【】元；许可期内提成费累计不超过人民币【】元。
>
> 2.3 结算与支付。提成费按【自然季度】结算，受让方于每季度结束后【30】日内提供结算报表，许可方收到报表后【10】个工作日内开具合规增值税专用发票，受让方于收到发票之日起【15】个工作日内支付。**许可方未开具合规发票的，受让方有权顺延支付且不构成违约。**
>
> 2.4 币种与账户。以人民币支付至许可方指定账户【未提及/待补充】。账户变更须经许可方法定代表人签字并加盖公章的书面通知，未经上述形式通知的变更不发生效力。
>
> 2.5 税费。因本合同产生的税费，由双方各自依法承担；许可方所得税由许可方自行承担，受让方依法负有代扣代缴义务的除外。
>
> 2.6 逾期责任。受让方逾期支付的，按逾期金额的每日万分之【三】支付违约金，累计不超过逾期金额的【10】%。
>
> 2.7 费用调整。除本条明确约定外，许可方不得单方调整许可使用费；任何调整须经双方书面协商一致。

| 字段 | 内容 |
|:---|:---|
| 风险等级 | **P0** |
| 相关条款 | 第一条 |
| 风险后果 | 第一条仅称"就上述合同标的达成一致"，但全文未出现任何专利名称、专利号、申请日、授权公告日、专利权人、剩余保护期、年费缴纳状态。标的不特定将导致：受让方无法确定自己究竟获得了什么权利；若该专利已届满、被宣告无效或未缴年费终止，受让方支付的许可费将失去对价基础且难以追回。 |

### 风险 3：许可类型、期限与地域未约定

| 字段 | 内容 |
|:---|:---|
| 风险等级 | **P0** |
| 相关条款 | 全文缺失 |
| 风险后果 | 未约定许可类型的，实践中通常按**普通许可**认定，即许可方仍可自行实施并再许可给受让方的竞争对手，受让方的市场投入可能为他人作嫁衣。未约定期限与地域，则许可范围边界不清，双方对可实施区域和年限各执一词。 |

**推荐措辞：**

### 风险 4：许可方权利瑕疵担保与侵权抗辩责任缺失

| 字段 | 内容 |
|:---|:---|
| 风险等级 | **P1** |
| 相关条款 | 全文缺失 |
| 风险后果 | 受让方实施专利后若遭第三方主张侵权，或该专利被宣告无效，现有文本下许可方无任何担保义务，损失全部由受让方承担；且专利被宣告无效后，已支付的许可费按现行规则原则上不予返还，受让方须靠合同约定自救。 |
| 判别标准 | 是否约定权属担保、无第三方权利负担担保、侵权抗辩配合义务、专利无效后的费用处理。 |
| 法律依据 | 《民法典》第850条、第877条；《专利法》第47条第2款。 |
| 整改建议 | 增加许可方担保条款，并明确专利被宣告无效时未到期部分许可费停付、已付部分按比例返还。 |

**推荐措辞：**

> 许可方保证其为附件一所列专利的合法权利人，该等专利合法有效、年费缴纳完备，且未设置质押或其他权利负担，亦未许可任何第三方以与本合同冲突的方式实施。第三方就受让方依本合同实施行为主张侵权的，许可方应提供必要协助并承担由此产生的合理费用及受让方的实际损失。**许可专利被宣告无效的，自无效宣告之日起受让方停止支付剩余许可费；已支付但对应期间尚未届至的部分，许可方应于【30】日内返还。**

### 风险 5：违约责任、合同解除与争议解决条款缺失

| 字段 | 内容 |
|:---|:---|
| 风险等级 | **P1** |
| 相关条款 | 第三条 |
| 风险后果 | 第三条以"未尽事宜由双方另行协商确定"兜底，实为无救济条款。发生争议时受让方无违约金依据、无解除权路径、无约定管辖法院，只能依法定规则处理，维权成本与不确定性显著上升。 |

| 整改建议 | 补入违约责任、解除权、通知送达和争议解决条款；管辖地争取约定至受让方住所地人民法院。 |

**推荐措辞：**

> 违约与救济。任何一方违反本合同的，应赔偿守约方因此遭受的直接损失。许可方存在专利权属瑕疵、隐瞒在先许可或专利被宣告无效情形的，受让方有权书面通知解除本合同并要求返还相应许可费。
>
> 通知送达。双方确认本合同首部载明的地址、电子邮箱为有效送达地址，一方变更的应提前【5】个工作日书面通知对方；按上述地址发出的文件视为送达，包括诉讼文书。
>
> 争议解决。因本合同产生的争议，双方应协商解决；协商不成的，任何一方可向**受让方住所地**人民法院提起诉讼。本合同适用中华人民共和国法律。

## 三、签署前先决事项清单

1. 许可方补充提供专利清单及专利登记簿副本、最近一期年费缴纳凭证。（对应风险 2）
2. 双方就许可使用费的**计费方式、金额/费率、结算周期、支付时间、税费、逾期责任**六项达成书面一致，并写入正文或不可分割附件。（对应风险 1）
3. 明确许可类型（独占/排他/普通）、许可期限与实施地域。（对应风险 3）
4. 补入许可方权利瑕疵担保及专利无效后的费用返还机制。（对应风险 4）
5. 补入违约责任、解除权、通知送达与争议解决条款。（对应风险 5）
6. 核验许可方主体资格与签约授权（营业执照、法定代表人身份或授权委托书）。
7. 若许可方为共有专利权人之一，需提供其他共有人同意许可的书面文件。

## 四、谈判优先级

- **P0（必须先解决，否则无法进入签署）**：许可使用费条款（风险 1）→ 许可标的特定化（风险 2）→ 许可类型/期限/地域（风险 3）
- **P1（优先谈判）**：权利瑕疵担保（风险 4）→ 违约与争议解决（风险 5）
- **P2（时间允许时处理）**：技术资料交付与改进归属（风险 6）

## 五、审查结论

本轮不出具正式可签结论，审查暂停待补。

现有合同文本仅三条，许可使用费的金额/费率、计费方式、支付时间、支付方式、税费承担、逾期责任六项全部缺失，且许可标的、许可类型、许可期限与地域、权利担保、违约与争议解决条款亦均未约定。缺项已超出"文本优化"范围，属于核心交易要素未形成合意，不具备判断"可签 / 有条件可签 / 不建议签"的事实基础。以受让方立场，现阶段**不建议在现有文本上签署**。

请先由许可方补齐上述"签署前先决事项清单"第 1 至 7 项（尤其是许可专利清单与许可使用费计费口径），并提供完整版合同文本及附件后，本轮审查将继续并出具正式审查结论。

上文推荐措辞为待补条款的谈判起草参考，不构成对现有文本的可签认可。
