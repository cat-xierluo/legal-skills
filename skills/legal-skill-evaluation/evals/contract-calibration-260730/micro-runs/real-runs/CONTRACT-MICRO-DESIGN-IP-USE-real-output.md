## 二、微观条款风险

### 风险 1：设计成果知识产权全部归乙方，且甲方被禁止向施工单位提供，委托目的落空

- 风险名称：设计成果权属与使用权配置与委托目的严重背离
- 风险等级：**P0**
- 相关条款：第二条
- 原文："设计成果知识产权归乙方所有；甲方不得复制、修改或向施工单位提供该成果。"

**风险后果**

1. 委托目的落空：甲方付费取得设计成果，通常是为了据以施工、报建、招投标。禁止"向施工单位提供"，等于甲方拿到成果却无法用于工程实施，合同对甲方的商业价值近乎归零。
2. 复制禁令与必需流程冲突：施工图报审、图审机构送审、招标发包、竣工备案、后续运维，均需复制、分发设计文件。甲方一旦执行上述任一常规动作，即构成违约，反被乙方索赔。
3. 修改禁令锁死后续变更：现场条件变化、政府审批意见、成本优化都需要改图。禁止修改意味着甲方要么被迫回头找乙方（形成单一供应商锁定、议价权丧失），要么违约改图。
4. 二期/改扩建受限：同一项目后续阶段无法复用本次成果。
5. 权属归乙方本身在委托设计场景中并非当然不合理（《著作权法》第十九条：委托作品未约定或约定不明的，著作权属于受托人），但法律同时确认委托人在约定使用范围内有使用权；本条恰恰把这层使用权掏空，形成"权属归乙方 + 使用权也不给甲方"的双重不利。

**判别标准**

- 甲方是否取得覆盖项目建设全流程（报建、审图、招标、施工、监理、竣工验收备案、运维）的使用权；
- 是否允许为上述目的进行必要的复制与分发；
- 是否允许因客观需要进行必要修改（或至少约定乙方限期配合修改的义务与不配合时的自行修改权）；
- 是否覆盖本项目后续阶段与改扩建。

**法律依据（方向性，非最终检索结论）**

- 《著作权法》第十九条（委托作品著作权归属及委托人使用权）
- 《民法典》第五百零九条（依合同目的与诚信原则履行）、第八百四十三条以下技术合同相关规则
- 《建设工程勘察设计管理条例》关于设计文件用于施工的相关要求

**整改建议（按优先级给三档，供甲方按谈判空间选择）**

- 方案 A（最有利，建议争取）：约定设计成果著作权（署名权除外）归甲方所有，乙方保留署名权。
- 方案 B（折中，常见落点）：权属仍归乙方，但甲方取得项目范围内永久、不可撤销、免费、可转授权的使用许可，含复制、修改与向第三方交付。
- 方案 C（底线）：至少删除"不得向施工单位提供"，并明确甲方为项目实施所需的复制、分发与必要修改不构成侵权或违约。

**推荐措辞（方案 B，可直接落文）**

> 第二条 设计成果的知识产权归乙方所有，乙方享有署名权。乙方在此授予甲方就本项目（含本项目后续阶段、改建、扩建及维修）永久、不可撤销、免费、可转授权的使用许可，包括为报建、审图、招标、施工、监理、竣工验收备案、运营维护及档案留存之目的，复制、使用、分发设计成果，并向施工单位、监理单位、造价咨询单位、审图机构及行政主管部门提供设计成果。甲方因客观条件变化、行政审批意见或功能调整需要修改设计成果的，应先书面通知乙方，乙方应在收到通知后 5 个工作日内（或双方另行约定期限）完成修改；乙方逾期未完成或明确拒绝的，甲方有权自行或委托第三方修改，乙方不得据此主张侵权或违约，但因该修改本身导致的设计质量问题由修改方承担。

**推荐措辞（方案 A，如甲方议价能力较强）**

> 第二条 乙方就本合同项下设计成果所享有的著作权（署名权除外）自甲方付清相应款项之日起归甲方所有。乙方保留署名权，并不得就该设计成果向任何第三方主张权利或另行许可他人使用。

**建议展现方式**：整条重写（原条款逻辑对甲方整体失效，局部删减无法修复），并附批注说明修改原因。

### 风险 2：付款与权利转移未挂钩

- 风险等级：P1
- 相关条款：第二条、第三条（缺失）
- 风险后果：合同未约定权属或许可与付款的对价关系。若采用方案 A，需明确"付清款项后转移"，否则甲方欠款时权属状态不清；若采用方案 B，需明确许可自成果交付之日起生效，避免乙方以"未付尾款"为由主张甲方使用行为侵权，形成付款争议叠加侵权索赔的双重压力。
- 整改建议：在权属条款中加入付款联动表述，并明确"甲方逾期付款的，乙方可主张违约责任，但不得撤销已授予的使用许可"。

### 风险 3：第三方权利瑕疵担保与侵权兜底缺失

- 风险等级：P1
- 相关条款：全文缺失
- 风险后果：设计成果可能含第三方素材、标准图集、字体、软件模型或抄袭内容。若第三方向甲方（而非乙方）主张侵权，甲方作为使用方直接暴露在索赔与停工风险中，且无合同依据向乙方追偿。
- 推荐措辞：

> 乙方保证其交付的设计成果为独立完成，不侵犯任何第三方的知识产权或其他合法权益。任何第三方就设计成果向甲方主张权利的，乙方应自行出面处理并承担全部费用；甲方因此遭受的损失（含但不限于赔偿金、律师费、停工损失）由乙方赔偿。

### 风险 4：成果交付标准、验收与保密条款缺失

- 风险等级：P2
- 相关条款：第三条（"未尽事宜由双方另行协商确定"）
- 风险后果：本合同仅三条，交付物清单、文件格式（是否含可编辑源文件如 CAD/BIM 源文件）、交付时间、验收标准与期限、修改次数、违约责任、争议解决、保密义务均缺失。其中"是否交付可编辑源文件"与本次 IP 争点直接相关——即使取得修改权，无源文件仍无法实际行使。
- 整改建议：补充交付清单（明确含源文件）、验收流程与期限、违约责任、争议解决条款；"另行协商"式兜底不具可执行性，应替换为具体安排。

## 三、需甲方确认的事实（影响最终定论，暂列为待补充）

1. 本项目的实际用途与阶段（方案设计 / 初步设计 / 施工图设计）——直接决定使用权范围的必需边界。
2. 设计费金额与支付节奏，以及该报价是否已包含知识产权对价——权属归属的谈判筹码取决于此。
3. 甲方是否已就本项目确定施工单位、是否存在必须交图的报建时间节点。
4. 是否存在二期或改扩建计划。
5. 乙方是否为项目唯一设计方，甲方是否有更换设计方的现实可能。
6. 合同其余条款（本次仅见三条，"其他条款"为占位）——完整文本可能另有交付、验收、保密与违约约定，需一并核对后才能定稿。

## 四、审查结论

**本轮不出具正式可签结论。**

第二条"设计成果知识产权归乙方所有；甲方不得复制、修改或向施工单位提供该成果"构成 P0 级风险：该条使甲方付费取得的设计成果无法用于施工、报建与招标，委托目的实质落空，且甲方为推进项目所必需的常规动作（复制送审、向施工单位交图、按审批意见改图）均会构成违约。以现状文本，甲方**不建议签署**。

2. **确认审查人身份配置**——`config/reviewer_profile.json` 中审查人姓名与律所/公司名称尚未在本环境确认，正式意见书出具前需补录。
3. **由甲方确认第三节所列事实**（项目阶段、设计费是否含 IP 对价、报建与施工节点、后续阶段计划、议价空间），据此在方案 A/B/C 中确定谈判目标。

**谈判优先级**

- P1：付款与权利转移联动；第三方权利瑕疵担保与侵权兜底
- P2：交付清单（含源文件）、验收标准与期限、保密、违约责任、争议解决条款补全
