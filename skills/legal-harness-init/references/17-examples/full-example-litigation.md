# 参考范例：诉讼律师

> 教学用，不直接套用。项目级范例采用 `strict`，真实案件事实不进入 AGENTS.md。

## 用户级

```markdown
# 民商事诉讼律师

## 工作流与产出
- 常见产物：诉讼方案、起诉/答辩文书、证据目录、庭审提纲、复盘报告。
- 法律观点区分材料事实、推断和建议，并标注依据与适用时间。

## 协作偏好
- 中文、要点先行；重大风险说明依据与信息缺口。

## 法律安全基线
- 可读写授权范围内的本地文件并进行法律检索。
- 未经逐项确认，不向法院、客户、对方或第三方发送/提交任何内容。
- 不伪造、补写或删除证据；不把未核验材料写成确定事实。
- 主体、金额、期限、引用和最终文书必须人工复核；AI 不作最终法律判断。
- 客户材料、凭证、高敏身份信息不得进入公开配置、Git、日志或未获授权的外部服务。

## 回溯契约
- 决策、证据、期限和交付分别写入项目既有权威载体。
- 期限记录必须包含起算事实、计算依据、责任人和复核状态；信息不足时不得猜测。
```

## 项目级（strict）

```markdown
# 项目：LIT-YYYY-001

- 类型：民商事诉讼
- 阶段：一审审理
- 关键时点：YYYY-MM-DD 举证期限（待人工复核）
- 隐私模式：strict

## 受控事实入口
- 本配置不保存真实案号、当事人、金额或材料正文。
- 任务需要事实时，请用户按需提供脱敏片段；缺送达或起算信息时列出缺口。

## 文件与回溯
- 沿用项目现有证据索引、期限台账、决策记录和交付记录。
- 对外动作必须取得明确授权；留痕不等于授权。
```
