# 参考范例：法律研究/学者

> ⚠️ 这是参考范例，**不直接套用**。展示完整的法律研究/学者 AGENTS.md 长什么样。

## 用户级 `~/.claude/CLAUDE.md`

```markdown
# 法学学者 · 上海 · 主营法律研究 + 律师培训 · 同时参与公益诉讼

## 工作流与产出

- 研究报告：问题 → 文献综述 → 案例分析 → 结论
- 案例汇编：主题分类 + 裁判要旨 + 学理评析
- 培训讲义：知识框架 + 案例 + 实务要点
- 学术论文：引言 → 文献 → 方法 → 论证 → 结论
- 公益诉讼：起诉材料 + 代理意见

## 协作偏好

- 适中（学术写作但要可读）
- 批注（保留原文便于修改）
- 中文（必要时保留英文文献原文）

## 工具链与禁区

### 允许的工具

- 读/写本地文件
- 检索学术文献（CNKI / Westlaw / HeinOnline）
- 检索裁判文书

### 禁止的动作

- 不要替我下结论性法律意见（学术写作必须保留学术中立）
- 不要伪造研究数据/案例引用
- 不要删除已有研究记录

### 必须人工复核

- 文献引用准确性
- 案例引用准确性（含案号、判决日期、判决机关）
- 结论性表述（不能替我下"通说"判断）
- 对外发表的稿件

## 回溯契约（Audit Trail Contract）

### 必须回溯的动作

- 研究思路与取舍 → docs/DECISIONS.md
- 检索结果/案例汇编节点 → CHANGELOG.md
- 文献引用增减 → CHANGELOG.md
- 结论性表述调整 → docs/DECISIONS.md
- 待办（检索/撰写/评审）→ TASKS.md

### 回溯原则

- 每次写入必须含日期、上下文、动作、影响
- 不删除已有记录（学术写作的历史很重要）
- 文献/案例引用必须可追溯
```

## 项目级 `<项目>/AGENTS.md`

```markdown
# 项目：研究 · 生成式 AI 著作权侵权专题

## 上下文

- 类型：法律研究（专题）
- 委托方：上海市律师协会
- 截止日期：YYYY-MM-DD
- 预期交付物：研究报告 + 案例汇编 + 培训讲义

## 关键事实

- 课题：生成式 AI 著作权侵权专题
- 委托方：上海市律师协会
- 截止日期：YYYY-MM-DD
- 预期交付物：研究报告（3 万字）+ 案例汇编（50 例）+ 培训讲义
- 研究范围：中国法（与美国法对比）
- 引用格式：脚注 + 文末参考文献（GB/T 7714）

## 文件结构

- 自建目录：
  - `01 课题资料/`
  - `02 文献综述/`
  - `03 案例汇编/`
  - `04 研究报告/`
  - `05 培训讲义/`
- 命名约定：`v{N}_{YYMMDD}_{章节}.md`
- 不进 git：无（研究项目通常全进 git）

## 项目级回溯补充

- 研究思路调整（章节增删、立场变化）→ DECISIONS.md
- 文献/案例新增 → CHANGELOG.md（含引用信息）
- 引用格式变更 → DECISIONS.md
- 交付物版本切换 → CHANGELOG.md
- 评审/审稿意见 → DECISIONS.md（含意见摘要 + 回应）
```

## 关键说明

- 法律研究/学者和律师最大的差别：**不下结论**——学术中立是底线，必须在 M4 明确
- 引用必须可追溯——M5 回溯契约对学术研究尤其重要
- 项目周期长（几个月甚至几年），DECISIONS 和 CHANGELOG 是复盘的关键
- 公益诉讼参与是复合身份的体现，M1 中可明确列出
