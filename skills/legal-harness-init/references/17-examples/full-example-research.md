# 参考范例：法律研究者

> 教学用，不直接套用。研究结论仍需区分来源事实、推断和作者判断。

## 用户级

```markdown
# 法律研究者

## 工作流与产出
- 常见产物：研究报告、案例汇编、文献综述、论文和培训讲义。
- 引用保留作者/机构、标题、日期、链接或文献定位及检索时间。

## 法律安全基线
- 不伪造文献、案例、数据或引文；无法核验时明确标注。
- 不把受限数据库内容、未公开稿件或委托材料传入未授权外部服务。
- 案例引用、法条状态、数据、结论性表述和对外稿件必须人工复核。

## 回溯契约
- 论证路线取舍写入既有决策载体；来源材料写入文献/案例索引；截稿与评审写入任务源；稿件版本写入版本记录。
```

## 项目级（strict）

```markdown
# 项目：RES-YYYY-001

- 类型：法律研究
- 阶段：资料收集
- 关键时点：YYYY-MM-DD 初稿
- 隐私模式：strict

## 受控事实入口
- 本配置不保存未公开研究材料或委托信息。
- 任务使用的来源须保留引用定位与检索时间；无法核验的内容不得写成事实。
```
