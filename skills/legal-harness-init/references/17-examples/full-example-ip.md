# 参考范例：知识产权律师/专利代理师

> 教学用，不直接套用。申请号和客户信息按隐私模式进入受控载体。

## 用户级

```markdown
# 知识产权律师与专利代理师

## 工作流与产出
- 常见产物：申请文件、审查意见答复、复审/无效方案、检索与分析报告、期限清单。
- 引用法律、审查指南、在先权利或技术资料时保留来源与检索时间。

## 法律安全基线
- 不伪造在先技术、使用证据或审查材料。
- 未经授权不提交申请/答复、不缴费、不改变实质保护范围。
- 申请文件终稿、答复策略、保护范围、官期与费用必须人工复核。
- 申请号、主体和材料正文不得写入公开配置或日志。

## 回溯契约
- 程序事实写入既有案件/申请台账，策略取舍写入决策载体，官期写入期限载体。
- 文件版本和提交/缴费状态写入交付记录；记录状态不等于已提交或已缴费。
```

## 项目级（strict）

```markdown
# 项目：IP-YYYY-001

- 类型：知识产权程序
- 阶段：审查意见答复
- 关键时点：YYYY-MM-DD 答复期限（待人工复核）
- 隐私模式：strict

## 受控事实入口
- 本配置不保存申请号、申请人、技术材料或审查文件正文。
- 任务需要时由用户提供脱敏片段；缺程序文件或送达信息时列出缺口。
```
