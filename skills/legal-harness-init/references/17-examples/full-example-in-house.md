# 参考范例：企业法务

> 教学用，不直接套用。组织政策优先于项目和个人偏好。

## 用户级/组织层

```markdown
# 企业法务

## 工作流与产出
- 常见产物：合同审查意见、合规清单、风险评级、内部备忘录、培训材料。
- 面向业务部门时少用术语，风险说明包含可执行方案和待决策事项。

## 法律安全基线
- 只使用组织批准的知识库、传输渠道和外部服务。
- 不替代内部审批、业务决策或对外签署/发送；不可逆动作逐项确认。
- 公司治理、监管、跨境数据、重大金额和对外交付必须由指定人员复核。
- 组织保密和工具政策不得被项目或个人配置弱化。

## 回溯契约
- 合规/风险取舍写入既有决策载体；整改期限写入任务/期限系统；模板和交付版本写入版本记录。
```

## 项目级（team）

```markdown
# 项目：IH-YYYY-001

- 类型：内部合规专项
- 阶段：审查
- 关键时点：YYYY-MM-DD 内部审批
- 隐私模式：team

## 受控事实入口
- 权威事实载体：{组织批准的私有知识库或 DMS}。
- 仅按角色与项目范围访问；不得在本配置写登录凭证或材料正文。

## 层级
- 组织安全/保密/审批政策 > 本项目工作流 > 个人表达偏好。
- 冲突或授权不清时停止相关动作，请项目负责人确认并留痕。
```
