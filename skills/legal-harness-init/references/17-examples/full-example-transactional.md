# 参考范例：非诉合同律师

> ⚠️ 这是参考范例，**不直接套用**。展示完整的非诉合同律师 AGENTS.md 长什么样。

## 用户级 `~/.claude/CLAUDE.md`

```markdown
# 律师 · 北京执业 · 主营非诉合同（公司治理/股权设计/并购重组）

## 工作流与产出

- 合同起草：从客户需求到完整条款
- 合同审查：风险清单 + 修改建议 + 商务条款确认
- 法律意见书：针对具体法律问题
- 尽调报告：DD 清单 + 重大事项摘要
- 谈判支持：会议纪要 + 条款对比 + 风险提示

## 协作偏好

- 适中：要点 + 关键理由
- 批注：保留原文，在旁边加意见（便于客户/律师讨论）
- 中文

## 工具链与禁区

### 允许的工具

- 读/写本地文件
- 检索法条/案例
- 合同对比分析

### 禁止的动作

- 不要替我对外发送合同给客户
- 不要替我做商业判断（"这个价格合不合理"）
- 不要直接覆盖客户原合同

### 必须人工复核

- 合同金额、费率、违约金条款
- 责任限制、担保、管辖条款
- 跨境合规（出口管制、数据保护）
- 对外交付的合同

## 回溯契约（Audit Trail Contract）

### 必须回溯的动作

- 合同版本切换 → CHANGELOG.md
- 关键条款决策（管辖/责任/担保/价款）→ docs/DECISIONS.md
- 里程碑事件（签约/交割）→ docs/DECISIONS.md
- 客户对条款的实质修改 → DECISIONS.md
- 待办事项（签约前/交割前）→ TASKS.md

### 回溯原则

- 每次写入必须含日期（YYYY-MM-DD）、上下文、动作、影响
- 不删除已有记录
- 写入前先检查目标文件
```

## 项目级 `<项目>/AGENTS.md`

```markdown
# 项目：非诉合同 · YYMMDD {客户简称} 并购 DD

## 上下文

- 类型：股权收购尽调
- 委托人：北京 {客户简称} 投资集团
- 标的公司：杭州 {标的公司简称} 科技
- 当前阶段：尽职调查中（DD）
- 关键时点：DD 报告初稿 YYYY-MM-DD，签约 YYYY-MM-DD

## 关键事实

- 业务类型：股权收购 DD
- 客户：北京 {客户简称} 投资集团
- 标的公司：杭州 {标的公司简称} 科技有限公司
- 交易类型：股权收购（100%）
- 项目金额：人民币 X.X 亿元
- 是否跨境：否
- 关键里程碑：DD 报告 YYYY-MM-DD，签约 YYYY-MM-DD，交割 YYYY-MM-DD

## 文件结构

- 不使用 new-case 模板，按业务类型自建目录：
  - `01 DD 报告/`
  - `02 合同版本/`
  - `03 沟通记录/`
  - `04 工作底稿/`
- 命名约定：`v{N}_{YYMMDD}_{描述}.docx`（版本 + 日期 + 描述）
- 不进 git：客户提供的机密材料、待签版本

## 项目级回溯补充

- DD 重大发现 → DECISIONS.md
- 合同版本切换（v1→v2→v3）→ CHANGELOG.md（含变更条款、变更理由）
- 签约/交割里程碑 → DECISIONS.md
- 客户对条款的实质修改 → DECISIONS.md
```

## 关键说明

- 非诉律师的核心是合同版本管理——每次版本切换要记录到 CHANGELOG
- 关键条款决策（管辖/责任/担保/价款）必须留痕
- 跨境项目需在 M4 中加"跨境合规"专项
