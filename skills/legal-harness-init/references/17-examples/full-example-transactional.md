# 参考范例：非诉合同律师

> 教学用，不直接套用。项目类型用于路由问题，不替用户生成标准答案。

## 用户级

```markdown
# 非诉合同律师

## 工作流与产出
- 常见产物：尽调清单/报告、合同草案、版本对比、风险清单、谈判纪要。
- 法律风险与商务选择分开表达，不替用户作商务决定。

## 协作偏好
- 先给结论摘要，再给条款位置、风险、建议和依据。

## 法律安全基线
- 不直接覆盖客户原件；编辑时保留原文、版本和修改依据。
- 未经授权不外发合同、不签署、不提交审批、不执行交易或支付。
- 金额、责任限制、担保、管辖、跨境合规和交付终稿必须人工复核。
- 客户材料和交易信息按最小必要原则进入受控载体。

## 回溯契约
- 条款取舍写入既有决策载体；合同版本和交付状态写入既有版本/交付记录。
- 签约、交割和后合同义务写入项目期限/任务载体，注明责任人和复核状态。
```

## 项目级（local）

```markdown
# 项目：TX-YYYY-001

- 类型：交易项目
- 阶段：尽职调查
- 关键时点：YYYY-MM-DD 初稿交付
- 隐私模式：local

## 受控事实入口
- 真实交易事实位于 `.legal-context.local.md`（0600、gitignore）。
- 仅在任务必要且用户授权时读取最小字段；不得把材料全文复制到输出或日志。

## 文件与回溯
- 合同版本、条款决策、里程碑和交付状态分别沿用项目现有权威载体。
```
