# 08 - M2 工作流与产出深度讲解

## 模块定位

回答"你最常做的几类工作、产出什么文档"。**用户级**，跨项目稳定。建议 3-8 行（列举而非长描述）。

## 回答什么

| 维度 | 问什么 | 为什么需要 |
|---|---|---|
| 主要工作类型 | 哪几类 | 决定 agent 默认工作流 |
| 产出文档 | 产出什么格式文档 | 决定默认输出模板 |
| 频率 | 高频/中频/低频 | agent 按频率排序常见任务 |

## 引导问题范本

agent 会按以下顺序问：

1. **你最常做的 3-5 类工作是什么？**（必答）
   - 列举而非描述（如"合同审查、合同起草、合同谈判支持"）
2. **每类工作产出什么文档？**（必答）
   - 合同审查：审查意见书 / 修改建议 / 风险清单
   - 诉讼：起诉状 / 答辩状 / 代理词 / 证据目录
   - 知产：申请文件 / 审查意见答复 / 复审请求书
3. **有没有特别高频/低频的？**（可选）
   - 高频：合同审查（每周 5+ 份）
   - 低频：法律培训（每季度 1 次）

## 常见答案片段

参考 [templates/modules/M2-workflow.md](../templates/modules/M2-workflow.md) 的完整片段库。

### 诉讼律师

```
## 工作流与产出

- 合同审查：审查意见书（条目式 + 风险等级）
- 起诉/答辩：起诉状、答辩状、管辖异议、证据目录
- 庭审准备：代理词、质证意见、庭审提纲
- 复盘：案件复盘报告（每个结案案件）
```

### 非诉律师

```
## 工作流与产出

- 合同起草：从客户需求到完整条款
- 合同审查：风险清单 + 修改建议 + 商务条款确认
- 法律意见书：针对具体法律问题
- 尽调报告：DD 清单 + 重大事项摘要
```

### 知产律师

```
## 工作流与产出

- 商标/专利申请：申请书 + 委托书 + 主体资格
- 审查意见答复：意见陈述书 + 修改替换页
- 复审/无效：复审请求书 + 证据材料 + 代理词
- 续展/年费：监控清单 + 缴费确认
```

### 企业法务

```
## 工作流与产出

- 合同审查：审查意见 + 修改建议 + 风险提示
- 合规审查：合规清单 + 风险评级 + 整改建议
- 法律培训：培训讲义 + 案例 + 互动问答
- 内部意见：备忘录 + 决策依据
```

### 法律研究/学者

```
## 工作流与产出

- 研究报告：问题 → 文献综述 → 案例分析 → 结论
- 案例汇编：主题分类 + 裁判要旨 + 学理评析
- 培训讲义：知识框架 + 案例 + 实务要点
- 学术论文：引言 → 文献 → 方法 → 论证 → 结论
```

## 好 vs 坏

### 好的 M2

```
## 工作流与产出

- 合同审查：审查意见书（条目式 + 风险等级）
- 起诉/答辩：起诉状、答辩状、证据目录
- 庭审准备：代理词、质证意见、庭审提纲
```

- 列举式，3-5 行
- 每类工作对应明确的产出
- agent 读完就知道"我该用什么格式输出"

### 坏的 M2

```
## 我的工作

我平时主要做合同审查工作。客户会发合同给我，我需要审查合同里的条款是否合规、是否对客户有利。审查完了我会出具审查意见。我也会做一些诉讼相关的工作，包括写起诉状、答辩状等。另外如果客户有法律研究的需求，我也会做一些研究。

```

- 一段话，agent 不易抽取要点
- 没区分"高频/低频"
- 没明确产出格式——agent 会按通用格式输出，不是你想要的

## 与 M3 协作偏好的关系

M2 决定"做什么"，M3 决定"怎么做"（详见 [references/09-module-collab-style.md](09-module-collab-style.md)）。

例：M2 = "合同审查：审查意见书"，M3 = "详尽版（含条款原文引用 + 修改建议对比表）"

agent 在合同审查场景下会同时读 M2 和 M3，输出符合你偏好的审查意见书。

## 跨项目复用：这是用户级

M2 写在用户级，跨项目稳定。**不要把“这个案件我做的是 XX”写到 M2**——项目定位属于 M6，真实事实按 M7 的受控入口管理。
