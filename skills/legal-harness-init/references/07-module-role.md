# 07 - M1 角色身份深度讲解

## 模块定位

回答"我是谁、做什么、执业地域"。**用户级**，跨项目稳定。建议 1-3 行。

## 回答什么

| 维度 | 问什么 | 为什么需要 |
|---|---|---|
| 角色 | 律师 / 法务 / 学者 / 培训师 / 复合 | 决定 agent 默认工作流 |
| 业务方向 | 主营哪些类型工作 | 决定默认产出格式 |
| 执业地域 | 哪个司法管辖区 | 决定默认法域、语言、惯例 |

## 引导问题范本

agent 会按以下顺序问：

1. **你的角色是什么？**（必答）
   - 选项参考：执业律师 / 实习律师 / 律师助理 / 企业法务 / 学者 / 培训师 / 法律科技 PM / 复合（多选）
2. **主要业务方向？**（必答，可多选）
   - 选项参考：诉讼（民商事/刑事/行政）/ 非诉合同 / 知产 / 合规 / 法律研究 / 法律科技 / 其他
3. **执业地域？**（必答）
   - 自由填写（如"上海"、"北京"、"广东深圳"、"美国纽约州"）
4. **如有专业资格**：是否双证（律师 + 专利代理师 / 税务师 / 注会）？

```
律师 · 上海执业 · 主营民商事诉讼（合同纠纷/股权纠纷）+ 知识产权诉讼
```

### 律师 + 主营知产

```
律师 + 专利代理师双证 · 北京执业 · 主营专利申请代理、复审、无效宣告
```

### 律师 + 复合

```
律师 · 广州执业 · 主营非诉合同（公司治理/股权设计）+ 知产（商标/著作权）
```

### 企业法务

```
公司法务 · 北京 · 服务对象为 TMT 行业 · 负责合同审查、合规体系、知识产权管理
```

### 学者/培训师

```
法学学者 · 上海 · 主营法律研究 + 律师培训 · 同时参与公益诉讼
```

## 好 vs 坏

### 好的 M1

```
# 律师 · 上海执业 · 主营民商事诉讼（合同/股权）+ 知识产权诉讼
```

- 一行讲清角色、地域、业务
- 跨项目稳定（不会随案件变化）
- agent 读到就知道默认走"上海法院管辖 / 民商事诉讼惯例"

### 坏的 M1

```
# 关于我

我是 XX 律师，毕业于某大学法学院，执业 10 年。我对工作认真负责。我主要做诉讼和合同审查。我的联系方式是 XXX。

```

- 履历对 agent 无用
- 联系方式属于隐私，不应进 AGENTS.md
- 没讲执业地域——agent 不知道适用哪个法域

## 跨项目复用：这是用户级，不是项目级

M1 写在用户级文件（如 `~/.claude/CLAUDE.md`），跨所有项目生效。

**不要把"我是 XX 案件代理律师"写到 M1**——那是项目级 M6 的内容。

## 用户级 vs 项目级 M1

**用户级 M1**：你的稳定身份（律师/法务/学者 + 地域 + 主营方向）
**项目级 M6 项目上下文**：本项目的具体身份（如"我作为 XX 公司代理人参与 XX 案"）

两者不冲突——用户级说"我是律师"，项目级说"这个项目里我代理谁"。

## 复合身份的写法

如果你的工作身份会随项目变化（如既做执业律师又做培训讲师）：

```
# 律师 + 培训讲师 · 北京执业 · 主营民商事诉讼 + 法律培训课程
```

agent 会按当前项目类型判断主要身份（办案件时是律师，做培训时是讲师）。
