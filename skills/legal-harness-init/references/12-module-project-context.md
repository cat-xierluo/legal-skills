# 12 - M6 最小项目上下文

## 模块定位

让 agent 知道“这是什么项目、处于什么阶段、最近需要关注什么”，而不是把 AGENTS.md 变成客户/案件数据库。默认 4—6 行。

## 默认只问

1. 项目类型：诉讼 / 非诉合同 / 知产 / 企业法务 / 法律研究 / 其他。
2. 项目代号：内部非识别性编号，如 `LIT-2026-001`。
3. 当前阶段。
4. 关键时点：只写日期和事项；起算事实不全时写待补充。
5. 隐私模式以及真实事实的受控入口。
6. 项目已有的文件结构和权威任务/决策/证据/交付载体。

不要默认询问完整案号、当事人名称、金额、统一社会信用代码或联系方式。这些字段不属于长期自动加载指令的必需上下文。

## 默认范本

```markdown
# 项目：{项目代号}

- 类型：{项目类型}
- 阶段：{当前阶段}
- 关键时点：{YYYY-MM-DD + 事项；未知则写待补充}
- 隐私模式：{strict/local/team}
- 受控事实入口：{无 / .legal-context.local.md / 组织批准载体}
- 权威载体：{沿用项目现有约定；未知则待补充}
```

## 项目类型只负责路由

- 诉讼：追问审级、下一关键程序时点和事实入口。
- 非诉：追问业务阶段、下一里程碑和交付记录。
- 知产：追问业务类型、当前程序阶段和期限台账。
- 企业法务：追问服务范围、审批链和组织知识库。
- 法律研究：追问研究范围、截止和引用/交付规范。

不要根据类型自动填标准答案。用户不知道时保留“待补充”。

## 与用户级和 M7 的关系

- 用户级 M1—M5：跨项目稳定的角色、工作方式和法律安全边界。
- M6：项目最小定位。
- M7：只提供受控事实入口和按需读取规则；真实事实不直接复制进 AGENTS.md。

隐私模式详见 [references/18-privacy-and-context.md](18-privacy-and-context.md)。
