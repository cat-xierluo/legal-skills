# 13 - M7 受控事实入口

## 模块定位

M7 不再把完整案件事实直接写入 AGENTS.md。它回答三个问题：真实事实在哪里、何时允许读取、输出或外发时如何最小披露。

## 默认输出

### strict

```markdown
## 受控事实入口

- 本配置不保存真实案件信息。
- 任务需要事实时，请用户按需提供脱敏片段；不得从缺失信息推断案号、主体、金额或期限。
```

### local

```markdown
## 受控事实入口

- 真实事实位置：`.legal-context.local.md`（本地、0600、gitignore）。
- 仅在当前任务需要且用户已授权时读取；只提取完成任务所必需的字段。
- 输出、日志、Git 和外部工具调用继续脱敏，不复制材料全文。
```

### team

```markdown
## 受控事实入口

- 权威事实载体：{组织批准的私有载体或路径}。
- 访问条件：{角色/审批/项目范围}。
- 对外披露：{脱敏和复核规则}。
- 不在本文件记录登录凭证、高敏身份号或材料正文。
```

## 受控事实最小字段

受控载体可按任务需要记录：

- 项目代号和事项类型；
- 字段值及来源材料/页码；
- 更新时间与核验状态；
- 可访问角色；
- 期限的起算事实和计算依据；
- 必要时的脱敏值。

不要把整个案卷、聊天记录或客户材料复制到上下文文件。优先引用本地材料路径、证据编号和页码。

## 信息缺口规则

- 缺案号、送达日期、主体身份、适用法域等关键事实时，列出缺口并请求补充。
- 未核验内容标“待核验”，不写成确定事实。
- 事实与推断分段表达；法律结论保留来源时间和适用范围。
- 项目进展改变事实时，更新事实权威来源；如形成策略取舍，再记录决策。

完整隐私治理见 [references/18-privacy-and-context.md](18-privacy-and-context.md)。
