# 13 - M7 案件/项目关键事实深度讲解

## 模块定位

回答"这个项目/案件的具体关键事实是什么"。**项目级**，每个项目不同。按所选项目类型动态问。建议 5-15 行。

## 与 M6 的关系

- **M6** = 宏观（类型、委托人、阶段）
- **M7** = 具体（案号、管辖、对方、关键时点/申请号、商品类别/课题等）

M6 + M7 一起回答"这个项目到底是什么"。

## 按项目类型动态问

| 项目类型 | 必问 | 可选问 |
|---|---|---|
| 诉讼 | 案号、管辖法院、对方当事人、当前阶段、开庭日期/举证期限 | 律师团队、案件标的、是否涉外 |
| 非诉合同 | 项目编号、业务类型（DD/谈判/签约/交割）、客户、对方主体 | 标的项目金额、是否跨境 |
| 知产 | 申请号、类型（商标/专利/著作权/商业秘密）、商品/分类号、当前阶段 | 驳回/复审状态、续展/年费节点 |
| 企业法务 | 服务对象（部门/业务线）、服务范围、当前重点 | 集团架构、合规体系 |
| 法律研究 | 课题、委托方、截止日期、预期交付物 | 研究范围限定、引用格式要求 |

## 引导问题范本（按项目类型）

### 诉讼

1. **案号？**（必答）
2. **管辖法院？**（必答）
3. **对方当事人？**（必答）
4. **当前阶段？**（必答）
5. **关键时点？**（必答）
   - 开庭日期
   - 举证期限
   - 上诉期（如已判决）
6. **律师团队？**（可选）
7. **案件标的？**（可选）
8. **是否涉外？**（可选）

### 非诉合同

1. **业务类型？**（必答）
   - DD / 谈判 / 签约 / 交割 / 后合同
2. **客户？**（必答）
3. **对方主体？**（必答）
4. **标的项目金额？**（可选）
5. **是否跨境？**（可选）
6. **关键里程碑？**（必答）
   - DD 报告 / 签约日 / 交割日

### 知产

1. **申请号？**（必答）
2. **类型？**（必答）
   - 商标 / 发明专利 / 实用新型 / 外观设计 / 著作权 / 商业秘密
3. **商品/分类号？**（必答，按类型）
4. **当前阶段？**（必答）
5. **驳回/复审/无效状态？**（可选，按需）
6. **续展/年费节点？**（可选，按需）

### 企业法务

1. **服务对象？**（必答）
   - 部门 / 业务线 / 集团
2. **服务范围？**（必答）
   - 合同审查 / 合规 / 诉讼管理 / 其他
3. **当前重点？**（必答）

### 法律研究

1. **课题？**（必答）
2. **委托方？**（必答）
3. **截止日期？**（必答）
4. **预期交付物？**（必答）
5. **研究范围限定？**（可选）
6. **引用格式要求？**（可选）

## 好 vs 坏

### 好的 M7

```
## 关键事实

- 案号：(2026)沪0115民初1234号
- 管辖法院：上海浦东新区法院
- 对方：上海 XYZ 有限公司
- 关键时点：举证 09-01，开庭 09-15
```

- 列举具体事实
- 关键时点显式列出（agent 可自动监控）
- agent 读完能精准工作

### 坏的 M7

```
## 关键事实

这个案件是上海法院在管的，对方是另一家公司。我们已经在准备起诉状了。

```

- 没案号——无法检索
- "另一家公司"不具体
- "准备起诉状了"是动作不是事实

## 涉及敏感信息时的处理

委托人/对方当事人姓名、统一社会信用代码属于敏感信息：

- **生产环境（真实项目）**：按实际填写，但建议加密存储
- **演示/培训环境**：用脱敏的占位符（如 `{委托人}` `{对方}` `{申请号}`）
- **公开发布的 AGENTS.md 范例**：必须用占位符

参考 [templates/modules/M7-case-facts.md](../templates/modules/M7-case-facts.md) 中"脱敏范例"段落。

## 跨项目复用

M7 是项目级，**每个项目一份**。M7 内容随项目变化（对方变更、新增证据等），agent 应主动提示更新。
