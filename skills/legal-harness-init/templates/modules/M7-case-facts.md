# M7 案件/项目关键事实片段库

agent 在用户卡壳时主动调出本片段库参考。本文件含**按项目类型动态问**的完整问法。

## 使用场景

用户卡在以下问题时参考：

- "本案件的关键事实怎么写？"
- "案号/管辖/对方怎么填？"
- "知产项目的关键事实怎么组织？"

## 诉讼关键事实

```markdown
## 关键事实

- 案号：[YYYY]{法院代号}+民/刑/行+初/终+XXXX号
- 管辖法院：{法院全称}
- 对方当事人：{对方名称}（统一社会信用代码 {代码}）
- 案由：{案由}
- 当前阶段：{阶段}
- 关键时点：{关键时点}
- 案件标的：人民币 {金额} 万元
- 是否涉外：{是/否}
- 律师团队：{律师团队}
```

### 诉讼关键事实问法

1. 案号？
2. 管辖法院？
3. 对方当事人？
4. 当前阶段？
5. 关键时点（开庭日期/举证期限/上诉期）？
6. 律师团队？
7. 案件标的？
8. 是否涉外？

## 完整组合片段

### 诉讼 + 一审 + 涉外

```markdown
## 关键事实

- 案号：(2026)沪0115民初1234号
- 管辖法院：上海市浦东新区人民法院
- 对方当事人：Singapore XYZ Pte Ltd（注册号 202XXXXXX）
- 案由：国际货物买卖合同纠纷
- 当前阶段：一审审理中
- 关键时点：举证期限 2026-09-01，开庭 2026-09-15
- 案件标的：美元 100 万
- 是否涉外：是（涉新加坡）
- 律师团队：杨律师 + 王律师（涉外）
```

### 知产 + 商标驳回复审

```markdown
## 关键事实

- 申请号：商标 12345678
- 类型：商标（第 9 类）
- 商标名称：ABC TECH
- 申请日期：2025-03-10
- 当前阶段：驳回复审中（复审请求 2025-09-10 提交）
- 驳回原因：与引证商标近似
- 引证商标：12345000（已注册，第 9 类）
- 关键节点：复审决定预计 2026-10
```

### 法律研究

```markdown
## 关键事实

- 课题：生成式 AI 著作权侵权专题
- 委托方：上海市律师协会
- 截止日期：2026-12-31
- 预期交付物：研究报告（3 万字）+ 案例汇编（50 例）+ 培训讲义
- 研究范围：中国法（与美国法对比）
- 引用格式：脚注 + 文末参考文献（GB/T 7714）
```

## 后续动作

agent 拿到用户回答后：

1. 按项目类型选最贴近的片段
2. 决定是否需要补充可选问（律师团队、案件标的等）
3. 写入 AGENTS.md 的 M7 段（建议 5-15 行）

注意：

- 涉及敏感信息（统一社会信用代码、身份证号等）在公开范例中必须脱敏
- 关键时点显式列出，agent 可自动监控
- 项目进展后 M7 内容可能变化，agent 应主动提示更新
