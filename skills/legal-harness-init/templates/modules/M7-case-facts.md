# M7 受控事实入口片段库

## strict

```markdown
## 受控事实入口

- 本配置不保存真实案件信息。
- 任务需要事实时，请用户按需提供脱敏片段。
- 缺失主体、日期、送达、金额或法域信息时列出缺口，不得猜测。
```

## local

```markdown
## 受控事实入口

- 真实事实：`.legal-context.local.md`（权限 0600，必须加入 .gitignore）。
- 仅在任务必要且用户已授权时读取最小字段。
- 输出、日志、Git 和外部工具调用继续脱敏；不复制材料全文。
```

## team

```markdown
## 受控事实入口

- 权威载体：{组织批准的私有 DMS/知识库/私有仓库路径}。
- 访问条件：{角色、项目范围、审批要求}。
- 可披露字段：{最小字段或脱敏规则}。
- 禁止在本配置写入凭证、高敏个人身份号或材料正文。
```

受控载体中的事实建议包含“值、来源路径/证据编号/页码、更新时间、核验状态”，并以项目代号关联。公开范例只使用 `{占位符}`。
