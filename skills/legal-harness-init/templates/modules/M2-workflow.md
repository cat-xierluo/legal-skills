# M2 工作流与产出片段库

agent 在用户卡壳时主动调出本片段库参考。

## 使用场景

用户卡在以下问题时参考：

- "我最常做什么？"
- "产出什么文档？"
- "怎么写工作流段？"

## 按角色类型的工作流片段

### 诉讼律师

```markdown
## 工作流与产出

- 合同审查：审查意见书（条目式 + 风险等级）
- 起诉/答辩：起诉状、答辩状、管辖异议、证据目录
- 庭审准备：代理词、质证意见、庭审提纲
- 复盘：案件复盘报告
```

### 非诉律师

```markdown
## 工作流与产出

- 合同起草：从客户需求到完整条款
- 合同审查：风险清单 + 修改建议 + 商务条款确认
- 法律意见书：针对具体法律问题
- 尽调报告：DD 清单 + 重大事项摘要
- 谈判支持：会议纪要 + 条款对比 + 风险提示
```

### 知产律师

```markdown
## 工作流与产出

- 商标/专利申请：申请书 + 委托书 + 主体资格
- 审查意见答复：意见陈述书 + 修改替换页
- 复审/无效：复审请求书 + 证据材料 + 代理词
- 续展/年费：监控清单 + 缴费确认
- 检索/分析：检索报告 + 新颖性创造性分析
```

### 企业法务

```markdown
## 工作流与产出

- 合同审查：审查意见 + 修改建议 + 风险提示（给业务部门看，少用术语）
- 合规审查：合规清单 + 风险评级 + 整改建议
- 法律培训：培训讲义 + 案例 + 互动问答
- 内部意见：备忘录 + 决策依据
```

### 法律研究/学者

```markdown
## 工作流与产出

- 研究报告：问题 → 文献综述 → 案例分析 → 结论
- 案例汇编：主题分类 + 裁判要旨 + 学理评析
- 培训讲义：知识框架 + 案例 + 实务要点
- 学术论文：引言 → 文献 → 方法 → 论证 → 结论
```

### 跨界（律师 + 法律科技）

```markdown
## 工作流与产出

- 律师本职：合同审查 + 法律意见书 + 诉讼
- 法律科技：产品需求文档 + 技术合同 + 合规审查
- 跨界协作：律师 + 工程师协作的协议设计
```

## 文档产出格式片段

### 审查意见书格式

```markdown
## 风险等级

- 🔴 高风险（必须修改）
- 🟡 中风险（建议修改）
- 🟢 低风险（可选修改）

## 风险条目

### 1. 条款 X.Y

- 原文：「...」
- 风险：...
- 修改建议：...
- 依据：法条/案例
```

### 起诉状格式

```markdown
# 民事起诉状

## 原告

- 姓名/名称：...
- 住所：...
- 统一社会信用代码/身份证号：...

## 被告

- 姓名/名称：...
- 住所：...

## 诉讼请求

1. 请求判令...
2. 请求判令...

## 事实与理由

...

## 此致

{法院名称}

## 起诉人

{姓名/名称 + 盖章 + 日期}
```

### 法律意见书格式

```markdown
# 法律意见书

## 致：{委托人}

## 关于：{法律问题}

## 律师意见

### 一、事实概要

...

### 二、法律分析

#### （一）适用法律

#### （二）法律依据

#### （三）论证

### 三、结论

...

## 律师

{姓名 + 执业证号 + 律所名称 + 日期}
```

### 尽调报告格式

```markdown
# 法律尽职调查报告

## 委托方

## 标的公司

## 调查范围

## 重大事项摘要

- 🔴 重大风险
- 🟡 中等风险
- 🟢 一般关注

## 详细调查发现

### 1. 公司治理

### 2. 主要资产

### 3. 重大合同

### 4. 诉讼/仲裁

### 5. 知识产权

### 6. 劳动人事

### 7. 税务

## 结论与建议

```

### 合同审查意见格式

```markdown
# 合同审查意见

## 合同基本信息

- 合同名称：...
- 双方当事人：...
- 审查日期：YYYY-MM-DD

## 总体评价

🔴 高风险 N 条 / 🟡 中风险 N 条 / 🟢 低风险 N 条

## 详细意见

### 第 X 条：{条款名称}

- 原文：「...」
- 意见：...
- 修改建议：「...」
```

## 复合身份的工作流

### 律师 + 培训师

```markdown
## 工作流与产出

- 律师本职：合同审查 + 诉讼 + 法律咨询
- 培训：律师培训讲义 + 案例库 + 互动设计
- 研究：律师实务研究文章
```

### 公司法务 + 兼职律师

```markdown
## 工作流与产出

- 公司法务本职：内部合同 + 合规 + 知识产权管理
- 兼职律师：商事诉讼 + 法律意见
```

## 高频 vs 低频标注（可选）

agent 可让用户标注：

```markdown
## 工作流与产出（高频标记 ⭐）

- ⭐ 合同审查（每周 5+ 份）：审查意见书
- ⭐ 起诉状（每月 1-2 份）：起诉状
- 培训讲义（每季度 1 次）：培训讲义
- 法律研究（不定期）：研究报告
```

## 后续动作

agent 拿到用户回答后：

1. 取最贴近的片段
2. 根据用户的实际工作类型微调
3. 写入 AGENTS.md 的 M2 段（建议 3-8 行）

不需要每类工作都写——只写最常做的 3-5 类。
