# M5 回溯契约片段库

先询问项目已用什么记录决策、证据、期限和交付版本；以下名称只是常见例子，不是必须创建的文件。

```markdown
## 回溯契约

- 决策与取舍：写入项目既有决策载体，至少记录日期、背景、方案、理由、影响和复核人。
- 证据材料：新增、来源、完整性、核验状态或证明目的变化写入既有证据索引；不把材料正文复制到公开日志。
- 期限：写入既有期限台账、任务源或经授权日历，记录起算事实、计算依据、截止、责任人和复核状态；缺信息时不猜测。
- 交付：版本、审批和发送状态写入既有交付记录；任何对外动作仍需明确授权。
- 项目没有对应载体或权威来源不明时，先询问并标记待补充，不自行创建空文档。
- 所有记录遵守最小必要原则和当前隐私模式。
```

## 常见载体映射

| 对象 | 常见载体 | 不是 |
|---|---|---|
| 决策 | `DECISIONS.md`、案件管理系统决策记录 | 把事实变化伪装成自主决定 |
| 证据 | 证据目录、证据索引、DMS | 把新增证据机械写入软件 CHANGELOG |
| 期限 | `TASKS.md`、期限台账、授权日历 | 在起算事实不足时猜截止日 |
| 交付 | `CHANGELOG.md`、交付记录、版本系统 | 把内部推理当用户可见变化 |

## 字段片段

### 决策

```markdown
- 日期：YYYY-MM-DD
- 背景与信息缺口：...
- 方案：A / B
- 决定及理由：...
- 影响：...
- 复核人：...
```

### 证据

```markdown
- 材料标识：...
- 来源与取得时间：...
- 完整性/核验状态：...
- 证明目的：...
- 保管位置：...
```

### 期限

```markdown
- 事项：...
- 起算事实：...
- 计算依据：...
- 截止：YYYY-MM-DD（待复核）
- 责任人/复核人：...
```

### 交付

```markdown
- 版本与日期：...
- 变更摘要：...
- 接收方：...
- 审批/发送状态：...
```
