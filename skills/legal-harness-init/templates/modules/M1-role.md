# M1 角色身份片段库

agent 在用户卡壳时主动调出本片段库参考。本文件是**片段集合**，不直接写入用户 AGENTS.md。

## 使用场景

用户卡在以下问题时参考本文件：

- "我的角色是什么？"（不知道用什么词描述）
- "主要业务方向怎么填？"
- "执业地域怎么写？"

## 角色片段

### 律师（细分）

```markdown
# 律师 · {城市}执业 · 主营{业务方向1}+{业务方向2}
```

例：

- `# 律师 · 上海执业 · 主营民商事诉讼（合同纠纷/股权纠纷）`
- `# 律师 · 北京执业 · 主营刑事辩护 + 公司刑事合规`
- `# 律师 · 广东深圳执业 · 主营非诉合同（公司治理/股权设计）`
- `# 律师 · 北京执业 · 主营知产（专利申请代理/复审/无效宣告）`
- `# 律师 · 上海执业 · 主营诉讼 + 法律科技产品`

### 双证律师

```markdown
# 律师 + {其他证}双证 · {城市}执业 · 主营{业务方向}
```

例：

- `# 律师 + 专利代理师双证 · 北京执业 · 主营专利申请代理、复审、无效宣告`
- `# 律师 + 注册会计师双证 · 上海执业 · 主营商事诉讼 + 公司治理`
- `# 律师 + 税务师双证 · 北京执业 · 主营涉税法律服务 + 公司治理`

### 实习律师/律师助理

```markdown
# 实习律师 · {城市} · {主办律师姓名}团队 · 主营{业务方向}
```

例：

- `# 实习律师 · 上海 · 张律师团队 · 主营民商事诉讼辅助`

### 企业法务

```markdown
# {公司类型}法务 · {城市} · 服务对象为{行业}{公司规模} · 负责{服务范围}
```

例：

- `# 互联网公司法务 · 北京 · 服务 TMT 业务线 · 负责合同审查、合规体系、知识产权管理`
- `# 金融公司法务 · 上海 · 服务零售业务 · 负责日常合同 + 监管合规`
- `# 制造业法务 · 广东深圳 · 服务集团总部 · 负责合同管理、知识产权、合规`

### 法学学者/培训师

```markdown
# 法学学者 · {城市} · 主营{研究方向}+{教学方向}
```

例：

- `# 法学副教授 · 上海 · 主营知识产权法研究 + 律师培训`
- `# 法律研究 · 北京 · 主营网络法研究 + 公益诉讼参与`

### 法律科技产品经理/律师跨界

```markdown
# 法律科技{职业} · {城市} · 主营{业务方向}+{跨界方向}
```

例：

- `# 法律科技产品经理 · 上海 · 主营 AI 法律工具产品 + 律师兼职`
- `# 律师 · 北京 · 兼法律科技创业 · 主营商事诉讼 + 法律 SaaS`

### 复合身份

```markdown
# {身份1}+{身份2} · {城市} · 主营{业务方向1}+{业务方向2}
```

例：

- `# 律师 + 仲裁员 · 上海 · 主营商事诉讼 + 仲裁代理`
- `# 公司法务 + 兼职律师 · 北京 · 主营内部合规 + 兼职商事诉讼`

## 业务方向片段

### 诉讼细分

- 民商事诉讼（合同纠纷、股权纠纷、侵权纠纷）
- 刑事辩护（经济犯罪、职务犯罪、网络犯罪）
- 行政诉讼（行政复议、行政诉讼、国家赔偿）
- 知识产权诉讼（专利侵权、商标侵权、著作权侵权、不正当竞争）
- 劳动争议（劳动合同、社保、解除纠纷）
- 家事诉讼（婚姻、继承、抚养）

### 非诉合同细分

- 公司治理（章程设计、股权架构、董监高治理）
- 股权设计（股权激励、员工持股、股权融资）
- 并购重组（收购、合并、分立、重组）
- 投融资（PE/VC、IPO、定增、并购贷款）
- 跨境投资（ODI、FDI、跨境合规）
- 合规（反垄断、数据合规、反舞弊、ESG）

### 知产细分

- 专利（发明、实用新型、外观设计、PCT）
- 商标（注册、复审、无效、续展、转让）
- 著作权（登记、维权、许可）
- 商业秘密（保护、维权、合同）
- 不正当竞争（反不正当竞争法案件）
- 技术合同（技术开发、技术转让、技术服务）

### 企业法务细分

- 合同审查（销售合同、采购合同、合作协议）
- 合规体系（反垄断、数据保护、反贿赂）
- 知识产权管理（商标管理、专利管理、商业秘密）
- 争议管理（诉讼管理、仲裁管理、调解）
- 监管沟通（金融监管、数据监管、行业监管）

### 法律研究细分

- 法学研究（民法、刑法、行政法、知识产权法）
- 法律实务研究（合同实务、诉讼实务、合规实务）
- 跨学科研究（法律经济学、法律社会学、网络法）
- 比较法研究（中国法 vs 美国法 vs 欧盟法）

## 执业地域片段

中国大陆常用地域：

- 上海 / 北京 / 广东（广州/深圳）/ 浙江（杭州）/ 江苏（南京/苏州）/ 四川（成都）/ 重庆 / 天津
- 中国香港 / 中国澳门 / 中国台湾

涉外业务常用：

- 美国（纽约/加州/特拉华）
- 英国（伦敦）
- 新加坡 / 香港
- 开曼 / BVI（离岸）

## 后续动作

agent 拿到用户回答后：

1. 取最贴近的片段
2. 根据用户的具体角色/地域/方向微调
3. 写入 AGENTS.md 的 M1 段（建议 1-3 行）

不需要长描述——M1 越简洁越好。
