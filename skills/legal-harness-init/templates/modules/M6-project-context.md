# M6 项目上下文片段库

agent 在用户卡壳时主动调出本片段库参考。

## 使用场景

用户卡在以下问题时参考：

- "项目编号怎么写？"
- "当前阶段怎么标注？"
- "项目上下文段怎么组织？"

## 按项目类型的上下文片段

### 诉讼

```markdown
# 项目：诉讼 · [YYYY]法院代号+案号

## 上下文

- 类型：{案由}（{诉讼类型}）
- 委托人：{委托人}（{自然人/法人}）
- 对方当事人：{对方}
- 当前阶段：{阶段}
- 关键时点：{关键时点列表}
```

### 非诉合同

```markdown
# 项目：非诉合同 · {YYMMDD} {客户简称} {业务类型}

## 上下文

- 类型：{业务类型}
- 委托人：{客户}
- 标的公司/对方：{对方}
- 当前阶段：{阶段}
- 关键里程碑：{里程碑列表}
```

### 知产

```markdown
# 项目：知产 · {类型} {申请号} {业务子类型}

## 上下文

- 类型：{类型} {业务子类型}
- 申请号：{申请号}
- 委托方：{委托方}
- 当前阶段：{阶段}
- 关键节点：{节点列表}
```

### 企业法务

## 编号格式片段

### 诉讼案号

格式：`[YYYY]法院代号+民/刑/行+初/终+XXXX号`

例：

- `(2026)沪0115民初1234号`（上海浦东新区法院 2026 年民商事初字第 1234 号）
- `(2026)京01刑终567号`（北京一中院 2026 年刑事终字第 567 号）
- `(2026)最高法民申890号`（最高法院 2026 年民商事再审申请字第 890 号）

### 非诉项目编号

格式：`{YYMMDD} {客户简称} {业务类型}`

例：

- `260812 ABC 并购 DD`（ABC 客户的并购 DD 项目）
- `260815 XYZ 股权激励设计`（XYZ 客户的股权激励项目）

### 知产申请号

- 商标：`商标 12345678`（12 位数）或 `商标 12345678A`（含字母）
- 专利：`CN2024XXXXXX.X`（发明）/ `CN2024YXXXXXXX.X`（实用新型）/ `CN2024DXXXXXXX.X`（外观）
- PCT：`PCT/CN2024/XXXXXX`

### 法务项目

格式：`{YYYY} {Q} {业务类型}` 或自定义

例：

- `2026 Q3 合同审查专项`
- `2026 集团数据合规审计`

### 研究课题

格式：`{课题简称}` 或 `{YYMM} {课题}`

例：

- `AI 著作权侵权专题`
- `2601 生成式 AI 著作权侵权`

## 阶段片段

### 诉讼阶段

- 诉前（诉前调解、律师函）
- 立案
- 审理（一审）
- 判决
- 上诉
- 二审
- 再审
- 执行
- 终结

### 非诉阶段

- DD（尽职调查）
- 谈判
- 签约
- 交割
- 后合同

### 知产阶段

- 申请
- 受理
- 审查
- 驳回
- 复审
- 无效
- 注册
- 续展
- 终止

### 企业法务阶段

- 常法服务（长期）
- 专项（合同审查、合规、知识产权管理等）
- 突发（紧急事件应对）

### 法律研究阶段

- 选题
- 调研
- 撰写
- 评审
- 发表

## 关键时点片段

### 诉讼

- 开庭日期
- 举证期限
- 上诉期
- 答辩期
- 管辖权异议期

### 非诉

- DD 报告交付日
- 签约日
- 交割日
- 后合同义务截止

### 知产

- 审查决定预计
- 复审决定预计
- 续展截止
- 年费截止

### 企业法务

- 合同定稿日
- 内部审批日
- 监管报告日

### 法律研究

- 调研截止
- 初稿截止
- 评审截止
- 发表截止

## 完整组合片段

### 诉讼 + 一审

```markdown
# 项目：诉讼 · (2026)沪0115民初1234号

## 上下文

- 类型：合同纠纷（民商事诉讼）
- 委托人：上海 ABC 科技有限公司
- 对方当事人：上海 XYZ 有限公司
- 当前阶段：一审审理中
- 关键时点：举证期限 2026-09-01，开庭 2026-09-15
```

### 知产 + 商标驳回复审

```markdown
# 项目：知产 · 商标 12345678 驳回复审

## 上下文

- 类型：商标驳回复审
- 申请号：12345678
- 委托方：上海 ABC 公司
- 当前阶段：驳回复审中
- 关键节点：复审决定预计 2026-10
```

### 法律研究

```markdown
# 项目：研究 · AI 著作权侵权专题

## 上下文

- 类型：法律研究（专题）
- 委托方：上海市律师协会
- 截止日期：2026-12-31
- 预期交付物：研究报告（3 万字）+ 案例汇编（50 例）+ 培训讲义
```

## 后续动作

agent 拿到用户回答后：

1. 取最贴近的片段
2. 根据用户实际项目调整
3. 写入 AGENTS.md 的 M6 段（建议 3-5 行）

注意：

- 编号必须准确（agent 会用来检索/复盘）
- 阶段用于 agent 判断当前紧迫度
- 关键时点用于自动监控（TASKS）
