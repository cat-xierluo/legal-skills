# M6 最小项目上下文片段库

默认使用非识别性项目代号，不在 AGENTS.md 记录真实案号、当事人、金额或联系方式。

```markdown
# 项目：{内部项目代号}

- 类型：{诉讼/非诉合同/知产/企业法务/法律研究/其他}
- 阶段：{当前阶段}
- 关键时点：{YYYY-MM-DD + 事项；未知则待补充}
- 隐私模式：{strict/local/team}
- 受控事实入口：{无 / .legal-context.local.md / 组织批准载体}
- 权威载体：{项目已有任务/期限/证据/决策/交付载体}
```

项目类型只决定下一条必要问题：

- 诉讼：审级和下一程序时点；
- 非诉：业务阶段和下一里程碑；
- 知产：业务类型、程序阶段和期限；
- 企业法务：服务范围和审批链；
- 法律研究：研究范围、截止和交付形式。

用户不知道的字段写“待补充”，不要根据项目类型替用户生成答案。
