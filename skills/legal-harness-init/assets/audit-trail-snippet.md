# 回溯契约通用片段

> 使用前先把 `{载体}` 替换成项目已经启用的权威来源；不存在时保留“待补充”，不要为了套模板创建空文档。

```markdown
## 回溯契约

- 决策/取舍 → {现有决策载体}：日期、背景、方案、理由、影响、复核人。
- 证据新增、来源、完整性或证明目的变化 → {现有证据索引}：材料标识、来源、核验状态、证明目的、保管位置。
- 期限变化 → {现有期限台账/任务源/授权日历}：起算事实、计算依据、截止、责任人、复核状态。
- 交付版本、审批或发送状态变化 → {现有交付记录}：版本、日期、变更摘要、接收方、状态。
- 对外或不可逆动作仍须明确授权；信息不足时列出缺口，不猜测。
- 同一事实只维护一个权威来源，不复制材料正文，不写入凭证或无关客户信息。
```
