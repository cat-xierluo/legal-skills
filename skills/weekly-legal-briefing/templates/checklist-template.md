# 复核清单模板

每期生成后,自动产出一份 `archive/法律周报_..._DRAFT.checklist.md`,供 {editor} 复核时勾选。

## 一、信源白名单合规

- [ ] 本期所有信源均在 `config/sources-whitelist.txt` 内
- [ ] 白名单外信源 0 漏入（如有,删除该条）
- [ ] 信源域名逐条点击可访问

## 二、案例板块案号可回查

- [ ] 案例研究板块共 {N} 条,案号 {list}
- [ ] 逐条在 https://wenshu.court.gov.cn 检索
- [ ] 检索失败 {M} 条 → 已剔除

## 三、日期窗口合规

- [ ] 本期窗口：{YYYY-MM-DD} - {YYYY-MM-DD}
- [ ] 本周动态所有日期在窗口内
- [ ] 政策发布 / 施行日期在窗口内或显式标注历史政策

## 四、文本纪律

- [ ] 无臆测表述
- [ ] 改写为"行业观察"或剔除
- [ ] 风险提示均有"对本类企业的启示"段落
- [ ] 不出现真实客户名 / 案号以外的真实案件标识

## 五、排版与导出

- [ ] PDF 封面应用正确（{cover_style}）
- [ ] 页眉页脚正常,页码连续
- [ ] 字体未缺失（衬线中文已 fallback）
- [ ] 文件名带 `_DRAFT` 后缀,未误发版

## 六、发布动作（人工）

- [ ] 把文件后缀 `_DRAFT` 改为 `_V1`（或其他发版标签）
- [ ] 上传到客户渠道（邮件 / 微信 / 客户系统）
- [ ] 在 archive/_meta.jsonl 中登记发版状态
