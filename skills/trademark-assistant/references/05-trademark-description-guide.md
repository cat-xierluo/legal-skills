# 商标说明撰写指南

商标说明不是所有商标申请的一般必填项。根据《商标法实施条例》第十三条，三维标志、颜色组合、声音标志须按类型声明并说明使用方式，声音标志还须按规定描述；商标为外文或含外文的，应说明含义。其他商标只在确有需要时客观说明构成、文字含义或图样特征，不在商标说明中认定显著性、专用权范围或注册成功率。

## 一、图形/组合商标分析流程

对于包含图形元素的商标，必须先使用图像理解工具分析商标图片，再撰写说明。

### 1. 图像理解能力选择

1. 首选当前模型原生视觉能力，直接读取用户提供的商标图样。
2. 当前模型无法读取图片时，使用运行环境已启用的通用图像理解工具；调用前确认工具实际可用，不写死平台或工具名称。
3. 没有可用视觉能力时，请用户用文字描述形状、构图、字体、颜色和相对位置，并明确标注“依据用户描述，未核对原图”。

### 2. 分析提示词模板

```text
请详细描述这个商标的构成要素：
1. 商标类型（纯文字/纯图形/组合商标）
2. 文字内容（中文/英文/拼音等）
3. 图形元素（如有）
4. 字体设计特点（普通字体还是艺术字/设计字体，具体设计特征）
5. 颜色使用（如有）
6. 整体设计风格及各元素之间的统一性
```

### 3. 分析要点

从图像分析结果中提取以下关键信息：

- **商标类型**：纯文字 / 纯图形 / 组合商标
- **文字内容**：中文 / 英文 / 拼音 / 数字
- **图形元素**：形状、构图、风格特点
- **字体设计**：普通字体还是艺术字，具体设计特征（弧线、几何化、连笔等）
- **颜色使用**：主色调、配色方案
- **设计风格统一性**：图形与文字的风格是否一致，传达的寓意

### 4. 设计特征描述技巧

#### 字体设计描述

- **弧线元素**：描述哪些字母/笔画使用了弧线设计，弧线传达的视觉效果（灵动、柔和、活力等）
- **几何化处理**：描述字母的几何造型特点（三角形、圆形、菱形等）
- **特殊变形**：描述独特的字母变形（如O内部嵌套图形、字母连笔等）

示例：
> 英文"NOVA ARTS"采用自行设计的艺术字体，全部字母均融入弧线设计元素，与左侧图形的几何造型风格统一。弧线设计寓意生机与活力，传递品牌灵动、创新的特质。

#### 图形设计描述

- **构成元素**：描述图形由哪些基本形状组成
- **构图特点**：对称/不对称、中心/偏心、紧凑/舒展
- **视觉风格**：现代/古典、简约/繁复、科技感/艺术感

示例：
> 左侧为抽象几何图形，由对称的三角形、菱形组合而成，中心嵌有星形图案，整体呈现规整而富有张力的视觉效果。

## 二、文字商标说明的核心内容

### 1. 明确商标类型

直接声明商标的构成要素。

**示例**：

- "本商标由纯中文文字'XX'构成，无图形、字母、数字或其他设计要素。"
- "本商标由中文'XX'及英文'XX'组合构成。"

### 2. 说明文字内容

**普通字体**：
- "商标文字为普通印刷体，无特殊设计。"

**自定义字体/艺术字**：
- "商标文字采用艺术字体，其中××笔画呈××形态。"

### 3. 解释文字含义

**自创词/无固有含义**（仅在申请人确认后使用）：
- "据申请人说明，商标文字'XX'为自创词，无特定含义。"

**有特殊含义或来源**：
- "商标文字'XX'源自古籍《XXX》，意为'XX'。"

### 4. 通用或描述性词语

只客观记录文字构成和通常含义，不写“非行业通用名称”“具有显著性”等结论。确需作放弃专用权等权利声明时，先由申请人或专业人员确认程序依据、声明范围和可能后果，不自动生成固定话术。

## 三、常见错误避免

- ❌ 未经申请人确认，声称文字为“独创”或“无特殊含义”
- ❌ 使用“具有显著性”“需保护其独特字形”“保护范围更广”等法律结论
- ❌ 使用“著名品牌”“驰名商标”等主观或法定认定用语
- ❌ 添加与商标无关的广告语、企业介绍或注册成功率判断
- ❌ 把普通着色图样与“颜色组合商标”混为一谈；是否指定颜色和如何描述，以实际申请类型及图样为准

## 四、实际填写示例

### 案例1：普通字体商标

> 本商标为纯文字商标，由中文"星辰"构成，采用普通黑体字，无图形或其他设计要素。"星辰"为常见词汇，含义为"夜晚的天空"。

### 案例2：艺术字体商标

> 本商标为纯文字商标，由英文"ZENITH"构成，字体为倾斜加粗艺术体，无其他图形要素。"ZENITH"意为“顶峰”。

### 案例3：自创词商标

> 本商标为纯文字商标，由中文"咔趣"构成，采用标准宋体字，无图形设计。据申请人说明，“咔趣”为自创词，无特定含义。

### 案例4：组合商标

> 本商标由中文"雅芙"及其拼音"YAFU"构成。

## 五、特殊情况处理

### 含拼音或外文

客观说明构成要素即可（权利保护范围不在商标说明中认定）：
- "商标由中文'雅芙'及其拼音'YAFU'构成。"

### 放弃部分权利

不得仅因含“优选”“品质”等词就自动生成放弃专用权声明。确需声明时，先提示由申请人或专业人员确认；在获得明确指示前，输出“是否需要权利声明：待确认”。

## 六、官方要求

- 商标说明应简明、客观，并以提交系统当次显示的字段限制为准；不要把经验性的字数上限写成固定法定要求
- 以三维标志、颜色组合、声音标志申请时，按《商标法实施条例》第十三条说明使用方式；声音描述与声音样本应一致
- 商标为外文或含外文时，应说明含义；无法确定含义时先向申请人核实，不得臆测
- 是否指定颜色应结合实际申请图样和策略确认，不在说明中承诺权利范围

法源核对：国家知识产权局《[中华人民共和国商标法实施条例（2014年修订）](https://www.cnipa.gov.cn/art/2015/9/14/art_96_28188.html)》第十三条（核对日期：2026-07-30）。

## 七、生成模板

根据商标类型自动生成说明：

```markdown
## 商标说明

本商标为**{商标类型}**商标，由**{构成要素}**构成，{字体说明}{含义说明}。

**要素构成**：{详细描述各要素}

**含义说明**：{含义或"无特殊含义"}

**其他声明**：{仅填写已经申请人或专业人员确认、且有程序依据的声明；否则写“无”或“待确认”}
```
