# Case 02: 著作权侵权代理词 — 蒸馏输出

> 以下 prompt 由 five-question-distill v0.1.0 蒸馏产出，请调用 legal-skill-creator 编译为正式 Skill。

- **jurisdiction**：CN
- **stage**：first_instance

## 二、五问要素

### 1. 输入什么（Inputs）

**必要输入**：
- 案件基本信息（原告、被告、案由、管辖法院、涉案作品清单）
- 权利基础文件（授权协议/著作权登记证书）
- 侵权证据（公证保全材料、侵权页面截图）
- 证据目录

**可选输入**：
- 被告答辩状或抗辩要点
- 同类案件判决书参考
- 当事人对赔偿金额的期望

**信息来源**：用户上传 + 公开检索（同类判决）

### 2. 输出什么（Outputs）

**主要产出**：一审代理词
**格式要求**：四段式结构（权利基础→侵权事实→抗辩反驳→赔偿计算）；法条引用精确到条/项/款；证据引用格式"证据 X，页 Y"
**质量标准**：权利链条完整无断档；侵权事实有公证证据支撑；抗辩逐条反驳有法律依据；赔偿计算有公式和参考案例

### 3. 处理逻辑（Workflow）

**主流程**：
1. 梳理权利基础：核对授权链完整性（原始权利人→原告），确认授权范围、期限、地域
   - 决策点：授权是否排他？非排他 → 需补充维权授权文件
2. 整理侵权事实：逐一核对公证保全材料，确认侵权行为（直接提供/链接服务/教唆帮助）
   - 决策点：行为定性为"直接侵权"还是"间接侵权"，影响法律依据选择
3. 预判被告抗辩：列出被告可能的抗辩点（搜索链接/合理使用/合法来源），逐条准备反驳
   - 决策点：被告若主张"避风港" → 需论证原告已发出合格通知
4. 计算赔偿：按"权利人损失→侵权人获利→法定赔偿"顺序计算
   - 决策点：有明确授权费标准 → 参照许可费倍数；无 → 酌定赔偿
5. 组装代理词：按"权利基础→侵权事实→抗辩反驳→赔偿计算→诉讼请求"五段组织
   - 质量检查点：主办律师复核法律依据准确性

**异常路径**：
- 授权链有断档 → 标注"需补充授权文件"
- 被告当庭提出新抗辩 → 需补充代理意见

### 4. 向谁交付（Context.Delivery）

**终端用户角色**：合议庭（审判长、审判员）
**触发场景**：知产侵权诉讼一审庭审中/庭后提交代理词
**语气基调**：正式、论证性强、法条引用密集、尊重法庭

### 5. 需要哪些知识支撑（Knowledge Base）

**法律依据**：
- 《著作权法》第 10 条第 1 款第（十二）项（信息网络传播权）
- 《著作权法》第 26 条（著作权许可使用合同）
- 《著作权法》第 53 条第 1 项（侵权责任）
- 《著作权法》第 54 条（赔偿计算）
- 《最高人民法院关于审理侵害信息网络传播权民事纠纷案件适用法律若干问题的规定》第 3/4 条
- 《北京市高级人民法院关于侵害知识产权及不正当竞争案件确定损害赔偿的指导意见》

**范本来源**：
- 历史代理词样本 1 份（四段式结构）
- 同类案件判决书 3 份（赔偿标准参考）

**风险清单**：
- 授权链断档风险（非排他授权无维权授权）
- 证据链不完整风险（公证内容未覆盖全部侵权行为）
- 赔偿被酌定压低风险（法定赔偿远低于主张金额）
- 被告"避风港"抗辩成功风险

**风格偏好**：
- 法条引用精确到条/项/款
- 证据引用格式严格统一
- 抬头："尊敬的审判长、审判员："
- 落款："此致 XX 法院"

## 三、素材溯源

- 样本来源：1 份一审代理词（影视公司诉视频平台信息网络传播权纠纷）
- 辅助材料：证据目录 1 份（5 项证据）

## 四、待确认清单

- [ ] 法律依据覆盖度：仅覆盖信息网络传播权场景，如果侵权类型是复制权/发行权需补充法条
- [ ] 赔偿计算：法定赔偿酌定标准因法院不同有差异，建议补充本地法院裁判标准
- [ ] 反诉应对：素材未涉及被告反诉场景，建议补充反诉应对逻辑
