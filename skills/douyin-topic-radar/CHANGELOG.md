# 变更日志 (CHANGELOG.md)

本文档记录 douyin-topic-radar 技能的用户可见变更。

---

## [0.1.0] - 2026-11-25

### 新增

- 关键词检索采集：`radar.py driver` 生成 ego-browser 驱动脚本，支持综合排序深滚、最新发布 + 一周内、最多点赞三种模式，按作品 ID 去重并保留每轮滚动条数。
- 结构化卡片解析：从页面组件数据读取作品 ID、文案、作者、点赞/评论/收藏/分享、毫秒时长、Unix 发布时间与话题标签；读不到组件数据时回退解析可见文本，并在产物中标注。
- 相关搜索采集：读取搜索页底部“相关搜索”词条，作为选题句式的直接输入。
- 信号计算与报告：`rank` 输出时间分布、互动分位、高频标签、主要作者、高互动作品与规则化选题线索，生成 `candidates.md`。
- 短名单与链接清单：`shortlist` 按点赞分位、互动深度、近期性加权选取，同一作者限流，输出 `shortlist.json` 与 `links.txt`。
- 一致性校验：`verify` 交叉核对报告、短名单、链接清单与观察记录，任一不一致即非零退出。
- 下载交接：`download` 默认只打印计划，`--execute` 才调用 `yt-dlp`，逐条记录失败原因到 `download_receipt.json`。

### 说明

- 首次点击被页面吞掉的问题已通过“点击后校验 + 最多三次重试”处理，筛选面板与筛选项均适用。
- 报告中的热度是浏览器可见观察值，不是平台官方流量数据；抖音不公开搜索量。

### 审计返修

版本仍为未发布的 0.1.0，上述条目保留原始交付目标，下列为本轮返修的实际变更：

- **链接逐条对账**：`verify` 现在把 `links.txt` 与 `shortlist.json` 逐条比对，形状合法但指向其他作品的链接会被拒绝。此前只校验 URL 格式，把一条链接换成另一条合法作品地址仍能通过。
- **下载入口收口**：`download` 在调用下载器前校验每条链接必须是抖音作品地址，不合规直接非零退出；链接以 `--` 与选项分隔，避免被当作参数。
- **下载回执核验落盘**：回执按作品 ID 回查目标目录，只认非空常规媒体文件，记录 `media_path` 与 `size_bytes`，并给出 `verified` 与 `media_bytes`。下载器退出码为 0 但没有产出文件时记为失败。
- **采集卡片身份隔离**：React fiber 遍历不再跟随根节点的 sibling（那是下一张卡片），并要求元素节点仍在本卡片内。此前缺 ID 的卡片会借用相邻卡片的 ID，造成文案与链接错配。
- **分模式呈现时效**：新增 `recency_by_mode` 与 `recency_by_keyword`，报告增加「分采集模式的时间分布」。时效结论只用综合排序基线，避免「一周内」筛选把近期占比整体抬高。
- **候选加入主题相关性**：短名单按完整主题词或至少两个主题片段判断切题，无关作品不占名额；排序加入相关性权重，并记录每条的 `matched_terms`。新增 `--include-terms` 与 `--exclude-terms`，可排除面向委托人的内容（如「请律师」「找律师」）。
