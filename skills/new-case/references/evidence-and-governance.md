# 扩展归档：格式转换MD与项目治理

本文件定义诉讼案件归档的扩展骨架：`12 - 📄 格式转换MD/`、`13 - 📋 项目治理/`、项目 `AGENTS.md` 与 `evidence.md` 页码对照。

本 Skill 只创建目录骨架和管理文件，不读取材料正文，不执行下载、OCR、ASR、格式转换、归类移动或重命名。实际转换和材料入库由 `legal-material-organizer` 或用户完成。

## 1. 适用场景

- 用户要求“归档”“标准化目录”“项目治理”“格式转换”“evidence.md”“以后复用”等；
- 诉讼案件需要为后续 PDF、图片、Word 转 Markdown 预留统一位置；
- 案件需要长期维护，要求目标、任务、决策和变更可追溯。

## 2. 目录

### 12 - 📄 格式转换MD

```
12 - 📄 格式转换MD/
├── 转换索引.md      # 转换台账：源文件、MD、日期、工具、用途、状态
├── evidence.md      # MD与原始文件页码对照表
└── <镜像来源子目录>/ # 实际转换出的 Markdown（由 organizer 或用户生成）
```

### 13 - 📋 项目治理

```
13 - 📋 项目治理/
├── PROJECT_CHARTER.md
├── TASKS.md
├── DECISIONS.md
├── CHANGELOG.md
├── 归档对比核验-YYYYMMDD.md   # 如用户另行要求归档对比
└── specs/                     # 仅在重大功能/重构/多阶段协作时创建
```

## 3. evidence.md 规则

1. 每份转换后的 MD 至少登记一行：转换后 MD、MD 定位、原始文件名称、原始路径、页码、状态。
2. 页码默认按 PDF 页码；印刷页码不同时同时注明。
3. 一份原件拆成多段 MD 时，每段单独一行。
4. 写材料引用时一律用“原始文件名 + 页码”，不得只写 MD 文件名、标题或行号。
5. 转换文本与原件冲突，以原件为准。
6. MD 改名、重转、作废时保留历史行，另起新行登记新版本。

## 4. 项目 AGENTS.md 必写规则

在案件根目录生成 `AGENTS.md`，至少包含：

1. 案件标识：案件名称、案号、案由、法院、当前阶段、我方立场。
2. 关键日期：立案、开庭、判决、上诉期及起算口径。
3. 原始材料只读：禁止修改、覆盖、重命名、移动、删除；禁止 `rm`、`mv`、`truncate`、`sed -i`、`>` 写回。
4. 派生文件另存：分析→02，研究→03，文书→06，报告→10，参考→11，转换MD→12，治理→13。
5. 职责边界：本 Skill 不下载、不OCR、不转换、不移动材料；材料入库和转换由 `legal-material-organizer` 或用户完成。
6. 转换规则：转换产物入12；不得写回原件目录；同步 `转换索引.md` 和 `evidence.md`。
7. 引用规则：写材料用“原始文件名+页码”。
8. 治理读取顺序：AGENTS.md → PROJECT_CHARTER → TASKS → DECISIONS → Spec → CHANGELOG → 实际材料。
9. 当前待决事项与修订记录。

## 5. 治理文件规则

读取用户级 `AGENTS.md`（优先 `$CODEX_HOME/AGENTS.md`；不存在时依次尝试 `~/.codex/AGENTS.md`、`~/.agents/AGENTS.md`），按其标准建立：

- `PROJECT_CHARTER.md`：问题、目标、范围/非目标、阶段、里程碑、主要问题、下一阶段。
- `TASKS.md`：稳定编号 `TASK-001`，写目标、状态、验收标准、依赖/关联决策。
- `DECISIONS.md`：稳定编号 `DEC-001`，写背景、决定、理由、影响；旧决策保留并注明替代关系。
- `CHANGELOG.md`：写改了什么、为什么改、有什么影响，关联 TASK/DEC。

仅在重大功能、核心架构/数据模型、跨模块重构、主要流程或多阶段协作时建立 `specs/`。

## 6. 归档完整性核验

如用户另行要求对比原始目录与归档目录，可由 `legal-material-organizer` 或人工执行；本 Skill 只负责在 `13 - 📋 项目治理/` 记录结果：

1. 统计两边材料文件数，排除 `.DS_Store`、管理用 `.md`、`.yaml`。
2. 对每个材料文件计算 SHA-256，比较哈希多重集。
3. 比较文件名集合，单独说明改名和同名分置。
4. 检查原始目录当天是否有文件被修改。
5. 结果写入 `13 - 📋 项目治理/归档对比核验-YYYYMMDD.md`，结论用 `PASS` 或 `FAIL`。

## 7. 禁止事项

- 禁止把转换副产物写入原件目录。
- 禁止只登记 `转换索引.md` 而不登记 `evidence.md`。
- 禁止用 MD 行号替代原始文件页码。
- 禁止在本 Skill 中执行材料下载、OCR、ASR、转换、归类移动或重命名。
- 禁止把个人路径或个人习惯写入公开 `assets/*.yaml`。
