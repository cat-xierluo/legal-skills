# 格式转换 Markdown 索引

## 使用规则

- 仅登记从 PDF、图片、Word 等原始材料转换出的 Markdown。
- 转换由 `legal-material-organizer` 或用户执行；本 Skill 只创建本索引骨架。
- 转换前先把源文件复制到临时目录，不直接改动原件。
- 输出路径镜像来源目录，统一放入本目录。
- 引用转换文本前必须回看原件；冲突时以原件为准。
- 每份 MD 对应的原始文件名称、路径和页码，必须同步登记到 `evidence.md`。
