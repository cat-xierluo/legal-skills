# 案件档案 case.yaml 模板（v4.0）

> **输出文件**：`00 - 📅 日程管理/case.yaml`——固定文件名（DEC-011 无编号前缀），不再随案件编号变化。
> **字段契约**：case-progress skill `references/schema.md`（v4.0 唯一权威）——字段含义、枚举、行键、校验规则以契约为准，本模板不重复定义，只给填写指引。
> **写入纪律**：建档之后的**一切修改必须经 case-progress 的 case_store CLI**（或看板 API），禁止手改——手改是历史格式漂移的根因。
> **初始化标注**：`🔧 初始化` 段落建档时填充；`⏳ 后续` 段落留 null 供后续填充。占位一律用 `null`（不用 `[待确认]`/空串/下划线），指引见注释。
