# 设计决策

## DEC-001：确定性案例格式化以内容保全优先（2026-09-30）

- 背景：技能要求实质内容完整、案例序号不变；旧脚本按固定窗口、日期及推广词猜测边界，与此约束冲突。
- 决策：移除猜测裁切和正文关键词删除；只处理可识别的文末块，保留不确定的前后文与证据图片。显式 `keep_from_marker` 继续作为调用方选择的前缀边界。
- 标点：只对未被数字、URL、Markdown 链接与行内代码保护的普通正文做既有中文化，不修改版式范围以外的实质信息。
- 边界：这是确定性脚本修复，不新增法律判断、自动内容抓取、完整 Markdown 解析器或插件。LLM 工作流和人工复核仍承担语义清理；合成回归不代表真实法律文书全面验收。
- 许可：保留现有 CC BY-NC 4.0 文本与署名，不重新授权。
