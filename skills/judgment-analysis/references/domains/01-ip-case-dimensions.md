# 知识产权与不正当竞争判决的阅读问题

按判决实际争点选用。这里只提供读判决的提问框架，不作为外部法律依据或固定法律测试；法条与裁判标准以当前判决实际援引为对象，适用正确性及效力留待检索核验。

| 领域 | 逐争点阅读重点 |
|---|---|
| 商业秘密 | 法院如何界定秘密点、商业价值与保密措施？如何评价接触与使用证据、分配证明责任、确定赔偿？ |
| 专利 | 法院如何确定保护范围、逐项对应技术特征、处理等同与抗辩？哪些特征决定结论？赔偿基数如何认定？ |
| 商标 | 法院如何识别被诉使用行为、比较标志与商品服务、评价混淆及知名度、回应抗辩和赔偿主张？ |
| 著作权 | 法院如何确定作品、权属与权利范围，区分受保护表达与其他要素，评价接触/相似及抗辩，分项处理赔偿？ |
| 不正当竞争 | 法院如何描述行为和竞争关系、选取规则、认定损害及因果联系、处理不同请求之间的关系？ |
| 特许经营 | 法院如何认定合同性质、经营资源、信息披露与履行情况，回应解除/效力争议，区分返还与赔偿？ |

每项回答落到文内事实、证据、理由、结论和位置；法院未涉及的项目不硬填。技术图、商标图或证据实物未见时，不能宣称独立完成比对或鉴定。多个领域仅按实际争点组合，不因关键词命中而扩充全案业务范围。
