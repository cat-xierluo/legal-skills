# 领域阅读问题扩展

只在现有抽取规则不足以解释某类判决的裁判论证时，新增 `references/domains/<领域>-case-dimensions.md`。先确认其职责仍是读懂单份判决。

每个领域说明：识别线索、需要追问法院说理的具体问题、如何对应事实/证据/规则/主文、哪些结论需要外部核验。使用问题句，不把预设实体规则、条号、胜率、证据强弱排名或计算公式当作通用答案。

在 SKILL.md 增加按需读取入口；只读实际争点涉及的领域。不要增加卷宗搜集、法律检索、起诉状审查或庭审复盘流程。

复核时检查：单份判决能否回答；未写明时是否保留未知；是否混淆法院观点与分析者判断；是否擅自新增现行法结论。

参照 [知识产权阅读问题](01-ip-case-dimensions.md) 与 [判决分析模板](../../templates/template-internal.md)。
