# 静态 SVG：明确例外与后备

适合调用方明确要求静态、目标平台拒绝动画，或运动确实无解释增益的关系、分类、并列比较、结构全景和读者需要随时回看的总结。静态交付必须在配图计划中逐图写明例外理由；箭头与虚线可以保持静态，静态图也可以使用多行文字和功能性容器。

按 [共享原则](core-principles.md) 规划尺寸与内容，按项目选择内联或独立文件。`assets/layouts.svg` 是可直接打开、测量或导出 PNG 的三步流程例子；不再是把 Markdown 片段存成 `.svg` 的模板集合。按实际内容重排，不把例子字号或配色当成要求。

静态例外也要用 `python3 scripts/svg_motion.py validate assets/layouts.svg --allow-static` 显式验收，并在 preview/publish 时携带同样标记。生成 HTML 后切到 375px 检查文字和图形。静态图也会裁切、字体回退、重叠；结构通过不证明布局通过。对不接受 SVG 的目标平台，保留可编辑 SVG 并按 [PNG 路径](png-export.md) 导出。

公众号编辑器保存、预览与真机结果分别记录；不使用“完美支持”或“所有平台通用”的保证。
