# 多图协作

当多张图可独立制作且当前运行时支持授权内委派时，按协调收益决定是否并行，不用固定张数阈值自动启动 Agent。

主会话先读文章并固定配图计划、事实来源、视觉系统及各图 ID。传递所分配图的段落、目的、对象/状态、项目约束和验收要求，避免 worker 只见标题而凭空补业务事实。每个 worker 写独立产物，主会话是文章的唯一回填者。

worker 交骨架、时码、最终 SVG、命令与已知问题。主会话独立打开真实输出，复核节奏、字体、边界、截图和共同页面的 ID 唯一性，再回填文章。编译成功、worker 自报通过或沿用上一轮截图均不能代替当前候选验收。

需要中间锚点时，可在工作副本用 `[[ILLUSTRATION:01:描述]]` 绑定图 ID；交付前按计划核所有图已替换且顺序正确。不要把未完成占位符留在最终文章。
