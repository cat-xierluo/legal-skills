# PNG 导出

当接收平台不保留 SVG、用户要求位图或需要静态后备图时，保留 SVG 源文件，再导出 PNG。路径、文件名与引用方式沿调用项目约定，不强制与文章同目录，也不存在通用的 15 字符文件名上限。

## 依赖与调用

需要既有 Node.js 18+、Puppeteer和可用 Chromium。优先使用环境已配置的运行时/包目录；缺依赖时报出缺项，按环境约定在项目局部准备，不自动全局安装。脚本会探测常见系统 Chrome 路径，未找到时使用 Puppeteer 的浏览器配置。

```bash
node scripts/svg2png.js input.svg output.png 600
```

原 CLI 总是将 PNG 写到 SVG 同目录；给出 output.png 时只取文件名，目录部分被忽略。它没有覆盖保护，调用前检查该目标名不存在，或选择新的文件名。此版本保留原路径行为，不自动改造旧消费者。DPI 范围 72–2400，默认 600；该值用作相对 96 CSS px 的输出像素倍率，不能当成文件已有打印 DPI 元数据的保证。

先用 Python validate 核 SVG；导出前在浏览器选择可读的静态构图。原脚本没有暂停或时间定位，**不能保证截到指定动画时点**。需要其他时点时，先生成独立静态总结 SVG 或通过预览的时间定位另行截图。需要确定帧时使用静态源，避免依赖未冻结的 SMIL 截图。

输出后检查 PNG 像素尺寸、文字、emoji 回退、裁切、透明背景及平台压缩结果。600 倍率的大图可能不适合实际上传，按目标尺寸选择参数。截图分辨率不能证明字体或内容正确。

PNG 用 Markdown 图片语法引用，路径按接收项目约定。上传图床或发布不自动执行，用户明确要求时再使用相应工具。
