# 浏览器布局验收

测量真实输出，不用字符数或正则证明没有重叠。先校验 SVG，生成 preview HTML，打开后确认 SMIL、字体和 SVG 实际尺寸；修改后重新编译、测量及截图，旧结果不覆盖新候选。

## 标注与测量

`scripts/measure_layout.js` 的 `measureSvgLayout(svg, options)` 已嵌入 preview。函数先核 document.hidden；后台时立即抛出 NOT_VERIFIED。fonts.ready 和双 rAF 共用最多 2 秒等待，等待中切后台或超时即拒绝，不产出测量结果；把页面带到前台后重测。options.waitTimeoutMs 可缩短至 (0,2000] 毫秒。预览按钮会显示失败原因，不保留旧报告冒充新结果。等待成功后读取 BCR、实际透明度、屏幕矩阵、文字长度及字号。可从浏览器自动化 `evaluate()` 调用，不需重写测量逻辑。

- 全部 `<text>` 自动纳入；对象或组合加唯一 `data-layout-id`。未标注且不属于已标注组合的图形会计入 `unannotated-graphics` 警告，不因此宣称全图已检。
- 容器形状标 `data-layout-id="panel" data-layout-role="container"`；文字或文字祖先标 `data-layout-within="panel"`。只有目标存在、可见且实际全包含才豁免容器碰撞；文字越出容器仍报错。嵌套容器可逐层声明归属，只有每一层均可见且实测包含时才传递豁免；排除记录包含完整 containment 路径，缺边、循环或任意一层越界均不作为传递包含。
- 背景可标 `data-layout-role="background"`，报告明确记录被排除的相交对；不能把有内容的对象批量标成背景来消警告。
- 互斥状态祖先标 `data-state-group="result" data-state="old"` 或 `new`。透明度由当前帧计算，隐藏项单列。两个不同状态同时可见且相交会报 `exclusive-states-both-visible`，标注本身不能豁免。
- 已标注组合与其后代边界实际包含时，返回 `measured composite and its descendant` 排除记录，避免组与自身文字重复计数；独立兄弟文本仍查碰撞。

`errors` 含越出视口、越出声明容器、字体过小、可见互斥状态和相交候选。默认容差 0.5 CSS px、可见透明度阈值 0.001、文字下限 12 CSS px，可通过 options 指定并随报告保留。12px 是本测量的审阅起点，不保证所有字体都易读；标题层级、行距和颜色仍查截图。

返回的 `items` 含真实矩形、CSS 字号、文字长度、字体栈、状态和 opacity；`exclusions`、`hidden` 保留原因。浮点容差不可用于遮掉明显越界。未找到、隐藏、角色不对的容器都会明确报错。

## 有意遮挡与测量边界

包围盒相交只是候选。矩形容器包含文字、箭头连接对象、指针停在按钮上、弹窗遮住旧界面都可能有意发生。对有意碰撞保留该时点截图与对象 ID，再写出可观察理由。

后绘制的不透明矩形可能把旧标签完全覆盖；此函数**仍会报文字碰撞候选**，不会仅凭 DOM 顺序自动豁免。要解释遮挡，需要测得覆盖者位于文字之后、有效填充与祖先透明度为 1、屏幕边界全包含，并确认 clip/mask/filter、叠加顺序和截图；半透明、局部覆盖或高层变换下不能只看 rect 的 fill。更稳妥的创作方式是将旧/新文字置于真正互斥的可见层。

BCR 不精确代表笔画像素，可能高估旋转图形或低估 stroke、marker、filter 的范围。mask/clip 在报告中提示人工复核；并不以被裁掉后的可见区域证明原内容不越界。字体栈和 fonts.ready 不能证明星号 emoji、缺字或字体替代符合预期，另查截图/实际可用字体。

## 取样与验收

在实际 375 和桌面宽度分别记录 `svg.getBoundingClientRect().width`。每次定位后重新测量，至少覆盖初态、关键停留、运动中段、交接两侧、周期末 `T−ε`、`T`、`T+ε`。复杂路径增加交叉点与接近边界的时点；有限取样不能保证连续时间的所有碰撞均不存在。

实际播放两个周期确认视觉节奏与复位，再暂停/拖动并核时间与状态。保存候选 SHA-256、浏览器/视口、采样秒数、测量 JSON 与关键截图到调用项目的既有证据位置。正文回填后还要检查同页 ID 引用及格式化后的 SMIL。

长中文/中英混排回归见 [验证设计](verification.md)。微信编辑器保存、预览、手机真机分别验证；浏览器完成时它们仍为 `NOT_VERIFIED`。
