# 更新日志

## [1.1.6] - 2026-10-30

### 改进

- `validate` 与 `publish` 默认要求每段文章 SVG 至少包含一组原生 SMIL；完全没有动画的静态文件不再静默通过。
- 静态交付改为显式例外：仅在配图计划和交付说明逐图记录理由后使用 `--allow-static`，不能为了通过工具门禁临时跳过。
- 回归测试绑定“动态默认通过、静态默认拒绝、显式静态例外通过”三条路径，同时保留 3–5 秒时长合同。

## [1.1.5] - 2026-10-30

### 改进

- 文章动态 SVG 的常规循环时长收窄为 3–5 秒；复杂过程通过拆图、删减无信息动作和合并状态处理，不默认延长周期。
- 编译器与校验器拒绝 3–5 秒范围外的时间轴；默认样例、工具示例和验收时点同步缩短，仍要求关键结果保留可读停留。
- 测试增加 3、4、5 秒正例与 2.9、5.1 秒反例，确保节奏约束不只停留在说明文字。

## [1.1.4] - 2026-10-29

### 改进

- 文章 SVG 插图默认输出原生 SMIL 动画；每张图需要至少一组解释对象关系或状态变化的动效，不能静默降级为静态示意图。
- 静态改为明确例外：仅用于调用方要求、平台限制或运动无增益的场景，并在计划与交付说明中逐图记录理由。
- 交付回读增加动画存在性要求；仅有浮动、闪烁等装饰动效不足以称为动态配图。

## [1.1.3] - 2026-10-29

### 改进

- 主入口聚焦阅读任务、视觉主句、构图、空间关系与连续变化，收起反复出现的具体形式示例。
- 移除内容类型与画法的映射表；素材仅用于按需查询工具和变换方法，画面形态由当前内容推导，避免将参考作品或两套示例变成创作模板。
- 界面、鼠标和其他具体造型继续保留为条件技术资源，不扩展成默认表达或新增固定风格。

## [1.1.0] - 2026-10-29

### 新增

- Python 标准库 `svg_motion.py`：静态骨架与秒数 JSON 编译为共同周期的 SMIL，支持 opacity、translate、scale、分段停留及 spline。
- XML、时序与本地引用检查；未知语法或外部资源在明确的保守子集中拒绝，不将检查通过等同于平台认证。
- 自包含 HTML 预览，提供播放、暂停、重置、逐秒步进、scrub、375px/桌面切换及实际 DOM 测量。
- 小型可运行示例、结构/错误路径回归与浏览器坐标、长混排、容器及互斥状态回归入口。
- DOM 测量在后台或字体/绘制等待超过 2 秒时以 NOT_VERIFIED 拒绝，不将旧报告或未完成绘制计作通过。

### 改进

- 从内容、配图计划、对象与状态推导时间轴；保留静态关系图和原 PNG 路径，取消固定配图数量、单行文字、统一缩小和箭头强制动画。

- 固定记录 wechat-animating 评估提交及 MIT 来源，独立实现最小工具，无整套安装或未归因代码复制。

### 修复

- 修正空分组动画不作用于兄弟文字的示例；静态定位与动态变换采用分层，明确相对位移、绝对轨迹与重复初始定位风险。
- 将旧的 Markdown 伪扩展名布局/动画素材改为可解析 SVG 示例。
- 资源检查同时拒绝表现属性中的 CSS 转义，避免 fill / stroke 绕过外链及缺失引用检查；保留普通本地引用正例。
- 移除无环境证据的公众号完美兼容断言；浏览器、编辑器保存、手机预览分别结算，真机仍待实测。

- 🐛 **背景色缺失问题**：纯白背景（#FFFFFF）导致圆角、边框等视觉元素无法显现，与文章文字对比度不足

### 影响文件

## [1.0.4] - 2026-03-19

### 修复

- 🐛 **最高频 Bug**：修复 `transform="translate()"` 定位 + `<animateTransform type="translate">` 动画组合冲突问题
  - **问题**：动画会完全覆盖外层定位，导致所有元素堆叠到左上角 (0,0)
  - **影响文件**：core-principles.md、dynamic-svg.md

### 新增

- 📝 核心原则文档新增"最高频错误"章节：详解 transform + animateTransform translate 冲突
- 📝 动态 SVG 文档新增"动画组合速查表"：清晰列出哪些定位方式与哪些动画类型可以安全组合
- 📝 记忆口诀：**translate 定位只能配 scale/rotate，要做浮动必须用 x/y/cx/cy 直接定位！**

### 技术细节

- 正确做法 1：直接用 `cx/cy` 或 `x/y` 定位，内层 `<g>` 包动画
- 正确做法 2：`transform="translate()"` 定位只能配 `type="scale"` 或 `type="rotate"` 动画
